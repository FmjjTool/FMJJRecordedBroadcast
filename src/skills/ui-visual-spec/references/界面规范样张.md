# 界面规范（样张版）

本目录是一个可运行的界面规范样张，不含业务逻辑。本文记录**这套界面必须遵守的规则**，以及样张里对应的实现位置。

- 主题与控件基线：`theme_real.py`（主程序 `theme.py` 副本）
- 外壳样式：`shell_qss.py`（主程序 `_SHELL_QSS` 副本）
- 无边框窗口：`window_chrome.py`（主程序副本）
- 线形图标：`icons.py`
- 页面与组件示例：`sample_gui.py`

改界面时以本文为准；本文没写的，按主程序 skill（`ui-visual-spec` / `ui-interaction-spec`）执行。

## 一、设计令牌

### 1.1 颜色

只用 `theme_real.py` 的语义角色，**不写十六进制**。

| 角色 | 用在哪 |
| --- | --- |
| `window` | 页面底、窗口底 |
| `base` | 卡片、输入框、侧栏、顶栏、弹层 |
| `alternate-base` | 表头、未选中页签、次级块 |
| `text` / `window-text` | 正文、标题 |
| `muted`（placeholder-text） | 辅助说明、表头字、图标 |
| `accent`（highlight） | 主操作底、进度、焦点、选中 |
| `on_accent` | 主操作上的文字/图标 |
| `link` | 链接、激活图标、悬停强调 |
| `border`（shadow） | 卡片/分隔线边框 |
| `mid` | 输入框边框、**二级页签边框**、勾选框边框 |
| `danger` / `danger_soft` | 错误、危险操作 |

规则：

- 子控件背景默认透明，让卡片底透出；不要逐层重设背景。
- 切主题只换 `QPalette`，页面不写主题分支。
- 自绘控件每帧取 `theme.current_palette()`，不缓存 `QColor`。

### 1.2 字号

| 字号 | 用途 |
| --- | --- |
| 10px | 品牌副标题、极小的注释 |
| 11px | 辅助说明、表头、分组标题、错误行 |
| 12px | 导航项、搜索框、页签（四级）、小按钮 |
| 13px | 正文默认（全局基线，页面不再声明） |
| 14px | 区块标题、面包屑当前页 |
| 27px | 统计数字 |

16 / 17 / 20 / 23 等越级值不得新增。

### 1.3 圆角

| 值 | 用在哪 |
| --- | --- |
| 3px | 勾选框（自绘） |
| 4px | 进度条、骨架条 |
| 6px | 输入框、下拉、普通按钮、页签上圆角、四级分段页签 |
| 8px | 导航项、搜索框、窗口按钮、**下拉弹层**、toast |
| 10px | 次级卡片 |
| 12px | 主卡片 |

### 1.4 间距

只用 `2 / 4 / 6 / 8 / 10 / 12 / 16`。

| 场景 | 值 |
| --- | --- |
| 页面四边 | 16 |
| 卡片之间 | 12 |
| 卡片内边距 | 12（带标题行 12,10,12,12） |
| 同一行控件 | 8 |
| 标签与控件 | 6 |

### 1.5 边框

| 场景 | 宽度 | 颜色 |
| --- | --- | --- |
| 卡片、分组 | 1px | `border` |
| 输入框、表格 | 1px | `mid` |
| 二级页签 | 1px | `mid` |
| 页签选中指示 | 2px 下边线 | `accent` |
| 分隔线 | 1px | `border` |

悬停/焦点只换颜色、不换宽度。除页签下边线外不得出现 ≥2px 边框。

## 二、外壳

### 2.1 窗口

- 无系统标题栏：`Qt.FramelessWindowHint`，标题栏、拖动、双击最大化由 `window_chrome.py` 提供。
- 四边/四角缩放热区：`install_resize_handles(self)`。
- 圆角：`apply_round_corners(self)`，在 `showEvent` 里调用。
- 默认 1240×820，最小 880×560。

### 2.2 侧栏

固定宽度 228，窗口 < 1040 时收 200。自上而下：

1. 品牌区：34px 图标 + 标题（16px 粗）+ 副标题（10px muted），内边距 `18, 23, 14, 18`。
2. 搜索框：高 34，圆角 8，`base` 外的 `window` 底，占位「搜索工具 · Ctrl+K」。
3. 分组标题：10–11px、muted、加粗。
4. 导航项：`padding: 8px 11px`、字号 12、图标 18、圆角 8；选中 `midlight` 底 + `link` 字 + 加粗。
5. 底部固定区：账号与登录卡片（状态、开关、管理入口）；任务 / 设置 / 性能 / 主题已移到顶栏。

### 2.3 顶栏

高 54，`base` 底，底部 1px `border`。内容从左到右：

- 面包屑：`分组 / 当前页`，分组用 muted、当前页用 text + 600 字重，单个富文本 QLabel（两个 QLabel 基线会对不齐）。
- 弹性留白。
- 顶栏入口：任务 / 设置 / 性能 / 主题，高 30、`padding: 0 10px`、字号 12、图标 16、圆角 8；常态 muted，悬停 `midlight` + `link`，当前页按钮保持选中底色。
- 1px × 18 分隔线。
- 窗口控制三连：最小化 / 最大化（还原）/ 关闭，每个 40×30、图标 16、圆角 8；关闭悬停用系统红 `#e81123`。

## 三、页面与页签

### 3.1 页面骨架

- 页面根控件四边 16，块间距 12。
- 页面顶端不放标题与说明：身份由侧栏 + 面包屑提供。
- 内容就是二级页签容器时，根布局设 0 边距，由各子页自己留 16（避免 16 叠 16）。

### 3.2 页签层级

最多四级，层级靠**位置 + 形态**区分。

| 级 | 位置 | 形态 |
| --- | --- | --- |
| 一级 | 侧栏 | 导航项，不是页签 |
| 二级 | 页面顶部 | 卡片式：`alternate-base` 底、上圆角 6、**1px `mid` 边框**、选中 `base` + 2px `accent` 下边线 |
| 三级 | 页内第一块卡片上方 | 下划线式：无底无框、`padding: 6px 12px`、选中 2px `accent` 下划线 |
| 四级 | 卡片或区域内部 | 分段式：容器 `alternate-base`、圆角 6、选中 `base` + 1px `border`、`padding: 4px 10px`、字号 12 |

规则：

- 需要第五层说明信息架构有问题，改用下拉筛选或拆页。
- 二/三/四级不得长得一样；三级/四级用页面级 `objectName` 收敛，不动全局 `QTabBar` 基线。
- 页签不响应滚轮切页（见 5.5）。
- 全局操作（刷新等）放 `setCornerWidget` 或工具栏右侧，不混进页签行。

## 四、工具栏与按钮

### 4.1 一行一件事

`[输入 / 筛选] …… [次要操作] [主操作]`

- 主操作每行最多 1 个，固定最右。
- 危险操作与主操作至少隔 12，或收进「更多」。
- 单行按钮 ≤5 个。
- 按钮高度一致（`padding: 6px 12px`，约 30px）；仅图标 30×26 + tooltip。
- 按钮文案动词开头 2–6 字，不加标点。

### 4.2 变体

| 变体 | 外观 |
| --- | --- |
| `primary` | `accent` 底 + `on_accent` 字，加粗 |
| `danger` | `danger_soft` 底 + `danger` 字 + `mid` 边框；悬停实心 `danger` |
| `secondary` | `base` 底 + `border` 边框 |
| `ghost` | 透明底 + muted 字，悬停 `midlight` + `link` |

### 4.3 带菜单的按钮

- 菜单按钮用 `menuButton=true` 属性：按下/展开只变 `midlight` 底 + `link` 字，**不得变主操作蓝**。
- 箭头只用 Qt 自带 `menu-indicator`，不要再 `setIcon(chevron)`，否则双箭头。

### 4.4 放不下时

严格按顺序：

1. 收进「更多 ▾」菜单；
2. 整组换行（需要流式布局时用 FlowLayout，不要复制第二份实现）；
3. 只去掉修饰词，缩短文案。

禁止：横向滚动条、文字截断、按钮被隐藏、为塞按钮缩小字号。

判定：1240 宽放得下就一行；880 宽至少主操作与「更多」可见。

## 五、输入控件

### 5.1 下拉

- 同组等宽（120–160），不随选项文字跳动。
- 筛选类首项固定「全部」，不用空项、不用「请选择」。
- 2–12 项普通下拉；>12 项用可编辑下拉（`setEditable(True)` + 补全）；<2 项改只读文本。
- 长文本省略 + tooltip 全文。
- 选项文案与被筛选数据完全一致。

### 5.2 下拉弹层圆角（三件套，缺一不可）

1. 视图：`border-radius: 8px` + 1px `mid` + `padding: 4px`；
2. 容器：`WA_TranslucentBackground` + `FramelessWindowHint` + `background: transparent`；
3. 窗口：`setMask()` 按 8px 圆角裁剪。

只做前两步：首帧直角、滚动条压角；只做遮罩不做透明：外圈露底色。

`RoundCombo.showPopup()` 里按最终尺寸设遮罩，并补一次 `singleShot(0)`。

### 5.3 数字框

- 容器右侧 `padding: 22px` 留给按钮。
- `::up-button` / `::down-button`：宽 20、贴右边缘、`subcontrol-origin: border`、上下各占一半。
- 一旦覆盖了 subcontrol，原生箭头不再绘制，**必须**补 `::up-arrow` / `::down-arrow` 的 `image`（本目录用 `assets/spin_up.png` / `spin_down.png`）。
- 箭头图在 `QApplication` 创建后生成，不能提前（`QPixmap` 早于 `QGuiApplication` 会直接崩）。

### 5.4 勾选框

- 不要只写 `::indicator:unchecked`：选中态会落回原生，出现两种观感。
- 表格勾选列自绘（`CheckDelegate`）：
  - 未选：`base` 底 + 1px `mid` + 圆角 3；
  - 选中：`accent` 实心 + `on_accent` 白勾；
  - 绘制前 `opt.features &= ~QStyleOptionViewItem.HasCheckIndicator`，否则原生方框和自绘框叠成双层。

### 5.5 滚轮

下拉、数字框、滑条、页签**一律不响应滚轮**（滚轮只滚页面）。统一在应用级事件过滤器拦，控件声明 `wheelOk=true` 才放行。

## 六、表格

| 项 | 规则 |
| --- | --- |
| 勾选列 | 第 1 列，宽 36，自绘，不参与排序 |
| 列宽 | 文本列 `setMinimumWidth(60~140)`，最后一列 `Stretch` |
| 长文本 | 省略 + tooltip，不换行撑高 |
| 行高 | 不手动设置，交给样式 |
| 选中 | `accent` 底 + `on_accent` 字 |

- 表头可点击排序（升 → 降 → 默认），勾选/图片/按钮列不参与。
- 分页文案：`第 3 / 12 页 · 共 2 341 条`；首页/上一页在首页置灰，下一页/末页在末页置灰。
- 默认每页 200 条；一次渲染分批 20 条。
- 空态不显示空表头，给一条「为什么空 + 下一步」；筛选无结果要写清总数与出口。
- 双击 = 打开详情/预览，不做破坏性操作；右键菜单与工具栏同能力。

## 七、状态与反馈

| 通道 | 用于 |
| --- | --- |
| toast | 成功提示、开关变化（2.6 秒，底部居中） |
| 状态栏 | 常驻状态、计数 |
| 行内提示 | 表单校验，控件下方 11px `danger` |
| 弹窗 | 必须决策、批量结果汇总 |
| 日志区 | 过程明细 |

- 成功不弹窗；同一事件只走一个主通道。
- 长任务：可见进度条 + 可取消 + 完成说明结果去向；完成/取消写「已完成 · 存到 X」「已取消（完成 42%）」。
- 错误三段式：做什么失败 + 原因 + 下一步；不出现堆栈、绝对路径、凭据字样。
- 状态词只用：未开始 / 进行中 / 已完成 / 失败 / 已取消 / 已跳过。

## 八、表单与弹窗

### 8.1 表单

- 左标签右控件；标签右对齐、同组等宽（本目录 64px）。
- 必填标签后缀 `*`。
- 失焦校验格式，提交校验完整性；错误显示在控件下方并把边框改 `danger`。
- 目录用只读输入框 + 浏览按钮，路径末尾显示、tooltip 全文。
- 数值用 `QSpinBox`/`QDoubleSpinBox`，带范围与单位后缀。

### 8.2 弹窗

- 只用于「不回答就不能继续」；长任务/配置用非模态独立窗口。
- 尺寸：单表单 720×520，列表型 900×640，宽型 1040×720；不超可用区，超高给滚动。
- 按钮区右下，顺序「危险 … 取消 主操作」；`Esc` = 取消；破坏性操作不绑 `Enter`。
- 二次确认写三段：做什么（带对象名）、影响、默认按钮是取消。

## 九、图标与文案

### 9.1 图标

- 24×24 逻辑坐标系，描边 1.65（窗口控制 1.4），`RoundCap/RoundJoin`，不填充。
- 2 倍分辨率 + `setDevicePixelRatio(2)`。
- 颜色取主题角色，不传十六进制。
- 已用：`table` `sliders` `play` `download` `stop` `refresh` `search` `trash` `folder` `win_min` `win_max` `win_restore` `win_close`。
- 语义接近就复用，不为同一概念画第二个；新增要同步图标清单。
- 切主题后图标必须重绘（颜色烘进像素）。

### 9.2 文案

| 语义 | 用 | 不用 |
| --- | --- | --- |
| 拉数据 | 抓取 | 获取、拉取 |
| 启动 | 开始 | 启动、运行 |
| 中途停 | 停止 / 暂停 | 结束、中断 |
| 重来 | 重试 | 再试一次 |
| 输出 | 导出 | 保存为 |
| 写入配置 | 保存 | 确定、应用 |
| 删除 | 删除 | 移除 |

- 界面文案不得出现 emoji。
- 禁止「请稍候」「未知错误」「出错了」。
- 数量单位统一：条 / 个 / 张 / 首 / 场 / 位；日期 `2026-11-21`，时间 `21:30`。

## 十、主题切换

1. 只切 `QPalette` + 全局 QSS，页面不写 `is_dark()` 分支。
2. 自绘控件在 `paintEvent` 取 `current_palette()`。
3. 预生成的图标、遮罩、箭头图在切主题后重建。
4. 弹窗、菜单、浮层在显示时也要正确着色。
5. 验证路径：浅 → 深 → 浅、跟随系统、懒加载页、弹窗、独立窗口。

## 十二、本目录踩过的坑（别重复）

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| 二级页签看不出形状 | `alternate-base` 与 `window` 只差 3 个色阶 | 边框用 `mid`，不用 `border/shadow` |
| 「更多」变蓝、两个箭头 | 菜单展开命中 `pressed` 蓝底；自绘 chevron + 原生 indicator | `menuButton` 属性 + 去掉自绘箭头 |
| 数字框箭头点不动 / 消失 | 只写 padding 没约束 subcontrol；覆盖 subcontrol 后原生箭头不再画 | 显式上下按钮 + 自绘 `arrow image` |
| 勾选列两种观感 / 双层框 | 只写未选态 QSS；自绘未清 `HasCheckIndicator` | delegate 自绘 + 清除原生指示器 |
| 下拉首次直角、右下角直 | 容器不透明；滚动条子控件不受父级圆角裁剪 | 透明容器 + 窗口 `setMask` |
| 图标按钮空白 | 图标库里缺 `win_min/max/restore/close` 分支 | 补绘制分支，空名不报错只是不画 |
