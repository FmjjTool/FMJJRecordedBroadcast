## 强制阅读与维护边界

涉及下列任一内容，操作前完整阅读本入口：

- 腾讯文档自动 / 定时 / 增量同步、写回、批量填充、上传或修改同步范围。

## 官方动态：当次新增选项值

## 官方动态：新增行的图片

新增官方动态行可同时带「封面图」和「评论区图片」，只通过 addRecords；此图片流程不改 / 不删已有行、不改结构、不扩大表范围。

「评论区图片」只取本地评论区导出中封茗囧菌本人（平台账号 ID 匹配）的顶层评论：一张筛选后的评论区长图及她评论中的原图。没有本地评论、只发文字、原图链接过期时留空 / 跳过，不临时抓取或伪造。线下活动宣传图不在本流程范围内。

## 刷新门禁与免校对

所有上传、行级修改 / 删除必须使用刚刷新的数据：采集任务 + 网媒账号资料采集 → 重新拉取腾讯表格快照，三步均成功才能继续；任一步失败则锁定上传并说明失败步骤。刷新凭证 60 分钟过期，上传成功立即作废，下一次重新刷新。禁止直接调用 import_pending.run(..., apply=True) 绕过。

现有“免校对模式”是用户在中间层工具条显式开启的例外，键 tcdoc_skip_sync_refresh，默认关闭；Agent 不得代开。开启时，中间层批量 / 单行与资产单条上传可用已有本地数据和快照，并在写入时读云端当前行去重；关闭恢复全部刷新门禁。它不扩大两表范围、不解除只新增入口的限制、不免除选项值当次确认与备注追加；过期快照可能漏判重复，回执须提示核对。不能把该设置自动推广到其他入口。

实现：src/toolbox/sync_refresh.py、config/sync_refresh.json（仅说明路径，不在真实环境改写）、gui_qt/pages/tcdoc_bridge.py。

## 行级修改 / 删除（含 WebUI）

既有 WebUI TARGETS 仅官方动态与直播记录；L3 必须拒绝其它表，不依赖界面过滤。这里只记录受限操作流程，不授权本次任务之外的真实写入。

1. 按 recordID 逐条操作；修改只传被改字段，删除单次不超过 20 条。不整表覆盖、不改结构。
2. WebUI 修改仅限文本列 fieldType 1 / 7 / 16，数字 / 日期 / 链接 / 多选 / 图片等拒绝。
3. 先实时读取当前行并预览 old → new，再二次确认提交；删除先列标题 + recordID 清单再确认。
4. 写后读回：逐字段比对；删除确认 recordID 消失。结果不明 UnknownWriteResult 时不重试，提示人工核对。
5. 同样受刷新门禁或用户已开启的免校对模式约束，与桌面上传共用 import_pending 写入锁。
6. 此通用文本修改 / 删除入口不提供按条件批量删除、清空整表、结构变更或追加已有行图片；上传中新建选项值仅按上一节的四列例外。独立的官方动态封面回填流程见下节，不能据此放宽其它图片入口。

实现：src/toolbox/webui_tcdoc_edit.py；import_local.LocalImportClient.update_record / delete_record 每次仍须 validate_target；src/toolbox/webui/services/tcdoc.py；/api/tcdoc/edit/{status,preview,update,delete}。

## 执行前后检查与越界处理

执行前核对：目标 doc_key 正确、tab_id 恰为两项之一、已限定 record_id 或明确新增行、本次动作获准、刷新与确认门禁有效、无凭据写入副作用。同步与规则变动按总约定先核对远端 / 本地历史。

完成后报告：文档名与 doc_key、表名与 tab_id、动作及条数、record_id 或新增行定位字段、读回结果，以及是否触碰白名单外目标。不要报告凭据或无关个人信息。

发现白名单外已发生改动：**立即停止后续操作与所有新的写入**，保留不含凭据的证据，列明对象与影响并报告，等待用户对恢复的具体指示；回滚本身也是写入，不得自动执行或扩大。发现代码中历史越界链路时不得沿用，按本次代码任务授权范围处理，未授权则记录并继续可独立完成部分，不为技能维护擅改应用。

本地同步引擎在 src/toolbox/tcdoc/；页面在 src/gui_qt/pages/tcdoc.py、tcdoc_bridge.py、tcdoc_mapping.py。OpenAPI 三字段仍由统一账户管理对话框维护，页面不新建凭据输入控件。src/toolbox/skills.py 扫描到技能不代表规则已被运行时执行。收尾统一按总约定写当日报告、本地提交，不自动推送。
