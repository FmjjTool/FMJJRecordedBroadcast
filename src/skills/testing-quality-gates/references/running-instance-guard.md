# 运行中实例保护

本文件是运行保护的唯一正文，入口为 [testing-quality-gates](../SKILL.md)；旧名 [running-instance-guard](../../running-instance-guard/SKILL.md) 仅作兼容跳转。先遵守 [总约定](../../convention-skill/SKILL.md) 与 [真实凭据保护](../../cookie-data-protection/SKILL.md)。

## 实例归属与权限

| 实例 | Agent 可执行范围 |
| --- | --- |
| 用户正在使用、用户启动，或归属不明的实例 | 默认只读检查；不得擅自关闭窗口/二级窗口、退出、结束/挂起进程、重启服务或停止后台业务 |
| 用户对本次具体实例明确授权关闭/重启 | 先说明录制/采集/同步中断与文件风险；按明确范围正常收尾后操作。授权接入、验证或让改动生效不等于关闭授权 |
| Agent 本任务创建且完全隔离的测试实例 | 可按记录的 PID、端口、目录正常结束并清理；不得使用进程名批量结束，也不得牵连用户实例 |

需要验证新代码时新建程序副本、新进程与新端口，不能先关旧实例。数据根跟随程序根，没有 --work-dir；完整隔离方式见 [隔离测试](isolated-testing.md)。不确定隔离或进程归属时，按用户实例保护。

## 运行中判定

只读查看进程命令行与路径、窗口/托盘、监听端口、业务状态或文件占用；任一信号成立即视为仍在运行。不能仅凭某个 python.exe、node.exe 名称判定属于测试实例。

- 桌面窗口、直播二级窗口、弹幕浮层或托盘仍在。
- 项目 exe、携带项目脚本路径的 Python、关联后台进程仍在。
- WebUI / 资料站端口监听，正在录制、采集、同步、打包或上传。
- 文件被锁、出现 PermissionError / WinError 32；遇到占用先停止相关文件变更，不强行替换。

运行检查的只读范围不自动授权驱动真实界面、截图真实数据、创建数据库快照或执行测试；后者仍按隔离参考的申请边界。

## 文件与业务保护

不得覆盖、替换或删除运行中的 exe / dll、目录与被占用文件；不得用 git reset、checkout、restore、stash 等覆盖运行实例依赖的源码。构建或更新若会清理运行目录，应换到独立副本。关闭授权不自动授权覆盖该实例文件或改动真实数据。

直播/弹幕录制先走停止、等待写完与正常打包；采集/同步先保存进度与结束事务。即使获准关闭，也优先正常退出。强制结束仅在用户已明确要求对指定实例强制关闭、且风险已说明时执行；不能把崩溃或无响应视为自动强制结束授权。

Agent 自建隔离实例也应正常收尾；清理其孤儿子进程前核对父子关系与独立目录。正常退出失败时，只处理已确认完全属于该隔离实例的进程，不能使用按名称批量 taskkill / Stop-Process。

## 收尾核对

核对归属、PID/路径/端口和授权范围；用户实例保持运行，或仅按本次明确关闭授权处理；未覆盖运行文件；隔离实例正常收尾。无法安全完成时说明具体占用与剩余状态。报告和本地提交按总约定，本文件不授权改动真实凭据、录播八模块或腾讯文档范围。
