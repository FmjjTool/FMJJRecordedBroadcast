## 测试选择与门禁

- Bug 修复先构造能复现问题的失败测试，再改代码；修复后证明同一用例通过。不得放宽断言、跳过测试或删失败用例来伪造通过。
- 网络在 Adapter 边界使用 fake / mock；数据只用虚构凭据、最小 fixture 与临时库。测试自动化默认不连真实网络、账户或生产数据库。真实环境仅按隔离参考中的当次批准范围执行，真实凭据禁令无例外。
- 只维护 Markdown 规则、索引、引用时，静态核对内容、链接、前后规则和差异即可；不为文档验收启动应用、运行导入或接入账户。
- `tests/` 是用户选择的一次性本地验证目录，已被忽略、不入库。回归用例在本次修复中先失败后通过，记录复现输入、命令与结果后按清理正文删除；这不承诺跨任务保留持续回归资产，也不授权 Agent 改动忽略策略。用户当次明确要求保留或维护测试基础设施时按其范围处理。

| 改动所属层 | 必须覆盖的行为 | 环境 |
| --- | --- | --- |
| Domain / L3 | 去重、日期范围、匹配/分组、排序、分页、状态机、编排 | `tests/`；纯逻辑/服务与 fake 适配器 |
| Adapter | 字段解析、空结果、分页、错误分类、回退顺序 | `tests/`；脱敏且不含真实个人数据的固定 fixture |
| L5 数据 | 迁移、旧数据兼容、事务/WAL、并发写、索引、备份/恢复与失败回滚 | 临时目录中的 SQLite |
| L2 UI | 构造、关键按钮/状态、无异常与无网络/凭据副作用 | 隔离副本；QT_QPA_PLATFORM=offscreen 与 fake app |
| 人工 UI / 平台行为 | 布局、交互、长任务与实际能力 | 默认隔离副本；真实接入另按参考申请 |

修改去重、日期、匹配、分组、排序、分页必须覆盖边界；修改重试、超时、限流、回退或取消必须覆盖成功、失败与取消。修改数据库必须覆盖迁移、旧数据兼容及失败回滚；修改适配器必须覆盖响应解析、错误、空结果、分页与回退。UI 改动需相关页面 offscreen 冒烟；视觉改动再按 [视觉规范](../ui-visual-spec/SKILL.md) 核对浅/深主题。录播八模块先取得本次具体授权，再测对应行为。

## 本地执行

先在隔离副本执行最相关的用例与导入/实例化冒烟。Qt 页面需要 offscreen QApplication，fake app 按页面实际依赖提供 work_dir、toast、show_page 等属性，禁止让真实 app 补全缺失状态。所有编辑部分完成后运行适用的完整离屏验证；后续改动影响结论时重跑相关检查。

基础命令按当前 shell 设置环境后在**隔离副本根目录**运行：

~~~powershell
python -m compileall -q src
$env:PYTHONPATH = 'src'
$env:QT_QPA_PLATFORM = 'offscreen'
python -m unittest discover -s tests
~~~

只允许测试写入隔离副本或本任务 `_smoking/` 子目录；包括编译缓存、导入初始化、日志、截图与导出。完整测试指本次实际存在且适用的测试集；`tests/` 为空、未运行用例或仅命令退出成功，不能写成完整回归通过。

## 数据与用例质量

- 临时文件优先放本任务 `_smoking/` 子目录，或在隔离副本中使用 TemporaryDirectory；不复制真实配置、下载目录、主播列表、数据库、凭据或浏览器 profile。
- 网络、时间、随机数、机器 GUID、外部进程在边界注入或固定。用事件、回调、可控时钟与有上限的等待判断异步结果，避免依赖固定 sleep。
- 用例单独运行、重复运行和不同顺序运行应得到同样结果；不共享可变全局状态，不 mock 被测对象本身。
- 断言可观察行为及异常路径：错误类别、用户提示、是否重试、是否写入。快照只用于稳定、可读输出，覆盖率不代替关键路径覆盖。
- 手动冒烟脚本、harness、临时数据、日志与过程截图统一放 `_smoking/`，不提交不推送；只有最终报告证据截图可放 `Progress/ui/<日期>/`。清理与复用按 [清理正文](references/test-cleanup.md)。

## 结果与收尾

报告应写明环境、用例/命令、结果、失败处理和未运行项；区分单测、离屏、真实 UI 与真实平台验收，不能相互替代。真实环境批准、快照和还原结果也必须如实记录。按清理正文处理本任务产物，再按总约定汇入唯一当日报告和本地提交；不触发自动推送或发布。

完成时逐项确认：测试范围符合改动层级；Bug 复现先失败后通过；边界与异常用例齐全；数据与进程隔离；未擅自关闭用户实例；未触碰真实凭据；清理未影响并行任务；未验证项明确标注。
