# 图片输出规范（兼容入口）

规范已合并至 [ui-visual-spec](../ui-visual-spec/SKILL.md)。先完整阅读该统一入口，再阅读[图片输出详细参考](../ui-visual-spec/references/generated-images.md)中本次输出对应的范围、共享实现、版式与验收章节。

屏幕 UI 与生成图片共享颜色语义，画布、字号、页头页脚分开适用；用户自定义封面、裁切、截图 / 抽帧、下载媒体和内部缓存图不强套报表模板，证书保留 A4 例外。本文件只兼容旧引用，不另设渲染实现、授权或验证流程。
