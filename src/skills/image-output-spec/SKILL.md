# 生成图片输出规范（Image Output Spec）

先阅读 [convention-skill](../convention-skill/SKILL.md) 与 [ui-visual-spec](../ui-visual-spec/SKILL.md)。涉及导出文件/路径/敏感数据时读 [security-baseline](../security-baseline/SKILL.md)；涉及图片渲染测试时读 [testing-quality-gates](../testing-quality-gates/SKILL.md)。

本 skill 只管 **程序生成并导出的图片**：账号对比 PNG、组图长图、资产预览拼贴、报表/图表图、封面默认模板、未来新增的导出图。屏幕上的 UI 样式仍以 `ui-visual-spec` 为准；两者共享颜色语义，但画布、字号、页头页脚规则不同。

## 适用与例外

**适用**

- `src/tracker/export_png.py`：网媒账号对比图 / 按组长图。
- `src/music_account/export_png.py`：音乐账号对比图 / 按组长图。
- `src/gui_qt/pages/asset.py` 的 `_export_preview_image`：资产预览拼贴图。
- `src/gui_qt/pages/cover_maker.py` 的**默认模板**导出。
- `src/toolbox/certificate_engine.py`：内部认证证书（固定版式，见「内部认证证书」一节）。
- 后续新增的报表图、统计图、分享图。

**例外（不强制套用本规范）**

- 用户在套版封面里自定义的字体/颜色/位置/底图：保留用户选择，只要求默认模板遵循本规范。
- `image_crop.py` 的裁切输出：保持原图像素与格式，不加品牌页头页脚。
- `editor.py` 的截图/抽帧：保持源画面，不加水印或重排。
- 下载的封面、头像、表情、媒体：不是程序生成，不重绘。
- `image_sorter` 缩略图、内部缓存图：不作为用户导出图。

## 唯一实现与设计令牌

1. 只允许一个共享渲染模块（目标：`src/toolbox/image_render.py` 或等价的 L5 渲染工具）提供：
   - 画布/边距/圆角/间距常量；
   - 字体加载与缓存；
   - 页头/页脚/卡片/表格/图表绘制函数；
   - 颜色 token 读取；
   - 文本换行、省略、混排 emoji、数字格式化。
2. 共享渲染模块只依赖 Pillow + 标准库，不依赖 PySide6；导出图在后台线程可安全生成。Qt 只用于屏幕预览。
3. 页面/业务模块不得自带第二套图片色板、字号表、页头页脚或数字格式；只传数据与少量布局选项。
4. `tracker/export_png.py` 与 `music_account/export_png.py` 目前是两份近似重复实现，迁移时先合并到共享渲染模块，再改样式。

- `src/tracker/export_png.py`、`src/music_account/export_png.py` 已改为薄适配层，统一调用共享渲染；宽度 1080。账号追踪默认 `theme="dark"` 的深色卡片仪表盘（`render_account_dashboard`），其他报表仍默认 brand-light。

## 画布与布局

| 项 | 标准 |
| --- | --- |
| 基准宽度 | **1080 px**（单账号、组图、预览图同宽；历史 860 px 图片迁移到 1080） |
| 最大高度 | 单张不超过 20000 px；超出按页拆分 |
| 页面边距 | 32 px |
| 卡片内边距 | 24 px |
| 区块间距 | 16 / 24 px |
| 卡片圆角 | 16 px；标签/胶囊 10 px |
| 表格行高 | 56 px；表头 48 px |
| 页头高度 | 约 150–180 px（含标题、副标题、来源） |
| 页脚高度 | 约 56 px |
| 多页 | 每页重复页头/页脚，页脚标 `第 x / y 页`；不在卡片中间断行 |

页面结构固定为：**页头（品牌 + 标题 + 副标题/日期/来源）→ 内容卡片 → 页脚（生成信息）**，不允许各模块自创顶部横幅或随机装饰。

### 内部认证证书（A4 例外）

内部认证证书是需要打印归档的正式凭证，**不套用 1080 px 报表画布**，由 `src/toolbox/certificate_engine.py` 单独实现，仍遵守「Pillow + 标准库、不依赖 PySide6、页面只传数据」的约束：

| 项 | 标准 |
| --- | --- |
| 画布 | 横版 A4 3508×2480 px，300 dpi |
| 页数 | 固定两页：证书页（文字）+ 图片页（作品图 / 水印样本） |
| 边距 | 页边距 150 px；双线外框（金 6 px / 浅金 2 px）+ 四角 L 形角线 |
| 配色 | 纸感米白 `#fcfaf4`、墨蓝 `#1f3350`、金 `#a9853f`；不跟随深浅主题 |
| 字体 | 标题华文中宋（`STZHONGS.TTF`），正文微软雅黑；标题字距 8–18 px |
| 图片 | 最多 6 张，按数量取 1/2/3/2×2/3×2 网格，`contain` 完整显示不裁切（水印署名不得被裁） |
| 图注 | 每张标注序号 + 文件名，单页最多 6 条 |
| 状态 | 有效不加标记；已终止 / 已作废 / 已续签在右上角加胶囊标签 + 页面中央淡斜水印 |
| 水印 | 作品图默认合成水印：按勾选内容取署名/认证号，斜向平铺（低透明度）+ 右下角白底标签（清晰可辨）；原图不修改，另存 `水印件/<认证号>_<作品>_已加水印_序号.png` |
| 命名 | `<内部认证号>_<作品标题>_内部认证证书_01.png` / `_02.png` 与同名 `.pdf` |

证书页固定信息顺序：主标题 → 证书/协议编号 → 授权作品 → 作品类型 → 授权方 / 主要设计人 / 协作设计人 / 被授权方 → 分发层级三级 → 授权用途摘要 → 授权期限 → 三方确认（授权方 / 被授权方 / 签发方代表，各带签名线与日期）+ 电子章 → 底部声明与页码。字体、框线与印章颜色只能在 `certificate_engine.py` 里改，页面不得自带第二套证书配色。

## 颜色令牌

导出图默认使用 **brand-light**；需要深色时显式传 `theme="dark"` 使用 **brand-dark**，禁止模块自己定义颜色。账号追踪仪表盘（网媒/音乐的单账号与按组图）默认使用 **brand-dark** 深色卡片样式，其他导出图仍默认 brand-light。取值与 `ui-visual-spec` 对齐：

| 语义 | brand-light | brand-dark | 用途 |
| --- | --- | --- | --- |
| 页面底 | `#f3f5f9` | `#151c29` | 画布背景 |
| 卡片 | `#ffffff` | `#1d2737` | 内容卡片/表格底 |
| 次级底 | `#f0f3f8` | `#243044` | 表头、斑马纹、标签底 |
| 正文 | `#263449` | `#dce5f3` | 标题、正文、数字 |
| 次要文字 | `#5f7089` | `#9caec5` | 副标题、页脚、轴标签 |
| 边框 | `#dce3ed` | `#303e52` | 分隔线、卡片边框 |
| 强调 | `#356bd6` | `#3f76c9` | 主数据、链接、重点标签 |
| 上涨/成功 | `#18754e` | `#7cd6af` | 涨、完成 |
| 下跌/错误 | `#b93842` | `#ff969f` | 跌、失败 |
| 警告 | `#99600c` | `#edc478` | 限制、提示 |
| 无变化 | `#5f7089` | `#9caec5` | 持平/未知 |

规则：

1. 正文/数字不得使用低对比灰色；上涨/下跌必须同时有箭头或文字，不能只靠颜色。
2. 图表最多 5 个语义色；禁止彩虹色、随机色、每个模块一套色。平台身份色例外：账号追踪卡片可按固定平台色表使用（B站 `#fb7299`、抖音 `#fe2c55`、微博 `#ff8200`、快手 `#ff5000`、小红书 `#ff2442`、网易云 `#e23a3a`、QQ音乐 `#31c27c`、酷狗 `#2ea7ff`、酷我 `#ffb020`、5sing `#ff7a45`；未知平台回退 `#3f76c9`），只用于平台识别，不得用于涨跌语义。
3. 不在图片里使用页面级 QSS/主题色；共享 token 是唯一来源。
4. 用户自定义封面不套用本表；默认模板遵循。

### 账号追踪仪表盘

- 画布 1080 px；页头居中显示应用名、主标题与副标题；页脚固定。
- 双列平台卡片（单账号时改用整宽横向指标卡）：左侧平台色条、平台+账号标题、首项大号数字、其余指标 2 行、底部采集时间。
- 多账号导出在卡片下方增加整宽「粉丝量合计」卡；合计数字与涨跌同一基线居中。
- 每张卡片最多 3 个指标，指标缺失显示 `—`，不输出空白卡。

## 字体与字号

| 元素 | 字号 | 字重 |
| --- | --- | --- |
| 主标题 | 32 px | Bold |
| 区块标题 | 22 px | Bold |
| 统计数字 | 28 px | Bold |
| 表头 | 15 px | Bold |
| 正文/表格 | 16 px | Regular |
| 副标题/页脚/轴标签 | 13 px | Regular |
| 最小字号 | 13 px | — |

1. 中文字体优先 `Microsoft YaHei`，回退 `SimHei` / `SimSun`；数字可用 `Segoe UI`；emoji 用 `Segoe UI Emoji`。
2. 行高 1.45–1.5；标题与正文之间留 8–12 px。
3. 字体加载失败必须有回退，不允许整张图空白或抛异常。
4. 文本超宽用省略号或换行，禁止裁掉半个字/溢出卡片。

## 页头与页脚

**页头**

- 左侧：品牌标记 + 应用名（13 px，次要色），可省略图形标记。
- 主标题：`{对象/报表名}`（32 px Bold）。
- 副标题：平台、账号、日期范围或数据来源（13–16 px，次要色）。
- 不在页头放广告、随机口号、二维码或联系方式。

**页脚**

- 固定格式：`由 {APP_NAME} 生成 · {YYYY-MM-DD HH:MM} · 数据来源：{source}`。
- 多页追加 `第 x / y 页`。
- 页脚不得出现 Cookie/Token、完整文件路径、内部 ID、账号密码等敏感信息。
- 用户要求的署名/水印只能加在页脚，不遮挡数据。

## 数据呈现

1. 数字：`1.2万` / `1.2亿`、千分位、百分比 1 位小数；日期 `YYYY-MM-DD`；时间 `HH:MM`；时区固定 `Asia/Shanghai`。
2. 涨跌：`↑ +123`（成功色）/ `↓ -123`（错误色）/ `—`（无变化）；颜色 + 箭头双重表达。
3. 表格：表头加粗、数字右对齐、文本左对齐；斑马纹用次级底；长文本省略并保留 tooltip/明细。
4. 图表：标题在卡片内；图例在上方；坐标轴 13 px 次要色；网格线用边框色；标签不重叠。
5. 空数据：居中显示“暂无数据”，不导出空白图；缺失图片用统一占位块，不抛异常。
6. 长列表：按区块分页/分栏；同一内容不跨页断裂；每页重复表头。
7. 排序稳定：同一数据每次导出顺序一致；不随机打乱。

## 格式与文件命名

| 项 | 标准 |
| --- | --- |
| 图表/预览 | PNG（无损、sRGB、不透明背景） |
| 封面/照片 | JPG，质量 92–95；用户可选 PNG |
| WebP | 只有用户明确选择时才用 |
| DPI | 144（屏幕分享足够；不写 72/96 混乱值） |
| 元数据 | 生成图不写 EXIF/路径/作者；不携带源图 EXIF |
| 命名 | `{module}_{object}_{YYYYMMDD_HHMMSS}.{ext}`，如 `tracker_封茗囧菌_20261117_201500.png` |
| 清洗 | 去掉 `\/:*?"<>|`、控制字符、首尾空格；最长 120 字符；重名追加 `_2` |
| 写入 | 先写临时文件，成功后原子替换；失败不留半张图 |

## 确定性与技术约束

1. 同一输入 + 同一主题 → 除时间戳外输出一致；不随机颜色、不随机布局、不依赖当前 locale。
2. 渲染只使用本地字节/已下载图片；渲染阶段不发网络请求。
3. 字体、颜色、尺寸 token 缓存；字体按 `(family, size, bold)` 缓存。
4. 图片解码限制像素/大小；损坏图片用占位块；大图/长图分块处理，避免一次性占用过多内存。
5. 导出图在后台线程用 Pillow 生成；不得在工作线程创建/操作 `QPixmap`。Qt 只在 GUI 线程做预览。
6. 生成图不包含 Cookie/Token/Authorization、完整路径、内部 ID；必要时脱敏。
7. 图片写入遵守 `security-baseline` 的路径/原子写/权限规则。

## 可读性

1. 正文对比度 ≥ 4.5:1，大字/标题 ≥ 3:1（按 `ui-visual-spec` 的实测基线）。
2. 最小字号 13 px；不把必读数据放在低对比的次要色上。
3. 图片/底图上放文字必须加纯色遮罩或卡片底，不能直接压在复杂画面上。
4. 不用纯颜色区分状态；同时给箭头/文字/图标。

## 测试与验收

1. 为共享渲染模块建立 golden/snapshot 测试：固定样例数据 → 断言尺寸、元素位置、颜色 token、文本不溢出。
2. 覆盖场景：空数据、超长标题、超多行、缺失图片、损坏图片、浅色/深色、多页拆分。
3. 手动验收：至少检查 1 张单图 + 1 张长图 + 1 张空数据图；确认页头/页脚/数字格式一致。
4. 不使用真实账号数据/截图做测试；用虚构昵称、虚构数字、占位图。
5. 迁移前后对比截图存 `Progress/ui/<日期>/`，确认只是统一样式而非丢数据。

## 迁移顺序

1. **抽取共享渲染模块与 token**：颜色、字体、画布、页头页脚、数字格式化、文本换行。
2. **合并账号追踪两份实现**：`tracker/export_png.py` 与 `music_account/export_png.py` 目前宽度 860、深色、布局近似重复；先合并，再统一到 1080 与 brand-light/brand-dark。
3. **资产预览图**：`asset.py:_export_preview_image` 目前是紫色渐变 banner + 自有配色；改为共享页头/卡片/页脚。
4. **封面默认模板**：`cover_maker.py` 的默认模板套用 token；用户自定义模板/字体/颜色保持自由。
5. **后续报表/图表**：新图直接使用共享渲染模块，不再新建私有画布。
6. 迁移不改变数据内容、排序和统计口径；只统一视觉。涉及录播八模块的导出图时先核对 `recording-toolbox-core` 授权。

## 与其他 skill 的关系

- `ui-visual-spec`：屏幕 UI 的颜色/字号/图标；本 skill 是导出图的画布与版式。
- `layering-contract`：共享渲染放 L5/L3，页面只传数据；渲染模块不依赖 Qt。
- `security-baseline`：图片中的敏感信息、路径、原子写、解码限制。
- `testing-quality-gates`：golden/snapshot 与空/长/坏图测试。
- `tracker` / `music_account` / `asset` / `cover_maker`：迁移对象；用户自定义内容例外。
