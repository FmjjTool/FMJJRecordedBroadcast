## 工作台

- 顶部只保留日期与「刷新数据」；没有页面标题和说明行。
- 统计卡：平台内容、微博超话帖子、腾讯文档行、资源文件、文档浏览量/成员数/已查看人数、追踪账号，以及站点访客/会话/浏览量/在线。
- 站点访问统计读取 `download/站点监控数据/访问统计.db` 的最近一次快照（优先当前统计口径）；点击站点卡展开「站点访问」抽屉。
- 抽屉内可填写/保存 mandisa.wiki 后台（`/admin`）密码、选择统计口径、点「采集今日」；也可选历史日期「采集该日」，或「补采最近 7 天」（站点只保留近 90 天明细，单日失败会继续补后续日期）。下方同时列出最近 14 条每日快照与最近 50 次采集尝试（成功/失败原因）。密码只加密存本机，采集是唯一联网动作，页面加载本身不联网。
- 每日自动采集由「任务」页的「站点访问统计」管理（Windows 任务 `FengMingWebwikiAnalytics`，默认 09:10 / 13:00 / 17:00 三个时间点）；每个时间点先检查当天是否已有快照，有则跳过，没有才采集，失败可由后续时间点补采。任务页「设置」里可改主时间和两个补采时间（留空不启用）；抽屉只显示下次运行时间，不内嵌计划设置。
- 数据刷新在后台汇总本地数据库，不触发采集或腾讯文档写入。

## 信息获取

- 批量输入（一行一个）：账号主页链接（B站空间/抖音/微博/快手/小红书）→ 添加为账号；作品链接、分享文案、纯 BV 号 → 解析并存入「已获取」，同时写日志。
- 获取最新：勾选账号后批量抓取，可暂停/取消；结果进入「已获取」与增量数据库。
- 增量模式：只入库新内容（数据库去重）。
- 获取后自动下载：获取→保存→下载一次完成；画质/线程数沿用「已获取」页全局设置。
- 限流：每平台累计抓到设定条数后冷却，防止触发风控。
- 定时获取：软件运行期间按间隔抓取全部账号（不是 Windows 计划任务）。
- 日期段：日历选择发布时间范围，范围持久保存。
- 双向同步：本页账号与「视频账号追踪」互相同步，已存在的跳过。
- 设置：账号分组、账号编辑（名称/URL/分组/排序）。
- 登录态由软件统一管理，抓取时自动套用。

## 腾讯文档监控

- 登录：登录态由软件统一管理，本页不保存登录信息。
- 立即采集：采集全部文档浏览量/成员数，并全量翻页拉取「已查看」浏览人明细（昵称/来源/最近浏览时间，写入报表「浏览人」页签，按 UID 增量去重）；每次追加一行并相对上次计算增量；不包含表格同步。
- 文档管理：添加/编辑/删除任意腾讯文档，可生成页面诊断包。
- 表格同步：纯 HTTP 同步智能表格，版本没变化自动跳过；按记录比对新增/修改/删除；每次生成 Excel 到 `表格数据/`。普通表格、图表页、文章页会自动跳过。
- 中间层同步：比对本地「已获取」+增量库与当前表格（链接/平台 ID/标题+日期三级匹配），列出未上传条目；支持复制 TSV、按行复制、图片检测与图片复制；默认不自动写入。
- 线下活动 / 周边图鉴：目标表选这两张时，优先读取票务解析（`download/票务演出/*/event.json`）和购物解析（`download/淘宝商品/*/item.json`）在获取详情时自动落下的结构化数据，按日期、城市或名称与本地表格快照比对，列出待补行并检测本地图片；没有结构化数据时回退到旧的本地动态识别。只读预览，可复制 TSV 后手工粘贴。这两张表不在写回白名单，不提供上传按钮。
- 完整歌曲：目标表选「完整歌曲」时进入检索模式——输入歌名，五平台（QQ/网易云/酷狗/酷我/5sing）并行检索，生成一行与表头完全一致的数据，五个平台链接分别填入同名链接列；复制后从表格第一列粘贴。该模式不读取、不写入腾讯表格。
- 表格图片：同步后图片字段增量下载到 `图片/`；可手动「采集图片」补采。
- 修订记录：纯 HTTP 增量翻页，遇到上次已拉取且一致的记录停止；存 `修订记录/`（JSON + Excel），支持全量重拉。
- 成员名单：游标翻页拉取成员，显示昵称/权限/账号来源/UID，按 UID 去重存 `成员名单/`。需要文档管理权限。
- 上传：官方动态/直播记录可勾选上传（记录 + 本地图片），完整歌曲仅新增、不改不删；已存在自动跳过。线下活动/周边图鉴不开放上传。
- 内容 Tab：表格文档显示表格同步，文档/AI 文档/幻灯片切换正文预览；正文抓取必须手动点「抓取正文」；AI 文档抓取全部子页面，支持 Markdown/TXT 导出；正文逐页写 `pages.db`。
- 定时采集统一在「任务」页设置（任务名 `FengMingTCDocMonitor`）。
- 数据位置：`download/腾讯文档数据/`（`tcdoc.db`、`tables.db`、`pages.db`、`revisions.db`、`members.db` 及报表、表格数据、正文存档、修订记录、成员名单、图片、日志）。
- Excel 正被 WPS/Office 占用时写入会失败，采集前先关闭。

## 本地资料站

- 把 `webwiki`（前端）与 `webwiki-api`（后端/数据重建）拉到本机，读取「腾讯文档监控 → 表格同步」的本地 `tables.db` 重建站点库后启动，浏览器访问 `http://127.0.0.1:站点端口/`。
- 项目为私有仓库：未登录时「拉取代码」「一键部署」锁定；登录状态由软件统一管理。
- 每次重建全量读取最新本地数据，不重新请求腾讯文档。
- 已下载的本地图片优先使用（封面直接读本地文件并生成缩略图），缺失才回退图床缓存。
- 只监听 127.0.0.1；端口被占用时在「目录与端口」更换。
- 站点访问监控读取线上站点后台统计，密码加密存 `config/webwiki_analytics.json`，只掩码显示；「采集今日」写 `download/站点监控数据/访问统计.db`，同日覆盖；历史表显示最近 14 条。
- 每日自动采集的 Windows 计划任务为 `FengMingWebwikiAnalytics`，统一在「任务」页安装/修改；失败写 `采集日志.log`。
- 站点默认只保留近 90 天明细；后台密码错 5 次锁 15 分钟。

## 资产管理

- 三个 Tab：已获取资源、数据库浏览、本地资源。
- 已获取资源：先显示数据库清单，再后台核对文件；首次需建索引，可刷新重核。支持平台/文件夹筛选、状态筛选、关键词搜索、时间排序、分页；「文件夹」下拉按一次导出产物聚合条目；单击查看详情，双击缩略图播放视频，右键打开 MD/媒体文件。
- 下载：单条重新下载或勾选批量下载，已完整自动跳过，大文件显示字节进度、可取消。
- 删除：可选删除 json/md/xlsx/_raw/媒体文件。
- 数据库浏览：直查已获取数据库，支持筛选/排序/勾选导出，双击看详情查看内容，右键打开链接/筛选作者。
- 本地资源：选择文件夹扫描图片/视频/音频（逐级读取全部子文件夹），按文件夹分组，可下钻与锁定根目录；单击预览，切页自动扫描，缩略图懒加载，支持扫描上限与增量索引。
- 备份：右上角「备份」导出全部资产为 zip/文件夹，或导入恢复（文件不覆盖、数据库按去重键合并）。
- 详情窗可导出紫色渐变预览拼贴图。

## B站资源

- B站资源页聚合五个入口：表情包、直播表情、装扮/收藏集、收藏集活动、空间。
- 表情包：浏览/搜索全部表情包，按 ID 下载普通或装扮表情，自动识别并跳转收藏集；表情类接口需要 B站登录。
- 直播表情：输入房间号加载直播间专属/UP主大表情/通用表情，附带主播头像、封面、背景图、关键帧。
- 装扮/收藏集：关键词搜索或按 item_id 查看详情（空间背景/粉丝牌/评论背景/表情包/加载动画/进度条/皮肤/点赞动画）；收藏集 ID 自动跳活动。
- 收藏集活动：输入 act_id 加载视觉、勋章、卡牌图与视频。
- 空间：输入 UID 查看公开信息（关注/粉丝/获赞/签名/直播房间），可下载头像/头像框/背景图/投稿封面/充电表情/收藏集封面；游客接口，无需登录。
- 表情类接口需要 B站登录，其余为游客接口；表情包可选下载格式，每个区域独立下载进度；文件列表勾选后可批量下载。
- 综合搜索与视频信息统一由「信息获取」页处理。

## B站小店

- 粘贴 b23.tv 小店短链、mall.bilibili.com 小店链接、space.bilibili.com 主页或纯 UID → 解析。
- 获取小店名/头像/粉丝数/商品数，以及每件商品 ID/标题/价格/封面/跳转链/来源类型。
- 保存到 `download/B站小店/<小店名>_<UID>/`（小店信息 JSON；商品列表可导出 Excel）。
- 游客可用，无需登录。

## 抖音指数

- 需要抖音登录（创作者中心接口）。
- 搜索达人名称/抖音号，候选列表两步确认。
- 核心指标：新增点赞/净增粉丝/新增分享/新增评论/新增作品，昨日/近7天/近15天/近30天 + 环比 + 涨粉里程碑。
- 稿均指标、每日趋势、达人视频（双击打开视频页）、粉丝分析（地域/年龄/性别/手机/兴趣，含占比与 TGI）、相似达人榜。
-「统计范围」控制视频列表与视频指数时间范围。
- 保存到 `download/抖音指数/<达人名>/`（时间戳 JSON + latest.json）。

## 抖音商品

- 把商品分享文案整段粘贴（含 v.douyin.com 短链），一行一条，可批量。
- 获取商品标题/ID/价格区间/销量/主图/店铺 ID/带货达人 ID/分享来源。
- 拿不到店铺名称、SKU 库存、详情图；需到抖音 App 打开。
- 保存到 `download/抖音商品/<标题>_<商品ID>/`，整批列表可导出 Excel。
- 无需登录。

## 粉丝群查询

- 抖音：主页链接 → 全部公开粉丝群（含 VIP 群），需要登录态。
- 微博：主页链接 → 全部公开粉丝群，含群号/人数/上限。
- B站：输入 UP 主 UID → 当前账号已加入的应援团；未加入的群查不到。
- 每次查询存快照并与上次对比，新群标「新」。
- 群头像自动下载到 `头像/`，表格首列缩略图，双击看原图，可强制刷新。
- 保存到 `download/粉丝群/<平台>/<UID>/`（头像 + 快照 JSON + 最新 JSON + Excel）。

## 微博超话

- 输入超话链接（`weibo.com/p/100808...`）或 100808 开头的 ID → 解析超话。
- 从头部动态读取频道 flowId，可单独勾选并设置最大翻页数。
- 游标翻页，跨频道按帖子 ID 去重；显示当前页数与累计条数。
- 导出汇总、频道明细、月度趋势、作者榜、设备/地区/星期/时段、全局 TOP50。
- 每次采集写入 `config/weibo_chaohua.db`（帖子去重 + 互动指标快照），历史分析查看累计/新增/点赞增长。
- 保存到 `download/微博超话/<超话名>超话_数据采集_时间戳.xlsx`。
- 已知边界：阅读量/影响力/榜单分数网页端不存在；帖子数/粉丝数只有缩略文案；「最新」频道深翻会混入零星老帖。

## 票务解析

- 三平台：大麦 / 秀动 / B站会员购。可粘贴平台链接或输入艺人/演出/场馆关键词；留空回车默认搜「封茗囧菌」，三平台同时搜索（大麦走浏览器约 20 秒）。
- 查询范围可选「近期（在售）」或「所有（含历史）」：近期会过滤已结束项目，只留今天及以后的场次；所有包含历史演出，关键词查询还会先按关键词匹配艺人，再走大麦/秀动艺人页通道补全历史场次。粘贴链接解析同样受范围影响；B站会员购没有艺人页通道，只在「所有」下保留其关键词结果中的历史项目。
- 勾选后获取演出详情并下载图片（封面/海报/宣传图/座位图/嘉宾头像/场馆图），存 `download/票务演出/`。
- 导出列表输出全量 JSON，未拉详情的会自动逐场拉取并下载图片。
- 单件失败原地重试，不中断整批。

## 购物解析

- 淘宝店铺：粘贴店铺链接（店铺信息游客可获取，商品列表需登录）；留空回车用默认店铺。
- 商品：粘贴 `item.taobao.com/item.htm?id=xxx`（详情需登录）。
- 勾选商品后获取详情，下载主图到 `download/淘宝商品/{标题}_{商品ID}_{时间}/`，Excel 同目录导出。
- 可导出商品 JSON；未拉详情的自动补齐。
- 单件失败原地重试；详情缓存复用。

## 公众号文章

- 输入公众号文章链接（每行一个），点「解析并导出」抓取正文与图片。
- 输出 HTML（图片内嵌）、PDF（A4）、Word（docx）、图片文本 MD（Markdown + 图片文件夹）。
- 导出位置可选默认（统一导出目录/公众号文章）或固定位置；按公众号名/文章名建文件夹。
- 仅支持 `mp.weixin.qq.com` 图文；付费/加密/已删除文章无法解析；批量解析自动限速。

## 音乐下载

- 功能：歌曲搜索、单曲解析、歌单解析、专辑解析（仅网易云）。
- 自动换源（默认开启）：下载失败或只拿到试听时，按酷我 → 酷狗 → 酷狗概念版 → 网易云 搜索同名曲继续下载。
- 平台：网易云全音质（VIP 需登录）；酷狗免费 128k（VIP 游客不可下）；酷我免费 320k，VIP 仅试听；5sing 原唱/翻唱/伴奏可下；QQ 官方直链关闭，靠自动换源。
- 酷狗概念版扫码登录后可下 128k/320k/FLAC，可领 VIP。
- 下载目录：默认 `download/歌曲文件` 或固定位置（自选文件夹）。

## 歌词转换

- 支持 LRC / KRC(酷狗) / KSC(酷我) / QRC(QQ) / TRC·ELRC 转换为纯文字 TXT、LRC、SRT、ASS、KSC 逐字。
- 输入方式：选择文件、选择文件夹批量、直接粘贴文本（按 LRC 处理）；可指定工作目录。
- KRC 工具支持 KRC（加密）↔ KRCD（明文）双向转换。
- 回车快捷：第一次扫描/选择，第二次开始转换。

## 图片裁切

- 导入图片/文件夹（拖入或按钮），支持 PNG/JPG/JPEG/BMP/WebP/GIF（首帧）。
- 四边参考线裁切，拖动时显示像素放大镜；精细模式 20px→1px，Shift 临时加速。
- 边界吸附与自动对齐，可裁黑边/留白；支持精确输入上下左右像素。
- 单张导出或批量导出到 `download/图片裁切/`，文件名加 `_cropped`；支持撤销/重做。

## 交互重命名

- 三栏工作流：左栏日期文件夹→文件列表；中栏直播账户（单选）+ 直播类型（多选，数字键 1-9）；右栏视频信息、弹幕版本、平台、标题模式、截图与新文件名预览。
- Enter 确认重命名，Esc 跳过当前视频。
- 可写入版权属性（ffmpeg 写元数据）。
- 参数设置 Tab 维护账户/类型/平台列表、视频后缀、匹配阈值、附加信息。

## 批量重命名

- 加文件/文件夹（含子文件夹、支持拖入），规则实时预览，确认后执行。
- 八类规则：整体、替换（文本/正则）、添加、删除、序号、模板变量、文本模式、选项；多规则叠加。
- 时间修改标签可批量改创建/修改/访问时间，与改名互不影响。
- 支持撤销上次改名；同名冲突自动加序号。

## 套版封面制作

- 随机底图 + 标题/日期/备注三段文字，快速产出静态封面。
- 底图：递归扫描底图文件夹随机抽取；可临时上传替换；适配模式支持裁剪填充或完整包含。
- 文字：三组字段独立字体/字号/颜色/加粗/斜体/对齐；同步样式可按项同步。
- 定位：预览区拖动文字块；重置位置恢复垂直居中；Y 轴整体微调。
- 分辨率：按画布比例存储，预览 960x540，导出可切 1080p/2K/4K；超长文字自动换行并缩小。
- 导出 PNG 无损或 JPG（质量 60~100）到 `download/套版封面/`。
- 模板存 `config/cover_templates/`，保存样式/位置比例与底图记忆，不保存文字内容。
- 下拉/滑条/数字框不响应滚轮；字体可直接输入；颜色使用内置主题色板。

## 弹幕姬

- B站/抖音直播弹幕实时采集与回放，共用一套框架。
- 连接：输入房间号或直播间链接（含 b23.tv），留空填默认房号；按钮连接后变为断开。
- 实时数据：弹幕、礼物、SC/上舰（B站）、进场、关注、点赞；主播信息实时刷新。
- 两种模式：仅弹幕 / 回放（导入回放包重演整场）。
- 录制：视频录制统一在「直播录制」二级窗口，支持开播自动录制、断流重连、分段、录满停止。
- 轮询等开播：未开播按间隔重试，开播自动接入，下播后自动恢复轮询。
- 搜索/筛选：弹幕关键字、按人筛选，事件区可独立筛选。
- 保存与回放：保存弹幕/统计；导出/导入/合并回放包；可自动导出。
- 弹幕实时落盘到 `导出目录/弹幕文件/实时记录/房间号_日期.jsonl`；游客优先，不影响登录态。

## 直播录制

- 多平台：抖音 / B站 / 快手 / 微博 / 小红书 / 网易云，底部切换，列表与录制任务互不影响。
- 添加主播：房间号或直播间链接；「是否监控」+「开启监控录制」实现开播自动录制。
- 录制设置：输出格式、录制方式、分段、录满停止、保存目录、断流重连、标题过滤、弹幕录制、封面保存。
- 独立设置：单个主播的录制内容/清晰度/分段/录满/提醒/备注。
- 推送：企业微信/钉钉/飞书/自定义 WebHook 按事件推送。
- 工具 → FLV 修复：修复截断、时间戳错乱、断流拼接花屏。
- 录制文件：`<保存目录>/<主播名>/<主播名>_<日期时间>.ts`（抖音及新增平台）/ `.flv`（B站）。
- 快手可游客取流；微博/小红书/网易云使用无头浏览器嗅探，已登录账号自动带登录态。

## 全局设置与后台运行

- 「全局设置 → 后台模式」提供「启用后台模式（关闭主窗口时隐藏到系统托盘）」开关：勾选后点关闭只隐藏窗口，采集、导出、直播录制等任务继续运行，并保留托盘图标；取消勾选即取消后台，托盘图标一并收起，点关闭直接退出软件。
- 托盘图标单击或双击恢复主窗口；右键菜单提供「显示主界面」与「退出」。首次隐藏会在托盘气泡提示恢复与退出方式。
- 「全局设置 → 关于」提供 GitHub 仓库与 GPL-3.0 开源许可证入口，并标注本软件以 GPL-3.0（GNU General Public License v3.0）协议开源。
- 「全局设置 → 检测依赖与其他强依赖」逐项显示 ffmpeg、ffprobe、PySide6、requests、Pillow、BeautifulSoup4、lxml、httpx、openpyxl、mutagen、websocket-client、playwright、抖音签名环境（node）的状态、版本与用途；缺失项标红。
- 可选依赖显示「可选」而非「缺失」、不计入缺失数量：Git（本地资料站拉代码）、Node.js（本地资料站前端构建，需 node + npm 同时在 PATH，内置 node 无 npm），点「下载」跳官方下载页，装完需加入系统 PATH。
- 全软件的依赖安装入口统一在本卡片（约定 11）；功能页只提示所需依赖，不再单独提供安装按钮。
- 缺失项修复：「安装」按 pip 安装 Python 包（仅源码运行态；打包后的 exe 里改为「未内置，请重装软件」提示）；FFmpeg / FFprobe 提供「一键下载」与「教程」。
- FFmpeg 一键下载：从 ffmpeg.org 指向的 Windows 官方构建站（gyan.dev）下载 release-essentials 包（约 110MB），只解出 ffmpeg.exe / ffprobe.exe 放到 `%LOCALAPPDATA%\FengMingToolbox\ffmpeg\bin`，并自动写入「FFmpeg 位置」；重装或再次点击会直接复用已下载文件。下载失败时按「教程」手动安装。
- FFmpeg 教程：内置说明一键安装与手动安装两种方式（下载页 → 解压 bin → 回填路径，或加入系统 PATH），并提供「打开官方下载页」按钮。定位优先级为 系统 PATH → 程序目录自带（根目录 / bin / ffmpeg\bin）→ 页面上方指定的位置。
