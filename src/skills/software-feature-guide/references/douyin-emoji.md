# 抖音表情

-   入口：侧栏「内容采集 → 采集工具」第 4 个页签「抖音表情」（`src/gui_qt/pages/douyin_emoji_page.py`）。只做一件事：按直播间 / 账号拉全「会员表情栏」并导出。与弹幕姬完全独立（不读弹幕包、不跟随弹幕姬连接、不要求先连接直播间）。
-   **账号来源**：顶部下拉列出「账号与登录 → 账号配置」里已存的抖音直播间（直播录制列表 / 抖音房间缓存 / 账号获取列表 / 最近连接），选中即用；也可直接填直播间号、19 位房间长号或 `live.douyin.com` 链接。
-   **会员表情栏（一键拉全）**：房间进房接口 `webcast/privilege/subscribe/info/`（先确定 `room_id`+`anchor_id`）本来就返回 `emoji_list`，前端表情面板用的就是它，所以不用等有人发表情——点「一键拉取全部」即可拿到全部会员表情（实测 48 个，PNG 直链）。**需要抖音登录态**（统一 账号与登录），未登录返回 `status_code=20003`（User doesn't login）。开播中、已结束的直播间都能拉：主播 ID 依次兜底 19 位长号走 `webcast/room/reflow/info` → `webcast/room/web/enter`（开播时最稳，本机偶发 200 空包）→ 直播间页面 SSR（未开播/已结束页面仍带 `roomId` + `anchor.id_str`）；接口 `room_id` 传 0 也能取到主播的会员表情。
-   按 URL 去重：只保留路径（对象 key + `~tplv-` 图床样式），忽略 `lf3/lf5/lf6`、`p3/p11` 等 CDN 域名与签名参数——同一张表情会被抖音换域名重复下发，域名不同也算同一张；不同对象 key 才各自保留；网格预览，勾选后可全选 / 全不选 / 清空，底部显示导出进度。
-   导出目录固定跟随全局统一导出目录的 `抖音表情包` 子文件夹（本页不放开输出目录选择）；保留原格式（webp/gif/png），文件名取表情名（接口没给名字时用资源 ID），同名自动加 `_2`。
-   另：抖音全站公开表情 214 个走 `aweme/v1/web/emoji/list`（游客可用），当前尚未接入本页。
