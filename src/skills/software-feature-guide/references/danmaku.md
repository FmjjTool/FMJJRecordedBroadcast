# 弹幕姬

-   入口：侧栏「直播录制」→ 页面工具栏「弹幕姬」按钮（弹幕页顶部不再是页签），打开独立窗口，里面按平台分「抖音弹幕 / B站弹幕」两个页签；录制页「工具 → 弹幕姬…」同样可开。窗口居中显示、可自由拖动，关闭只停弹幕渲染/回放，不影响正在进行的录制。
-   B站/抖音直播弹幕实时采集与回放，共用一套框架。
-   连接：输入房间号或直播间链接（含 [b23.tv](http://b23.tv)），留空填默认房号；按钮连接后变为断开。
-   实时数据：弹幕、礼物、SC/上舰（B站）、进场、关注、点赞；主播信息实时刷新。
-   两种模式：仅弹幕 / 回放（导入回放包重演整场）。
-   录制：视频录制统一在同一页的「直播录制」页签，支持开播自动录制、断流重连、分段、录满停止。
-   轮询等开播：未开播按间隔重试，开播自动接入，下播后自动恢复轮询。
-   搜索/筛选：弹幕关键字、按人筛选，事件区可独立筛选。
-   保存与回放：工具栏保留保存弹幕、渲染当前弹幕与保存统计；「更多」按顺序提供导出回放包、导入回放包、合并回放包、转弹幕机 TXT；自动导出规则不变。聊天与事件区的标题、筛选分行显示，礼物表格的列宽工具有独立底行；回放的播放进度与时间/倍速分两行，适应窄窗口。
-   转弹幕机 TXT：工具栏「更多 → 转弹幕机 TXT」可多选 `.jsonl`（抖音/录播姬）或 `.xml`（B站）弹幕文件，批量输出到 `导出目录/弹幕文件`；每行 `HH:mm:ss.SSS|[昵称]：内容`，最早一条对齐 `00:00:00.000`，只含聊天/表情弹幕，重名自动加序号、不覆盖旧文件。
-   弹幕实时落盘到 `导出目录/弹幕文件/实时记录/房间号_日期.jsonl`；游客优先，不影响登录态。
