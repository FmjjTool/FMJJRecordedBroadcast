# 微博超话

-   输入超话链接（`weibo.com/p/100808...`）或 100808 开头的 ID → 解析超话。
-   从头部动态读取频道 flowId，可单独勾选并设置最大翻页数。
-   游标翻页，跨频道按帖子 ID 去重；显示当前页数与累计条数。
-   导出汇总、频道明细、月度趋势、作者榜、设备/地区/星期/时段、全局 TOP50。
-   每次采集写入 `config/weibo_chaohua.db`（帖子去重 + 互动指标快照），历史分析查看累计/新增/点赞增长。
-   保存到 `download/微博超话/<超话名>超话_数据采集_时间戳.xlsx`。
-   已知边界：阅读量/影响力/榜单分数网页端不存在；帖子数/粉丝数只有缩略文案；「最新」频道深翻会混入零星老帖。
