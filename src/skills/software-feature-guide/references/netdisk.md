# 网络库

-   两个 Tab：网盘备份（默认）、网盘下载；登录状态由统一管理入口负责，本页不保存凭据。网盘备份是本地目录增量上传业务，不属于全局设置中的配置与资产备份恢复。
-   网盘备份：顶部双行工具条（第一行：立即备份 / 停止 / 新增备份目录 + 上传并发 2/3/4 路下拉；第二行：24px 进度条 + 「上传中 · 文件名」状态，窄窗口下文件名仍有完整宽度）；左侧「备份目录」用三行卡片展示（云端目标 + 后端标签 / 本地目录 / 统计与上次结果，失败结果标红，长路径中间省略、悬停看完整值），右侧「本次运行日志」；多组映射逐条启用 / 编辑 / 清空同步记录 / 删除；后端可选夸克 / 百度 / 移动云盘 / 115（115 先试秒传，未命中走阿里云 OSS 直传，单文件 5 GB 上限）；并发分片对夸克 / 百度生效，保留断点续传与百度 d→c→c2→c3 节点回退；移动云盘固定顺序分片（EOS 要求按序号上传，乱序报 InvalidPartOrder），115 单次直传，均不受此项影响；「立即备份」与定时任务同一条引擎（`toolbox/quark/backup.py`）；定时时间到「任务」页修改。
-   网盘下载：工具条三行（网盘 / 上一级 / 面包屑 / 刷新；保存到 + 选择 + 下载后自动解压；下载选中 / 下载本文件夹 / 分享选中 / 停止 + 进度条 + 状态）；网盘下拉含夸克 / 百度 / 移动云盘 / 115（115 用 `webapi.115.com`，根目录 cid 为 `0`，直链按 pickcode 申请且与 UA 绑定）；「全选」与项数放在「云端文件」卡片标题行，文件夹行带文件夹图标、名称列加长省略；浏览云端目录（双击进入、上一级、刷新），列目录按分页流式返回，首个分页到达即显示、后续分页在后台继续拉取并按当前排序插入，切换目录或网盘会取消旧加载；勾选文件或「下载本文件夹」递归下载；本地保存目录可选；单线程 + Range 断点续传，同名同大小自动跳过，直链过期自动重新申请；可勾选下载完成后用内置 7-Zip 解压 rar / 7z / zip；进度条显示当前文件与速度，可停止。
-   旧地址 `quark_download`（原「网盘下载」）与 `quark_backup`（原「夸克网盘备份」）都指向本页；定时任务中心的网盘备份来源显示为 `netdisk`。`backup_center` 仍兼容到全局设置。
-   本页不复制业务逻辑，下载 / 备份分别调用 `toolbox/quark/download.py` 与 `toolbox/quark/backup.py`。
