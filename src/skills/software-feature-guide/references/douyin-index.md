# 抖音指数

-   入口：侧栏「账户追踪 → 抖音指数」（原「内容采集 → 信息工具」页签）。
-   需要抖音登录（创作者中心接口）。
-   搜索达人名称/抖音号，在候选列表选择目标并点「确认并抓取」（或双击目标）后立即开始抓取，无需再点工具栏按钮；选择框会提前说明快照保存与已有资产回写范围，取消选择不启动任务。
-   核心指标：新增点赞/净增粉丝/新增分享/新增评论/新增作品，昨日/近7天/近15天/近30天 + 环比 + 涨粉里程碑。
-   稿均指标、每日趋势、达人视频（双击打开视频页）、粉丝分析（地域/年龄/性别/手机/兴趣，含占比与 TGI）、相似达人榜。  
    \-「统计范围」控制视频列表与视频指数时间范围。
-   保存到 `download/抖音指数/<达人名>/`（时间戳 JSON + latest.json）。
-   「抓取并回写」：确认后先保存完整快照，再按抖音视频 ID 精确更新已存在条目的点赞、评论、分享、收藏；同时更新已获取主数据、已有增量归档和单条资产导出 JSON，刷新资产库可见。只补有效返回值，缺失值不覆盖、明确的 0 可写入；不新建资产，不改标题、正文、播放量、人工信息、发布时间或媒体文件。
-   视频指数与来源采集时间、统计窗口保存在条目原始数据的 `douyin_index` 中；本次无指数时保留旧指数及 `video_index_meta` 原窗口。旧快照不覆盖较新数据。结果显示回写、未匹配、已是最新、旧快照及校验跳过数量；部分失败会提示重试。支持停止，当前步骤结束后取消后续处理，已保存/已提交部分保留。
-   抓取中禁用搜索输入与重复提交；WebUI 的页内刷新、顶栏刷新或切走后返回会继续展示同一任务的进度与取消入口。失败后保留当前候选，可直接重试；搜索候选的粉丝数和抖音号与桌面使用相同来源字段。
-   本页搜索确认会自动抓取并回写；工具栏「抓取并回写」保留用于当前达人的重新抓取，点击后确认范围再执行。「采集任务」里的抖音指数订阅仍只保存独立快照。
