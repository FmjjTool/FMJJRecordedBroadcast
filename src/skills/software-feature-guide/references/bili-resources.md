# B站资源

-   B站资源分为三类：表情包（普通表情包、直播间表情）、收藏集（装扮与收藏集、收藏集活动）和空间数据（用户空间）。搜索、按 ID 查看 / 下载及收藏集活动自动跳转均保留。
-   表情预览只缓存缩小首帧，按字节与条数上限回收；离开页面会释放预览下载缓存，不影响原图下载。
-   表情包：浏览/搜索全部表情包，按 ID 下载普通或装扮表情，自动识别并跳转收藏集；表情类接口需要 B站登录。
-   直播表情：输入房间号加载直播间专属/UP主大表情/通用表情，附带主播头像、封面、背景图、关键帧。
-   装扮/收藏集：关键词搜索或按 item\_id 查看详情（空间背景/粉丝牌/评论背景/表情包/加载动画/进度条/皮肤/点赞动画）；收藏集 ID 自动跳活动。
-   收藏集活动：输入 act\_id 加载视觉、勋章、卡牌图与视频。
-   空间：输入 UID 查看公开信息（关注/粉丝/获赞/签名/直播房间），可下载头像/头像框/背景图/投稿封面/充电表情/收藏集封面；游客接口，无需登录。
-   表情类接口需要 B站登录，其余为游客接口；表情包可选下载格式，每个区域独立下载进度；文件列表勾选后可批量下载。
-   综合搜索与视频信息统一由「采集任务」页处理。
