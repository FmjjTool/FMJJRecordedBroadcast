# 性能诊断

-   顶栏「性能」进入既有诊断页；「启动软件后自动监控」是页内选项，默认不勾选，勾选后立即开始普通采样，并记住以后每次启动桌面软件自动开启。无需先打开性能页，切换页面或卸载诊断页后仍由主程序继续采样。
-   自动模式在桌面 `main.py` 的 Python 入口就保留时间基准，并在 Qt / 主界面模块导入前开始进程采样；无窗口 WebUI / 定时任务 / CLI 入口先分流，不参与桌面启动监控。入口仅读既有开关，缺失、损坏或关闭时不创建诊断线程、报告目录或文件，不改写设置；Qt 接管同一记录器，不清空早期采样。
-   「启动与报告」列出 Qt / 主界面模块导入、配置、日志、Qt 应用、主题、主窗口、首页、本地状态恢复和预载的阶段耗时与工作集 / 私有提交增量，启动汇总独立于普通事件缓冲保留。早期尚无界面时，界面延迟和控件读数标为未测；阶段可能嵌套或并发，数据不可直接相加。
-   取消勾选只关闭下次启动自动开启；当前采样用「停止检测」停止。手动停止不会清除自动开启偏好，本次切页、重建页面不会自行恢复，下次启动软件才按偏好恢复。
-   「追踪 Python 分配（较慢）」仍需单独手动勾选后开始；自动监控只做普通采样，不自动开启分配追踪。已有检测正在运行时再勾选自动监控，只保存偏好，不重建会话、不清空采样。
-   「开始检测 / 停止检测 / 记录标记 / Python 快照 / 导出报告」保留；每秒采样，最多保留 3600 次采样和 2000 个事件，图表显示最近 10 分钟。停止后仍可导出，重新开始建立新记录；仅软件运行期间有效，不安装 Windows 计划任务。
-   检测开启后自动写入 `logs/performance/performance_日期_时间_进程ID_随机标识.json`：启动时先保存，之后每 15 秒后台原子更新同一会话文件，阶段边界触发保存请求；停止 / 正常退出保存最终状态，新会话另建文件。有效自动报告默认保留最近 20 份，单份最多 32 MiB；只轮转本模块格式完整的自动报告，不删除手动导出或损坏 / 无标记文件。程序目录不可写时，报告根随配置 owner 回退到 AppData 的程序数据目录，读取列表不创建目录。
-   「启动与报告」可在当前会话与已保存报告间切换，查看阶段、刷新列表、立即保存；选中历史报告时，上方「导出报告」另存该报告。读取历史报告时清空上一份阶段并暂时禁用导出；读取失败显示原因与刷新重试提示，不保留旧内容或一直显示加载中。保存状态显示最后成功时间或失败提示，保存失败仍保留内存记录与上次完整文件，可重试。自动报告是诊断日志，不新增用户备份入口。
-   覆盖从 Python 脚本入口开始的阶段，无法覆盖解释器或打包引导加载；首条内存采样在诊断初始化后取得。可捕获的 Python 启动失败会尽力保存固定阶段与异常类型，不记录异常正文、配置、请求参数或用户目录。原生崩溃、强杀、断电只保证最后一次成功落盘，不能承诺最后瞬间或每个函数 / 请求都被完整记录。
-   配置是 `config/config.json` 的 `convert.performance_auto_start` 布尔值（旧配置缺省为 `false`）；主数据仍由 `toolbox/config_manager.py` 写入，桌面与 WebUI 统一调用 `toolbox/performance.py` 的用例保存并回读确认，不增加另一份配置或迁移旧数据。
-   WebUI 的同页可修改「启动桌面软件后自动监控」，保存后供下次启动桌面软件使用；下方「已保存报告」显示历史记录、查看启动阶段并下载同一份 JSON，支持表头三态排序与列宽自适应 / 重置。实时采样曲线、任务标记与 Python 分配快照依赖桌面进程内状态，Web 不控制它们；历史报告通过共享 owner 读取，不另建 Web 数据或采样器。
