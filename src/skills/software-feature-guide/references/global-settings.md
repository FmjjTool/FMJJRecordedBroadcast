# 全局设置与后台运行

> 本文备份、导入与更新流程面向用户说明，不授权 Agent 操作真实凭据或重启运行中的用户实例。Agent 始终遵守 [真实凭据保护](../../cookie-data-protection/SKILL.md) 与 [运行保护](../../testing-quality-gates/references/running-instance-guard.md)，不因既有按钮而放宽。

-   「全局设置 → 备份与恢复」是配置与资产备份恢复的唯一主动入口（约定 17）：配置导出 / 导入全部设置为 zip（工作目录与导出目录、登录状态、账号名单与分组、弹幕姬 / 录制 / 音乐标签等页面设置），不含已获取资产、媒体文件与数据库快照，导入会覆盖同名配置、重启后生效；资产导出全部资产为 zip 包或文件夹（`collected.db` / `increment.db` 快照 + 统一导出目录全树），导入时文件不覆盖、数据库按去重键合并，导出 / 导入显示文件级进度可取消。资产库与其他业务页不再保留配置 / 资产备份按钮或快捷跳转。内部覆盖前安全副本、迁移保护与日志轮转保留。
-   本卡片只提供配置与资产备份恢复，资产导入导出按钮按两列排列；网盘备份仍在「网络库 → 网盘备份」，不嵌入设置。备份计划的设置 / 安装 / 删除仍只在「任务」页。WebUI 的网络库同样保留网盘备份与下载两个页签；原来没有的 Web 配置 / 资产备份接口本次未新增。
-   「全局设置 → 后台模式」提供「启用后台模式（关闭主窗口时隐藏到系统托盘）」开关：勾选后点关闭只隐藏窗口，采集、导出、直播录制等任务继续运行，并保留托盘图标；取消勾选即取消后台，托盘图标一并收起，点关闭直接退出软件。
-   托盘图标单击或双击恢复主窗口；右键菜单提供「显示主界面」与「退出」。首次隐藏会在托盘气泡提示恢复与退出方式。
-   主题相关设置集中在「主题自动切换（跟随系统 / 定时黑白）」；配色由全局色板统一维护，页面不提供自定义配色。
-   主题区的模式开关、浅色 / 深色时间及保存按钮紧凑相邻，窄窗按「标签 + 时间输入」整组换行；跟随系统与定时模式仍互斥，改动即时保存。
-   「全局设置 → 窗口过渡」提供「使用 Windows 原生窗口动画」开关，默认开启：打开、关闭、最大化、最小化和还原交给 Windows 管理，效果遵循系统动画设置；切换即时保存并对当前窗口生效，关闭时仅禁用本窗口的系统过渡，不修改 Windows 全局动画设置。配置键为 `window_animations_enabled`。该能力依赖本机原生窗口与桌面进程内状态，属于桌面专属；WebUI 的「全局设置」保留窗口过渡说明，不提供无法控制浏览器窗口的开关，也不新增路由。
-   「全局设置 → 关于」提供 GitHub 仓库与 GPL-3.0 开源许可证入口，并标注本软件以 GPL-3.0（GNU General Public License v3.0）协议开源。
-   「全局设置 → 关于 → 软件更新」：显示当前版本，点「检查更新」查询 GitHub Releases（`toolbox/updater.py`）；发现新版本在同一行变红/变绿提示，并打开更新对话框展示更新说明与安装包大小。点「立即更新」下载安装包、按 Release 的 `SHA256SUMS.txt` 强校验后，自动退出程序并静默安装（`/VERYSILENT`），安装器拉起新版本；UAC 权限确认需用户点「是」。只有安装版可自动安装：绿色版 / 源码运行位置与注册表 `HKLM\Software\FengMingToolbox` 的 `InstallPath` 不一致时只允许「打开下载页」，避免在 Program Files 外再装第二套。
-   「启动时自动检查更新（每天最多一次）」默认开启，可在同一行取消：启动约 15 秒后后台查询一次，失败静默、不阻塞启动；发现新版本只弹一次托盘气泡，不自动下载或安装。与「以后不再提醒这个版本」配合，写入 `config.json` 的 `auto_check_update` / `update_last_check` / `update_skip_version`。
-   更新安装前必须先真正退出进程（关闭窗口只是隐藏到托盘，exe 被占用）：由 `updater.launch_installer` 写临时 cmd 等本进程 PID 消失后再运行安装器；直播录制/监控进行中会拒绝更新，提示先停止录制。
-   「全局设置 → 运行环境与组件」默认收起，点击整行标题展开，再次点击收起，右侧箭头同步指示状态；支持键盘聚焦后按空格切换。展开 / 收起保留已填写的 FFmpeg 路径、组件选项与检测结果，不写入折叠偏好。WebUI「全局设置 → 依赖与组件」也默认收起，展开后沿用相同依赖状态、提供受控 Python 包安装任务，并就地显示进度、取消与重试。
-   「全局设置 → 运行环境与组件 → 依赖与可选组件」逐项显示 ffmpeg、ffprobe、PySide6、requests、Pillow、BeautifulSoup4、lxml、httpx、openpyxl、mutagen、websocket-client、playwright、抖音签名环境（node）的状态、版本与用途；缺失项标红。
-   可选依赖显示「可选」而非「缺失」、不计入缺失数量：Git（资料站拉代码）、Node.js（资料站前端构建，需 node + npm 同时在 PATH，内置 node 无 npm），点「下载」跳官方下载页，装完需加入系统 PATH。
-   本地总结模块与 GGUF 模型同样标「可选」，不在 FULL 内置清单；依赖清单两行可直接选择下载/卸载 CPU / Vulkan GPU 模块或推荐/已准备模型，并与本卡片下方专用面板共用状态和确认流程；模型也可导入，详见「直播总结」一节。
-   全软件的依赖安装与卸载入口统一在本卡片（约定 11）；功能页只提示所需依赖，不再单独提供安装或卸载按钮。
-   卡片同时承担四个可选组件的安装与状态：采集引擎（Playwright 内核，无系统 Edge/Chrome 时用，约 91MB）、本地转写程序（约 84MB）、本地转写模型（下拉选择 Tiny 72MB ~ Large 2944MB，可装多个）、图识别模型（CLIP ONNX，约 85MB）；下载进度显示在卡片底部，装完自动刷新状态。
-   **可卸载组件**：采集引擎（只删除程序下载的本地内核，不碰系统 Edge/Chrome）、本地转写程序、本地转写模型（按下拉选中的单个模型）、图识别模型（默认模型目录）、代理内核。卸载前二次确认，只删除受控目录；运行中/文件被占用时提示先停止，卸载后可重新下载。系统 Git/Node、系统浏览器、自定义模型路径、FULL 内置组件与抖音签名环境（node）不提供卸载；功能页也不得新增卸载入口。
-   对应功能页只保留状态与说明：账号与登录底部只显示浏览器环境并可「刷新环境」；语音转字幕设置只显示识别程序/模型状态（卸载入口只在全局设置）；资产页「图识别」弹窗只提示到全局设置下载，仍可「选择模型文件」手动指定。
-   缺失项修复：「安装」使用当前程序对应的 Python 安装包并在全局设置所点依赖行显示进度、取消、失败原因与重试，安装后重新检测和导入校验；仅源码运行态可安装，打包后的 exe 提示「未内置，请重装软件」。安装仅使用固定依赖清单，不接受任意安装参数。「证据加密组件」同时校验 pyzipper 与 AES 后端；FFmpeg / FFprobe 提供「一键下载」与「教程」。
-   FFmpeg 一键下载：从 [ffmpeg.org](http://ffmpeg.org) 指向的 Windows 官方构建站（gyan.dev）下载 release-essentials 包（约 110MB），只解出 ffmpeg.exe / ffprobe.exe 放到 `%LOCALAPPDATA%\FengMingToolbox\ffmpeg\bin`，并自动写入「FFmpeg 位置」；重装或再次点击会直接复用已下载文件。下载失败时按「教程」手动安装。
-   FFmpeg 教程：内置说明一键安装与手动安装两种方式（下载页 → 解压 bin → 回填路径，或加入系统 PATH），并提供「打开官方下载页」按钮。定位优先级为 系统 PATH → 程序目录自带（根目录 / bin / ffmpeg\\bin）→ 页面上方指定的位置。
-   桌面启动后的 FFmpeg 检查与设置页、直播录制复用同一定位方式：安装包内置或已配置的位置可直接使用，不要求再加入系统 PATH；运行检查区分「未找到」与「启动失败 / 响应超时」，失败时到「全局设置 → 运行环境与组件」核对。该检查只负责桌面进程启动后的本机提示，不修改媒体处理或录制参数。
-   桌面启动检查属于本机进程启动与原生窗口提示，不新增 WebUI 启动弹窗或独立说明页；WebUI 沿用既有全局设置与媒体引擎，不引入第二套 FFmpeg 路径规则。
