# 资产库

> **当前有效范围优先**：Agent 对腾讯文档的写入仅限《封茗囧菌数据汇总库》（`doc_key=DRnd3bkhkQUR1aEJr`）的「官方动态」`ss_h2uh2s` 与「直播记录」`ss_1xgstm`。白名单只是上限，执行仍需本次任务授权与门禁。下文五表上传、线下活动宣传图追加、活动歌单回填等白名单外按钮和旧授权仅保留为既有实现说明，**不构成现行许可，Agent 不得触发**；详见 [腾讯文档范围](../../tcdoc-sync-scope/SKILL.md)。本轮仅整理文档，未修改应用实现。

-   四个 Tab：资源归档、采集记录、本地文件、活动视频。
-   图识别按分块特征计算匹配度，仍按每个资产条目的最高分返回结果；可停止、保留已完成特征并在下次继续。关闭弹窗会请求停止，在后台任务正常收尾后释放窗口与模型。
-   资源归档：先显示数据库清单，再后台核对文件；首次需建索引，可刷新重核。支持平台/文件夹筛选、状态筛选、关键词搜索、时间排序、分页；「文件夹」下拉按一次导出产物聚合条目；单击查看详情，双击缩略图播放视频，右键打开 MD/媒体文件。
-   资源条目卡片统一为 112 逻辑像素高；标题、作者、统计与位置各占一行，长文字按可用宽度省略，悬停可看完整内容；原文中的换行只在列表显示时合并为空格，详情保留原文。「不可下载」提示位于作者行，不额外撑高卡片。
-   下载：未下载条目显示「下载资源」、已有媒体显示「重新下载」，也可勾选批量下载；单条及批量按已完成条目的产出路径更新对应卡片，空产出也不回退全盘扫描。状态筛选导致条目移出时保留其它卡片并补位；页码、勾选和滚动位置保留。已完整自动跳过，大文件显示字节进度、可取消。
-   删除：可选删除 json/md/xlsx/\_raw/媒体文件；按实际删除回执更新关联条目，不重扫资源目录。删除文本后尚有媒体则保留媒体条目，末页删空时回退最后有效页。
-   全选 / 取消全选只同步勾选状态，不重建资源卡片或重复加载缩略图；补齐 B站封面也只更新实际补齐的条目。
-   WebUI 资源归档：全选本页在本地完成，不请求清单；标记 / 解除、下载成功 / 部分成功 / 取消后，定向刷新受影响条目并保留未变化行和未完成项的勾选。状态归属变化时按当前页补位；下载回执缺少文件路径时，仅补查对应平台作者目录与旧版平铺位置，不递归扫描整库。首次优先读取完整索引，列表展示不逐条访问磁盘路径，也不触发旧目录整理；分页复用完整状态缓存，60 秒缓存到期后核对索引版本，未变化时保留完整条目与媒体映射，不退回 2000 条扫描。外部文件改动需由桌面资产页刷新完整索引，Web 在下一缓存周期接收新版本；没有完整索引时仍以最多 2000 条的目录扫描兜底。请求超过 30 秒显示原因与「重试」，刷新失败保留已有表格，切换筛选会取消上一请求，离开页签后的旧响应不改当前视图。
-   采集记录：直查已获取数据库，支持筛选/排序/勾选导出，双击看详情查看内容，右键打开链接/筛选作者。单条或批量删除后刷新当前页并补位，保留平台、作者、关键词、排序及未删除记录的勾选和滚动位置；当前页越界时回退到最后有效页，作者记录删空时保留该作者筛选空态，不跳到其它平台。过期作者查询不会回写旧计数或重置页码。
-   WebUI 采集记录：支持逐条删除、勾选批量删除（均需确认）；删除后保留当前平台、搜索词、排序和有效页码，末页删空时回退到最后有效页，仅删除数据库记录，不删除已导出的文件。筛选或排序变化时回第 1 页。
-   本地文件：选择文件夹扫描图片/视频/音频（逐级读取全部子文件夹），按文件夹分组，可下钻与锁定根目录；单击预览，切页自动扫描，缩略图懒加载，支持扫描上限与增量索引。
-   活动视频：读取腾讯文档本地快照的「线下活动」表（含现场 LIVE 1–3），按年份/活动选择；B站走实时搜索（游客优先、登录态兜底），抖音使用已采集的本地归档（实时搜索受平台登录/风控限制，不触发验证码或凭据回写）。结果表支持表头排序、双击打开、右键复制链接/标题，可导出 Excel 到导出目录的「线下现场视频」子目录；活动延期/取消不搜索，日常直播不计入，嘉宾场只收 20 分钟以上整场录像并标「待确认」。标题列可手动拖动，拖动其他列不会再反向压缩标题。
-   本页不提供备份按钮或快捷跳转；配置与资产备份统一在「全局设置 → 备份与恢复」。网盘增量上传仍在「网络库 → 网盘备份」。
-   单条上传：资源归档表格右键「上传到腾讯文档（官方动态）」把这一条直接写进《封茗囧菌数据汇总库》的「官方动态」，不经过中间层待同步清单、不受 50 条批量上限限制。点击后自动执行「同步前刷新」（采集账号 → 拉云端快照）→ 写入 → 读回校验，一条龙完成，不需要先手动点刷新；已存在的同一原帖链接会跳过。中间层工具条开启「免校对模式」时，这里跳过自动刷新，直接用当前本地数据写入。
-   图片格式：上传时腾讯只收 JPEG/PNG/GIF/BMP/WebP，其它格式（HEIC/AVIF/TIFF 等）自动在内存里转成 PNG 再传，不改动本地原图；转换失败才报「格式不支持」并中止这一条。
-   详情窗可导出预览拼贴图，复用 `toolbox.asset_preview.render_asset_preview` 与共享 `toolbox.image_render`，遵守 [统一生成图片规范](../../image-output-spec/SKILL.md) 的版式与设计令牌。
