# 图片裁切

-   可将图片或文件夹拖入窗口，也可双击图片列表选择导入图片或文件夹；支持 PNG/JPG/JPEG/WebP。
-   批量导入仅保留尺寸和小缩略图，原图按当前编辑项读取；快速切换合并为单个后台读取任务，切页释放原图并保留裁切区域与撤销记录。批量导出逐张读取原图，输出维持原始像素精度；源文件变化时提示重新导入，避免旧坐标用于新文件。
-   四边参考线裁切，拖动时显示像素放大镜；精细模式 20px→1px，Shift 临时加速。
-   边界吸附与自动对齐，可裁黑边/留白；支持精确输入上下左右像素。
-   单张导出或批量导出到 `download/图片裁切/`，文件名加 `_cropped`；支持撤销/重做。
