# 通用页面说明

## 页签命名

- 同一组页签按同一内容维度命名；数据视图优先用具体对象或用途，操作工具用明确的操作名称。通常 2–6 字，不为凑字数改变含义，避免仅用「整体 / 历史 / 字段」等泛称。
- 资产库：资源归档 / 采集记录 / 本地文件 / 活动视频。归档包含未下载及下载不完整条目；显示名称不改变导出目录、数据库字段或已有文件。
- 采集工具：视频评论 / B站资源 / 公众号文章 / 抖音表情；B站资源内部为表情包 / 直播表情 / 装扮与收藏集 / 收藏集活动 / 用户空间。旧页面名称仍可作为搜索别名。
- 公众号文章：链接导出 / 公众号资料 / 文章归档，复用既有页面的三级页签，不增加侧栏或独立管理器。
- 腾讯文档：指标历史与修订记录、推送历史区分；映射回写内的远端预览叫「只读表格」。其余同步名称和操作范围保持。
- 证书制作：证书信息 / 选项复核 / 作品图片 / 证书记录；选项复核页签仍显示匹配进度。
- 批量改名：整体规则 / 文本替换 / 文本添加 / 文本删除 / 序号规则 / 命名模板 / 逐行命名 / 处理选项 / 时间修改。媒体筛选信息面板：文件信息 / 文件改名。
- 性能诊断：采样记录 / 页面控件 / 耗时明细 / Python 分配 / 分配增长 / 子进程 / 启动与报告。网媒账号详情：指标记录 N / 直播记录 N，数量动态更新。
- 桌面与 WebUI 的对应入口使用一致名称；只有显示文案变化时，已有路由键、请求参数、表名、文件夹名与写入范围不随之改动。网络库保留「网盘备份 / 网盘下载」两个业务页签，配置与资产备份入口统一在全局设置。

## 通用表格操作

-   所有表格的表头右键都有「列宽自适应」「重置列宽」；表格自己所在的卡片底部操作行右端还有「自适应」「重置」两个小按钮（右侧只有一个动作按钮时排在它左边，否则顶到最右；卡片没有操作行时贴在表格右下角），只对这张表生效，不再放在主窗口状态栏。列宽自适应按内容宽度分配并尽量铺满视口，重置恢复表格首次显示时的宽度。
-   默认布局应铺满且不出现横向滚动；手动拖宽后允许出现滚动条，用上述入口恢复。表头点击排序见约定 14（`table_sort`）。
