# 证书制作

-   用途：录入「封茗囧菌数据汇总库·美工作品授权与二级分发协议」后，自动匹配字段与 □ 勾选项，人工复核后输出横版 A4 内部认证证书。
-   顶部保留导入文档、粘贴文本、自动编号及最右侧「生成证书」；「更多」按顺序提供输出目录、导出 Word、导出样本 Word、清空字段，功能与原按钮一致，长状态文字可换行。
-   录入：工具栏「导入文档」支持 txt / md / docx / pdf 协议，以及 xlsx 填写表（按「字段名称 / 填写内容」匹配三张表）；「粘贴文本」直接贴协议全文。字段覆盖配套填写表的三张表（协议正文 17 项、附件一 23 项、内部认证证书 23 项），含管理组代表、对接人、歌曲/项目名、双方确认签名与日期、图片内署名、署名写法说明、证书载明项。
-   自动匹配：内部认证号、作品标题与类型、授权方圈名与邮箱、主要与协作设计人、授权期限、签发日期、水印样本文件名；附件一「图片中应清晰可辨」的署名默认跟随正文，可单独覆盖。
-   选项复核：左栏「选项复核」页签列出文档里的六组 □（作品类型、样本格式、水印内容核对、计划使用位置、证书状态、图片格式），自动匹配到的项带「已匹配」并预先勾选；单选组互斥但允许全不选；勾「其他」才启用相邻的说明输入框。
-   联动：勾选作品类型后自动写入用途摘要与证书副标题；勾选「已续签」才启用「续签至」；勾选水印内容后自动生成对应图片水印文字；手动改过用途摘要后不再自动覆盖，可点「按类型恢复」。
-   编号：只保留「内部认证号」一个编号，格式 `FMJJ-DB-ART-<年份>-<6 位序号>-<8 位校验哈希>`。五段在编号卡片里分控：前三个前缀各一个可编辑下拉（选项来自历史已用值，也可直接输入），年份下拉默认「自动（本机当前年份）」且覆盖 1900–2199，序号下拉默认「自动（下一个）」并可手填；下方只读显示五段合成后的完整编号与校验码。序号按所选年份在输出目录、历史记录与保留/作废清单里的最大序号 +1 顺延（历史 3 位旧编号保持原样，不回改）；校验哈希取「编号主干 + 作品标题 + 授权方 + 授权期限 + 签发日期」的 SHA-256 前 8 位（大写），作品信息改动后自动重算。
-   授权方联系方式：原「授权方邮箱」改为「联系方式」（邮箱 / 微信 / 其他均可）。
-   署名写法说明为选填，留空不影响生成。
-   授权起始 / 截止改用下拉日历选择；截止默认按起始日 +3 年自动带出，手动改过后不再跟随；清空则按协议第四条表述。
-   「导出 Word」输出 .docx（证书页含内部认证号 / 校验哈希 / 全部证书字段 + 完整协议正文八条 + 附件一 + 附件二）到该证书的专属文件夹，可在 Word 里继续编辑；协议全文由 `src/toolbox/certificate_agreement.py` 内置模板按软件当前字段填充，导入文档里的旧值不会覆盖，冲突一律以软件生成为准；证书图片仍走「生成证书」的 PNG + PDF，若同目录已有 zip 会自动重打。
-   图片与自动水印：「图片」页签添加作品图 / 水印样本，最多 6 张，可上移下移、完整显示不裁切；「自动生成水印」默认开启，导出时按水印内容勾选把署名/认证号以淡纹稀疏平铺到作品图（不压主体），并在右下角带一个小标签，另存到证书文件夹的「水印件」子目录；重复的署名会去重。
-   预览：右侧实时预览默认「适配宽度」，可切 100% / 125% / 150% / 200%，放大后出现滚动条查看细节；窗口缩放时自动重新适配。
-   证书记录：「证书记录」页签保存字段数据及可选的产物引用与校验值，不保存原图副本；同一认证号重复生成会合并为一条并累计 revision。勾选框用于加密导出，「载入 / 删除」仍只作用于当前行；筛选不清除已勾选记录，筛选外的已选数量会显式显示。「全选结果」勾选当前筛选范围，「取消选择」清除全部勾选。载入后图片列表保持当前内容。右键记录可选「载入 / 删除记录（保留序号）/ 删除记录并作废序号」；保留与作废的序号写入 `config/certificate_history.json` 的 `retired` 清单，自动编号不再发到它们，也不出现在序号下拉里；「清空」会把这些记录的序号一并作废。
-   加密导出：勾选一条或多条记录后点「加密导出」，核对清单并两次输入 12–128 位密码，导出一个 AES-256 ZIP；密码仅本次使用，不保存、不能找回。批量最多 42 条，整包最多 128 个文件条目且明文总量不超过 64 MiB，附件较多时需进一步分批；超限会明确提示，不静默漏导。多条按 `records/0001/` 等通用编号目录分开，每条含字段快照、来源/校验清单与可用附件，全部文件内容加密。单条允许补充材料并注明「本次补充」，批量不共用补材；不会把当前表单图片当作历史证据。缺失或校验不符的旧材料会明确列出，未留存的原协议与原图无法凭字段还原；仅有字段的旧记录仍可导出快照。桌面导出可取消，不覆盖已有同名文件，期间暂停本页生成及记录修改入口，结束后恢复。
-   WebUI：侧栏「证书制作」提供「证书记录」的筛选、勾选、全选结果、取消选择与同一加密导出能力，显示数量、进度与取消；不接受浏览器传入本机附件路径。证书制作的自绘预览/排版仍在桌面端，Web 页保留说明。记录数据与桌面同源，导出不改写历史或原文件。
-   输出：固定两页（证书页 + 图片页），横版 A4 300dpi；每份证书在「输出目录」（默认 `download/证书/`）下建一个 `<内部认证号>_<作品标题>_内部认证证书/` 文件夹，内含 `_01/_02.png`、同名 `.pdf` 与 `水印件/`，并在同级生成同名 `.zip` 附属包（解压后仍是同名文件夹）。
-   证书状态：有效 / 已终止 / 已作废 / 已续签由「证书状态」勾选决定；非「有效」时右上角胶囊标签与页面淡斜水印同步变色，便于识别旧证。
-   必填校验：填写表里标「是」的字段在标签后带红色 `*`，未填时输入框或单选组显示红色边框，顶部汇总「必填未填 N 项」；导出前再确认一次，可继续生成但不会静默放过。
-   字段记忆：字段、图片列表、输出目录、编号年份与自动水印开关存 `config/config.json` 的 `certificate_maker` 段；历史数据单独存 `config/certificate_history.json`。
