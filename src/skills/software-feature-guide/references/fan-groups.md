# 粉丝群

-   抖音：主页链接 → 全部公开粉丝群（含 VIP 群），需要登录态。
-   微博：主页链接 → 全部公开粉丝群，含群号/人数/上限。
-   B站：输入 UP 主 UID → 当前账号已加入的应援团；未加入的群查不到。
-   QQ群：平台下拉选「QQ群」→ 页面直接列出预置的 8 个官方群（名称/群号）与人数状态；粘贴群号（需先完成 QQ 群登录）或 `qun.qq.com/universal-share/share` 群资料分享链接后点「查询」即保存并订阅。**按群号是主路径**：登录态下走 `group_search/pc_group_search`，任意群（不要求已加入）都能拿到群名、当前人数与人数上限；分享链接免登录但每个群 authKey 独立，只能一链一群。未订阅的群显示「未订阅」，不抓人数。
-   QQ群模式工具条：「刷新人数」刷新全部已订阅的群；「订阅列表」打开完整订阅弹窗，支持逐个保存、批量导入（每行一个群号或分享链接，按群号匹配官方目录/追加新群）、刷新全部、停止、删除订阅（快照保留）、导出 Excel 与打开保存目录；「重载列表」重新读取订阅。分享链接失效、群未公开或已解散时显示失败原因，不伪造数据。
-   QQ群登录查询：在「账号与登录 → 登录状态」完成 QQ 群登录后即可粘贴群号查询；在 QQ群订阅弹窗「更多 → 按群号订阅全部」可一次订阅预置的 8 个群。登录态自检走 `qun_mgr/get_group_list`（ec=0 即有效，登录状态页显示「已登录 · QQ <号>」，不再是「无法验证」）；取人数先走群搜索、`qinfo` 仅备用（qinfo 只认自己的会话票据，常对网页登录态回 no login）。未登录时仍只能用各群分享链接。登录入口只在统一登录管理，页面不保存或展示凭据。
-   每次查询存快照并与上次对比，新群标「新」。
-   订阅：查询成功后该账号自动加入定时快照名单；名单在「账号与登录 → 账号配置」的「粉丝群快照」勾选项里增删（只对抖音 / 微博 / B 站开放），取消勾选即退订。
-   群头像自动下载到 `头像/`（QQ群下载到各自的 `download/粉丝群/QQ群/<群号>/头像/`，取 `p.qlogo.cn/gh/<群号>/<群号>/`），表格首列缩略图，双击看原图；订阅弹窗「更多 → 重下群头像」可强制重下。QQ群模式下「打开保存目录」优先进选中群的目录（历史快照、头像都在里面）。
-   保存到 `download/粉丝群/<平台>/<UID>/`（头像 + 快照 JSON + 最新 JSON + Excel）；QQ 群存到 `download/粉丝群/QQ群/<群号>/`，导出在 `download/粉丝群/QQ群/all/`；登录按群号与分享链接共用同一快照目录。
-   定时快照：名单存 `config/fan_groups_targets.json`（QQ 群记录 `platform=qqgroup`、`input=<分享链接或群号>`）；在「任务」页给「粉丝群快照」设置每天 / 按间隔后，按名单逐个重查并写快照，人数变化以上一次 `最新.json` 对比；**每次运行都新写一份 `快照_<时间戳>.json`，历史永久保留，`最新.json` 只被覆盖用于对比**；QQ 群日志只写群号/群名，不写含 token 的分享链接；日志在 `config/fan_groups_task.log`。
