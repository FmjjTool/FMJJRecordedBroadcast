# 命名投稿

-   直播类型随中栏宽度自动换行，类型区高度跟随实际行数；窗口缩放不会重建复选框，勾选顺序、编号和数字键操作保持不变。
-   三栏工作流：左栏日期文件夹→文件列表；中栏直播账户（单选）+ 直播类型（多选，数字键 1-9）；右栏视频信息、弹幕版本、平台、标题模式、截图与新文件名预览。
-   标准文件名日期前缀支持跨天范围：开始日期 + 视频时长推算出结束日期后，写成 `2026-11-24~2026-11-26_HH-MM-SS_…`；结束日期与开始日期相同（未跨天）时保持单个日期 `2026-11-24`。
-   当前日期文件夹同步扩展：`20261124` → `20261124~20261126`（保留 `_备份` 等后缀）；目标文件夹已存在时只记日志、不覆盖；已重命名/失败记录会跟随新路径更新。
-   文件列表按参数里的「视频后缀」筛选（默认 `.mp4`，录 `.ts` 时可改）；新文件名沿用该后缀。
-   重命名视频时同步改名同场附属文件（`_弹幕.jsonl/.xml`、`_封面.jpg`、`_时间轴.json`、`<视频>.ffmpeg.log` 等），重名自动加 `_1`；视频从 `.ts` 改为 `.mp4` 时日志扩展名跟随改成 `.mp4.ffmpeg.log`。
-   `_时间轴.json` 里的视频路径与 `base` 会同步改到新文件名，重命名后弹幕对齐 / 写时间码仍然有效；分段 `_001` 的附属文件留给分段自己改名。
-   Enter 确认重命名，Esc 跳过当前视频。
-   改名不会被本软件内的预览挡住：确认时会先让「视频操作」松开正在预览的同一文件（切页时也会松手，回来按原位置续播）；若文件仍被杀软/同步盘等外部程序短暂占用，会自动等待重试约 1.5 秒，仍失败才提示「视频仍被占用，改名未执行」。
- 可写入版权属性（ffmpeg 写元数据）：写入标准 `copyright` 标签（MP4 落在 `cprt`），并在 mp4/mov/m4v 上同时写一份到「备注」。
  - 实测限制：Windows 资源管理器**不显示 MP4 的「版权」字段**（写进去后 属性 → 详细信息 → 版权 仍为空；标题/备注/作者/专辑/流派都能显示）。所以看版权请用 属性 → 备注，或 MediaInfo / 剪辑软件的标准版权字段。
  - 写入后会读回校验，校验不一致或失败都保留原视频；勾选状态下写入不成功会暂停自动投稿。
-   参数设置 Tab 维护账户/类型/平台列表、视频后缀、匹配阈值、附加信息。
-   投稿入口统一为「投稿已重命名视频」，不再单列「投稿设置」。没有视频或尚未设置工作目录时也能打开投稿窗口，配置、保存及另存为投稿模板；选择可投稿视频并完成账号验证后才可开始上传。WebUI 的「B站投稿上传」配置区同样始终可用，空目录可先保存模板，选视频后再预检与确认投稿。
-   投稿窗口：标题模板、直播日期、来源平台、简介、标签、分区、创作声明、加入合集、视频来源、封面、并行线程与自动投稿开关。标题模板 `{日期}` 与「本次直播日期」支持跨天 `20261124~20261126`：选中范围内的视频后自动带出，单日时保持 `20261124`；手填范围时不能倒序。分P仍要求同一主播/平台/弹幕版本，且日期范围包含今天。创作声明默认「内容为自制：未经作者允许，禁止转载」（版权类型自制 + 禁止转载）；选「内容为转载（原直播录播）」时才必须填视频来源，其余声明只换稿件页标签。加入合集默认「封茗囧菌直播」，验证账号后下拉列出该账号可用合集，填写名称不在列表时在投稿前拦下；投稿成功后按合集名匹配合集 ID 并调用合集切换接口加入，失败只在状态栏提示，不回滚已完成的投稿。
