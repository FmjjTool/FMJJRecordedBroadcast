# WebUI：网络库

- 网络库：两个页签——「网盘备份」映射卡片（网盘类型 / 本地 → 云端目录 / 启用或停用 / 已备份文件数与大小 / 最近运行与结果 / 排除规则、单文件上限与分享链接）可「新增 / 编辑 / 启停 / 删除」（删除仅删配置、不动文件，需确认），「立即备份」走桌面同一条引擎（后台任务、进度与日志、失败组与分享链接回显，完成后回写最近运行）；最近运行表与任务日志尾部保留。「网盘下载」可切换网盘、逐级浏览云端目录（最多 3000 项）、进入文件夹 / 上一级 / 刷新，勾选文件「下载选中」或「下载当前文件夹」（递归保留层级、断点续传、同名同大小跳过）；保存目录限制在导出目录或工作目录内，默认 `<导出目录>/网盘下载`。自动解压仍在桌面端。
