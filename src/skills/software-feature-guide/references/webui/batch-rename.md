# WebUI：批量改名

- 批量改名：文件夹路径（默认工作目录）与「包含子文件夹」、类型筛选（全部 / 图片 / 视频 / 音频 / 字幕 / 文档）；规则支持模板（{名}/{序号}/{日期} 等）、前缀 / 后缀、查找替换、序号（起始 / 位数）、大小写（全部大写 / 小写 / 首字母大写）、全半角互转、按位置插入（可从右往左）、文本模式（每行一个完整新文件名，优先于规则结果，可一键填入当前预览）、忽略扩展名与同名冲突加序号；表格预览序号 / 文件名 / 新文件名 / 状态 / 扩展名 / 大小，冲突会标「冲突已加序号」，文本模式重名会标「重名，执行会跳过」。规则引擎与桌面共用 `toolbox/rename_rules.py`；执行改名按钮可用时先弹二次确认，后端要求 `confirmed`，重算预览后校验非法字符 / 系统保留名 / 目标重复 / 目标已存在，采用「先改临时名、再落最终名」的两阶段改名（可处理互换与大小写），中途失败会尝试回滚并返回原因；未改名项列出原因。递归扫描的改名按各自子目录落位。「按类型删除」= 从文件名里删掉勾选的字符类型（空格 / 数字 / 小写 / 大写 / 中文 / 特殊字符），可叠加按位置删除（从第 N 个字符起删 M 个，可反向）与按关键词删除（以关键词定位后向左 / 向右删 N 个，可选包含关键词本身）；这些只改文件名、不删除任何文件，改动即时重算预览。扩展名可统一大写 / 小写 / 删除，或替换为指定后缀（切换扩展名规则时自动勾选「忽略扩展名」）；「关键词插入」按定位关键词在其之前 / 之后插入文本。参数由中间层 `FIELDS` 字段表统一生成配置与透传，新增规则只改字段表。页面顶部另有「时间修改」页签：按「指定时间 / 偏移量（+2h、-210m、-30s、+1d）/ 文件名中的日期」改写文件的修改、创建、访问时间，预览列出当前时间与目标时间（无法计算的行标「跳过」并给原因），应用前二次确认、应用后自动重算；规则与桌面共用 `toolbox/file_time_rules.py`，只改时间元数据，不改文件名与内容。随机数（序号旁勾选「随机数」给主名追加四位随机后缀，执行按预览计划 `plan` 落盘，看到的名字就是改成的名字；执行后再次刷新会重新生成随机值）已开放；勾选「文件夹改名」会把子文件夹也纳入同一套规则——目录不拆扩展名、不套用扩展名规则，预览里以「［目录］」标注，执行时先改文件、再按目录深度由深到浅改名，避免父目录先改导致子路径失效，目录改名中途失败会回滚已改目录。
