# WebUI：账户追踪

- 账户追踪：音乐账号 / 网媒账号按桌面卡片布局展示——工具栏（刷新 / 分组下拉 + 按组导出 / 获取全部、平台筛选）、两列账号卡片（昵称 / 平台 / 分组 / 最近采集 + 2×4 指标网格 + 历史 / 导出图片）。「获取全部」按当前平台筛选 4 并发采集（复用桌面 `collect_account` + `save_history`，网媒抖音账号顺带抓直播历史、失败不影响指标），后台任务带进度与日志；「导出图片」导出该账号最近两次采集的变化对比 PNG（需 ≥2 次数据，直接下载）。「按组导出」选一个分组后导出该组全部账号的合成变化对比 PNG（分组为空时禁用并提示）；账号配置与定时计划仍在桌面端。
