# WebUI：抖音指数

- 抖音指数：达人下拉（本地 `download/抖音指数/<达人>/latest.json` 快照，显示采集时间）、摘要行（抖音号 / 标签 / 粉丝 / 总获赞 / 作品 / 采集时间 / 统计天数）与五个页签——核心指标（昨日 / 近7天 / 近15天 / 近30天 + 环比，另附稿均指标）、每日趋势、达人视频（标题可打开视频页）、粉丝分析（维度 / 项目 / 占比 / TGI）、相似达人。顶部「搜索达人并回写资产」：按名称 / 抖音号搜索（展示粉丝数，可先选近 30 / 90 / 180 / 365 天），候选区提前展示快照与回写范围，点目标行「确认并抓取」后立即开始，无需再次弹窗确认。后台复用桌面同一套 `douyin_index_service.fetch_and_save`，先保存完整快照，再按视频 ID 更新已有抖音资产指标与指数来源；未匹配不新建，缺失值和旧快照不覆盖。完成后刷新快照列表并保留回写数量与失败回执；可停止后续步骤，已提交部分保留。
