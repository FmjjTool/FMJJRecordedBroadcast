# WebUI：音乐标签

- 音乐标签：显示音乐目录；路径框 + 「添加文件 / 添加文件夹」按相对路径扫描并加入列表（只允许音乐目录内相对路径，绝对路径 / `..` 逃逸 400）；「音乐文件」表（文件名 / 标题 / 艺术家 / 专辑 / 年份 / 流派，读取前 300 个音频的标签快照），点行打开「编辑标签」：标题 / 艺术家 / 专辑 / 专辑艺术家 / 年份 / 音轨 / 音轨总数 / 碟号 / 碟数 / 流派 / 作曲 / 作词 / 备注 + 歌词文本域，「写入标签」按 `config/music_tag` 的 ID3 版本与连接符写盘（空串=清除该字段），写前读一次、写后读回校验并记入标签历史；「抓取歌词」按当前标题 / 艺术家四平台搜索候选（最多 12 个），点「使用」把 LRC（含翻译）写入 `lyrics` 并记历史。「标签历史」表（时间 / 文件 / 标题 / 艺术家 / 专辑，来自 `config/music_tag_history.db` 最近 60 条）只读展示；编辑器内可查看所选文件最近 5 个完整快照，预览字段后「载入编辑器」仅回填表单，不自动写盘，确认后仍需手动点「写入标签」。「提取封面」经确认后将内嵌前封面导出为同名图片到音频所在目录，任务可取消，同名图片已存在时跳过且不覆盖；「编码修复」复用桌面解码逻辑，可搜索选择编码、预览原值与新值，载入编辑器只回填字段，仍需手动「写入标签」落盘。历史读取使用存储层只读接口，兼容 Windows 路径大小写与斜杠。「编辑图片」在当前编辑器内查看多图缩略图与实际类型，支持多选添加、逐张移除、设为前置、逐张导出、更换 / 移除前封面（只处理 type=3，保留背面等其他图片）；这些修改先暂存在浏览器，取消不写盘，须点「写入标签」并确认才与文字标签一起保存。单张及本次新增图片合计最多 20 MB，最多 64 张，支持 JPEG / PNG / GIF / WebP / BMP / TIFF；实际格式与像素由后端校验。文件版本变化时拒绝整次写入、保留当前草稿，可「重新读取」并确认放弃图片草稿后恢复；切换音乐文件也会提示未保存修改。沿用共享 save_tags 写入与读回，格式容器对图片类型 / 描述的限制仍与桌面一致。
  - 自动匹配：在既有标签页选择最多 20 个文件、网易云 / QQ / 酷狗 / 酷我来源、搜索条件和并发；标题 / 艺术家 / 专辑 / 年份 / 音轨 / 碟号 / 风格 / 备注可分别启用并选择是否覆盖，封面 / 歌词可选写入标签、保存同名文件、两者或不处理。先预览候选、字段差异、图片及同名文件变化，默认只勾选可写结果，再确认写入；确认时使用原预览，不重新搜索。同名文件覆盖前保留原始安全副本，已有其他类型内嵌图保留。预览最多保留 30 分钟，文件或同名文件发生变化时拒绝过期结果；任务可取消，预览不写音乐文件。
  - 按标签批量改名：同页编辑面板读取已保存标签，最多 100 个文件；复用桌面 @1～@8 和 7 个模板预设，支持自定义模板。预览列出最终名称、同名冲突编号、歌词及图片随动或跳过原因；可逐项勾选、三态排序、列宽自适应 / 重置及表头右键。含标题 / 艺术家占位符但对应标签为空时跳过，保留扩展名；同名 .lrc / .jpg / .jpeg / .png / .webp / .bmp / .gif 随动，已有目标保留不覆盖。确认后按固定预览执行，检查源文件、目录及同名文件版本；预览 30 分钟失效、一次执行后作废，可取消并保留已完成结果，失败或部分完成逐项显示。成功后列表与编辑器使用新路径；不会改写标签内容或把旧路径历史记录改成新路径。
