# WebUI：资料站

- 资料站：四张状态卡（GitHub 是否登录、站点 / API 服务状态与地址、站点数据是否重建及时间、本地图片数）、「代码与目录」卡（微信小程序主程序、webwiki、webwiki-api 的 commit 与本地改动、资料站目录、API / 站点端口、歌曲 / 活动 / 周边 / 动态 / 直播记录数量）、「站点访问统计」卡（后台密码保存（加密不回显）、采集今日、口径 / 最近日期 / 访客 / 打开 / 浏览量 / 在线指标，14 天历史表，采集日志最近 5 条）与「腾讯文档预览」（源文档下拉 + 打开链接）。可执行：仓库更新可选择单个或全部（单项只同步代码、不构建或启动）；「一键更新全部并部署 Wiki 网站」（二次确认；更新微信小程序主程序、webwiki-api、webwiki → 安装 Python 与 Node 依赖 → 重建站点数据 → 构建前端 → 启动 Wiki 网站（网页 + API），需桌面端已登录 GitHub）；「启动所选项目」可选「仅微信小程序」「仅 Wiki 网站」或「全部（小程序 + Wiki 网站）」，说明各自打开 / 启动什么，并明确不更新仓库、不发布小程序；「重建站点数据」（sync_docs + 构建前端）、「停止 Wiki 网站 + API」「采集今日」。服务状态从共享服务实例读取；服务未运行时禁用停止 / 打开按钮，运行范围操作失败后刷新状态。服务只监听本机回环；资料站代理只允许公开资料 GET/HEAD，不转发后台、统计、内部、上传或其他写方法；WebUI 与站点互不影响；改端口仍在桌面端。
