# WebUI：直播总结

- 直播总结：工作目录内 TXT / SRT 转录与已保存总结预览，提供模型接口 / 本地 CPU·GPU / 本地规则三模式、每块字数、八项本地推理参数、保存设置、测试连接与可取消总结任务。云接口字段只在接口模式显示，切换模式保留已保存配置；结果展示统计、正文与校验问题并自动保存。可选组件和模型在 Web 全局设置下载 / 导入 / 卸载，Web 导入来源限服务端工作目录；本机任意文件选择与另存为对话框仍在桌面端。
- 云接口支持 OpenAI Chat Completions、OpenAI Responses API 与 Anthropic Messages API；可按接口地址和格式获取模型列表，筛选并选择模型，也可手动输入。修改地址或格式后须重新获取；拉取可取消，只有显式保存才更新设置。
