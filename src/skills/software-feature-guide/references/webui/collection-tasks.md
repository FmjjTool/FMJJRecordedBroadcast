# WebUI：采集任务

- 采集任务：批量添加 / 解析（textarea + 开始处理，一行一个，支持整段分享文案；账号主页 → 添加账号并自动取名，作品链接 → 解析入库，单次最多 200 行，background 任务带日志与取消）；账号列表带勾选（全选本页 / 全不选 / 平台筛选），「采集范围」可选全部账号或选中账号（实时显示已选数量），覆盖桌面端「选中账号」语义；采集设置可改每账号条数、增量模式与日期段（增量与日期段写回桌面配置），限流与自动下载为只读快照；「获取最新」按范围采集（复用桌面 `collect_accounts`，增量入库 / 导出规则一致），进度与运行日志在页面内实时显示；会话定时仍在桌面端。
