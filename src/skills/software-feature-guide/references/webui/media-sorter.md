# WebUI：媒体筛选

- 媒体筛选：显示桌面端配置的源文件夹；类型筛选（全部 / 图片 / 视频）与文件名搜索，统计文件数 / 图片数 / 视频数 / 总大小与截断提示；文件列表含勾选框、类型徽标、名称、所属目录、大小、修改时间，图片可预览（限 20MB，路径限制在源文件夹内）。勾选后可复制 / 移动到桌面端分类工作目录下的子文件夹（目标下拉按内置「默认 / 收藏 / 删除 / 重复文件」优先排序，同名自动加 (1)(2) 后缀，单次上限 200 个）；「移入删除」= 移动到「删除」文件夹，不永久删除、可随时找回（需先在桌面端设置分类工作目录）；重命名限单个文件（不填扩展名沿用原扩展名，拒绝非法字符 / 系统保留名 / 已存在目标，支持仅大小写改名）。所有写操作都要在页面二次确认。MD5 过滤与去重仍在桌面端。
