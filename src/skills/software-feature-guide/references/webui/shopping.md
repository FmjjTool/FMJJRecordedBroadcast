# WebUI：购物解析

- 购物解析：共享输入区按勾选平台解析淘宝、抖音、B站小店与闲鱼商品链接；闲鱼统一由「搜索并解析」按输入自动选择关键词搜索或商品详情解析。闲鱼结果支持首页 / 上一页 / 下一页、本页全选 / 清除勾选、跨页保留勾选（单次最多 30 件）、三态排序、列宽自适应 / 重置、按数量确认跨页入库、任务进度与取消；已访问页读缓存，翻页失败或取消保留原页，新关键词搜索成功后回到第 1 页，空末页仍可返回或保存此前勾选；调用同一共享用例保存资料与图片，成功项自动取消勾选、失败项保留。下方四个页签浏览 `download/淘宝商品`、`download/抖音商品`、`download/B站小店`、`download/闲鱼商品`，图片可预览、JSON / 图片与已生成的 Excel 文件可下载。抖音商城和 B站小店解析成功后，可在本次结果表底部点「导出 Excel」，确认本次全部商品数量，后台生成后点「下载结果」保存到浏览器；复用桌面同一导出器，保留完整商品字段和已下载且可用的抖音主图，不重新请求平台、不在商品目录新增导出文件。解析快照只在当前服务进程内保留，最多 3 组、单组最多 2000 件、全部快照合计 16 MB、30 分钟失效；超出限制时保留解析结果并说明不能导出的原因。修改输入或平台范围会禁用旧结果导出，需重新解析。商品表支持三态排序、键盘表头排序、表头右键列宽操作与底部自适应 / 重置，窄屏优先保留价格、销量和链接列；排序只改变展示顺序。导出期间锁定解析与平台选择，可取消，当前 Excel 生成结束后响应取消；失败或取消不提供半成品，可用尚有效的原快照重试，短暂断线恢复后清除旧错误提示。Excel 文本按字面值保存以避免公式执行；任一文本字段超过单元格 32767 字符上限时保留解析结果并禁用导出，避免静默截断。淘宝单商品在原解析流程生成的 Excel 仍从历史产物区下载；淘宝店铺解析成功后可勾选商品抓取详情并逐件导出 Excel（每批上限 30 件，见下条「淘宝店铺逐商品详情导出」）；闲鱼沿用现有入库下载流程。
  - 淘宝店铺逐商品详情导出：结果表首列勾选框，多一列「详情导出」显示未开始 / 已完成 / 失败 / 已跳过（悬停看逐件原因）；「全选」在本次结果超过 30 件时禁用并提示逐件勾选，「清除」清空本批勾选，勾选跨页保留，表格每页 200 条。点「抓取详情并导出」先确认所选件数；任务串行执行，同一时间只允许一个批次（并发提交提示等待已有任务）。逐件按 3 秒间隔抓取详情、下载主图 / 规格图 / 图文详情并生成固定五表 Excel（商品信息、参数信息(全部)、选购参数、主图、图文详情），文本按字面值写入；主图 / 图文详情缺图时在对应工作表保留原图链接，规格图失败计入缺图数量并提示重试，不额外改变选购参数表结构。图片限制单张 20 MB、单件合计 64 MB、2000 万像素、最多 120 张。产物写入 `<导出目录>/淘宝商品/网页批次_<时间戳>_<随机>/`，成功后点「下载结果」保存只含本批成功 Excel 与 `结果清单.json` 的 ZIP。抓取详情必须已登录淘宝，未登录直接拒绝、不访问平台；单件 Excel 上限 32 MB，批次累计文件和最终附件上限 64 MB。登录态变化、平台风控 / 验证码或批次累计超限会停止后续商品，仍可打包已完成项。取消与附件生成失败不提供 ZIP，已完成的本地 Excel 保留；同步详情请求需等待返回后响应取消，图片下载按数据块检查取消。结果按完成 / 失败 / 未执行统计并保留逐件原因，勾选保留可重试。店铺快照与抖音 / B站导出快照分开管理：最多 3 组、单组 2000 件、合计 4 MB、30 分钟失效，过期需重新解析。另可点「导出完整 JSON」逐件抓取所选商品详情并作为 JSON 附件下载，数据结构沿用桌面的店铺 / 商品数 / 商品 / 导出告警；保留公开图片链接，不下载图片文件、不写入商品导出目录、不包含服务器本地图片路径或平台原始报错，详情失败项保留解析列表信息并说明告警。单批仍最多 30 件、详情请求间隔 3 秒、附件上限 64 MB，任务可取消。
