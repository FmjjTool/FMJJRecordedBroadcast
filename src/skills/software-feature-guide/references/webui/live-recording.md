# WebUI：录制

> **说明顺序**：下文早期能力说明与后续补充合并保留。以本页后文的“添加主播 / 批量导入经桌面控制桥写入”补充为准；不能因前文“仍在桌面端”将其误报为 Web 完全不支持。Agent 不得据此连接或停止用户正在使用的实例。

- 录制：布局按桌面端重排——两行工具栏（开启监控录制 / 一键停止录制 / 关闭监控 + 全选 / 取消；第二行说明与刷新状态）、主播统计条（共 N 个主播 · 监控 · 录制中 · 通道状态）、主播表（选择 / 序号 / 主播名称 / 监控状态 / 是否录制 / 录制中 / 备注 / 操作，表头三态排序）、运行日志位（提示在桌面端查看）、底部平台切换（各平台任务互相独立）。桌面运行时可通过「桌面控制桥」远控：单个主播开始 / 停止录制、开启 / 关闭监控，批量操作对勾选主播生效、未勾选时作用于本平台全部主播，均二次确认。桥仅监听 `127.0.0.1`，随机端口 + 随机令牌（写 `logs/webui_desktop_bridge.json`，不写 config），WebUI 服务端代理调用，浏览器不接触桥令牌；桌面未运行时回退为只读配置。添加 / 批量修改主播、录制设置、推送设置、写时间码、弹幕姬、在线人数与实时日志仍在桌面端；FLV / TS 修复已在本页接入，结果可下载。平台切换现在与桌面一致列出全部六个平台（抖音 / B站 / 快手 / 微博 / 小红书 / 网易云），只有 0 个主播的平台也能选中并添加；「添加主播」支持填房间号或直播间链接（可点「识别」补全主播名 / 开播状态 / 可用清晰度，不识别也能直接添加）、备注、加入监控、开播即录；「批量导入」每行一个房间号或链接，重复与无法识别的行跳过、默认加入监控。两者都经桌面控制桥写入（桌面程序为唯一写入方，桌面未运行则按钮禁用并提示），桌面端会同步刷新主播表。
