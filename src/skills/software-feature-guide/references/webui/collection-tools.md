# WebUI：采集工具

- 采集工具：四个页签对应桌面子页的本地产物——视频评论（按平台 / 视频分组，评论长图与原始 json）、B站资源（按子目录分组）、公众号文章（导出的 HTML / PDF / Word / MD）、抖音表情包；图片可预览（限 20MB），任意文件可下载（附件），路径限制在各自导出根目录内。视频评论与公众号文章已可执行：评论区支持抖音 / B站 / 微博，输入视频链接或 ID；平台右侧按钮单击切换「视频 / 作者」，作者仅抖音，作者模式才显示视频数（1–10）与页数（1–50），视频模式固定默认 5 页；导出长图 / 保存原始数据选项在首行抓取操作之前，作者参数单独在第二行。关键词 / 昵称 / 最少点赞 / 仅带图 / 排序筛选，按勾选导出评论区长图与原始数据到「评论区/<平台>/<视频ID>/」；公众号文章支持一行一个链接（≤30 篇，批量限速），导出 HTML / Word / Markdown（PDF 需桌面 Qt 渲染）。任务均为后台执行，带进度、日志与取消，完成后自动刷新产物列表。B站资源与抖音表情包也可执行：B站资源页签按类型切换——表情包（按包名搜索全量列表，勾选下载到「B站资源/表情包」，长 ID 自动按装扮表情包解析）、装扮（填 item_id 或链接，按桌面同一份清单下载到「B站资源/装扮」）、UP 信息（填 UID 或空间链接，下载头像 / 横幅 / App 背景 / 投稿封面 / 充电表情 /收藏集封面到「B站资源/空间资源」）；抖音表情包页签填直播间号或链接，先「拉取表情」读取会员表情栏（需抖音登录 Cookie，可预览名称），再「下载全部」写入「抖音表情包」导出目录。
