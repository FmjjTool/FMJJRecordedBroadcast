# WebUI：腾讯文档

> **当前有效范围优先**：Agent 对腾讯文档的写入仅限《封茗囧菌数据汇总库》（`doc_key=DRnd3bkhkQUR1aEJr`）的「官方动态」`ss_h2uh2s` 与「直播记录」`ss_1xgstm`。白名单只是上限，执行仍需本次任务授权与门禁。下文五表上传、线下活动宣传图追加、活动歌单回填等白名单外按钮和旧授权仅保留为既有实现说明，**不构成现行许可，Agent 不得触发**；详见 [腾讯文档范围](../../../tcdoc-sync-scope/SKILL.md)。本轮仅整理文档，未修改应用实现。

- 腾讯文档：按桌面端「顶部文档卡 + 子页签」布局。顶部为文档选择、打开链接、立即采集、表格同步、自动维护状态与最近采集摘要；子页签与桌面同名同序——中间层同步（见下）、表格同步（工作表选择 / 同步 / 只读行与分页）、历史记录（采集时间 / 浏览量 / 浏览增量 / 成员数 / 成员增量 / 已查看人数，最新在前）、采集明细（成功 / 失败与说明）、修订记录（本地库，时间 / 版本 / 编辑人 / 修订号 / 类型）、成员名单（本地库，昵称 / 权限 / 来源 / UID / 企业）、文档管理（名称 / 类型 / 记录数 / 最近采集 / 链接，添加编辑删除仍在桌面端）、映射回写（本地表格比对 / 本地采集记录与推送历史）。中间层同步：选表格 / 时间范围（7 / 30 / 90 / 365 天）/ 账号口径（腾讯表账号或全部）后「重新比对」，只读比对本地快照与本地采集数据，列出待同步行（标题 / 时间 / 账号 / 平台 / 图片数 / 标记，可勾选）；支持「同步前刷新」（采集平台资料 + 拉取腾讯文档快照，走桌面端同一套流程，后台任务可看日志）、「查看 TSV」（浮层全选复制，列顺序按字段映射）；批量上传仅限「官方动态」「直播记录」且仅新增（单次 ≤50 条，需勾选 + 二次确认 + 刷新门禁），写入时自动带本地图片与评论区索引图，写入后读回校验并记录推送历史，完成即作废刷新凭证；完整歌曲 / 线下活动 / 周边图鉴可只读比对，网页端不允许上传；线下活动在「手动录入」中可选「补充已有活动歌单」：选活动 + 填三个平台歌单链接或 ID，直接写入 `活动歌单_*` 三列（只改这三列、已有其它链接不覆盖、写后读回）。中间层同步支持「手动录入」：所有目标表按当前表头生成只读 TSV；「线下活动」在同一窗口另提供「补充已有活动歌单」模式，只允许更新该表三列歌单链接。中间层同步支持「检查新下拉选项」：按勾选记录读云端字段，列出哪一列会新建哪些选项值（只读、不写）；勾选「允许新建下拉选项（仅本次）」后再上传，腾讯按「快速添加」建值，上传回执列出新建的选项。只新增选项值，不新增字段、不改字段名与顺序、不删选项，仅限「官方动态」，且同意只在本次上传有效。写回：仅《封茗囧菌数据汇总库》的「官方动态」（`ss_h2uh2s`）与「直播记录」（`ss_1xgstm`）单条新增——按 30 / 90 / 180 / 365 天预览本地待写记录，每次只写选中 1 条并二次确认；写入前要求「同步前刷新」未过期（或桌面端已开启免校对模式），与桌面共用上传互斥锁，写后读回校验并记录推送历史；中间层支持批量新增（≤50 条）；「修改 / 删除」页签接续：选「官方动态」或「直播记录」+ 关键词「读取云端记录」，实时读云端当前行（记录 ID / 标题 / 时间 / 账号），点「修改」打开浮层——只列出文本列，先「预览改动」列出字段的当前值与目标值，再「确认提交」二次确认，提交后读回核对每个字段；勾选若干行「删除选中」（单次 ≤20 条）先按标题 + 记录 ID 列出待删清单再确认，删除后读回确认已消失。修改 / 删除同样要求「同步前刷新」未过期（或桌面端免校对模式），与桌面共用上传互斥锁，只按 recordID 逐条操作、不改表结构、不删除或重排下拉选项（新增选项值见上「检查新下拉选项」）。「宣传图追加」页签：按时间范围读取「已存在且有本地 cover / images」的线下活动，与云端该行「宣传图」按图片标题去重后列出每场可追加张数与表内已有张数（同名图片跳过、已补齐的不列出），勾选后二次确认再上传——只更新这些行的「宣传图」列，不改其它字段、不删或替换已有图片、不改表结构；同样要求「同步前刷新」未过期（或桌面端免校对模式），写后按图片标题与数量读回核对，不提供清空 / 覆盖 / 删除图片的入口。
