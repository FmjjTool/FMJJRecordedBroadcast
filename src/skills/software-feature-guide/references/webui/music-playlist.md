- 歌单制作：来源固定为线下活动曲目，活动框默认显示日期最新的一场，支持框内搜索、清空与改选；完整歌单名称默认「封茗囧菌数据汇总库-」+ 活动名，含前缀均可编辑，提交不补回；活动或名称变化会清除旧预览，同活动直接重选保留手改名称。目标平台勾选（默认勾选网易云 / QQ音乐 / 酷狗，其余按 `/api/music-playlist/platforms` 的能力与可用性决定是否可勾选）、「同时加入待确认歌曲」；「预览匹配」后台逐平台生成计划并写入 `音乐信息/歌曲合集/preview_*.json`，结果表显示 平台 / 序号 / 来源歌曲与歌手 / 状态（已匹配 / 待确认 / 未找到 / 重复）/ 匹配歌曲与歌手 / 相似度（最多 1200 行，超出提示截断）；结果表第一列「写入」可逐首勾选（已匹配默认勾、待确认默认不勾，未找到 / 重复不可勾），表上方「全选 / 选匹配 / 清除」与「已勾选 N 首」计数，写入请求按 `selection={平台: [序号…]}` 只写勾中的歌（全不勾的平台整条跳过）；「创建歌单」需二次确认，按预览缓存逐平台读登录态建单并分批加歌（账号里已有同名歌单时直接复用、不新建，回执标「复用同名歌单」；复用前会核对歌单是否还在——酷狗客户端删掉的歌单接口仍返回旧记录，以 `deleted=1` 判定已删除并重新新建；复用或重跑时先读歌单已有曲目，已有的不再重复添加，回执标「歌单里已有这首歌」）（未登录平台跳过并说明，不影响其他平台），每个平台写 `journal_<平台>.json`，结束时写 `result_*.json` 并回显各平台已添加 / 失败 / 跳过数；来源为线下活动时，写完自动把三个平台的歌单链接回填到腾讯文档「活动歌单_*」三列，回执逐项显示已写入 / 已是该链接 / 已有其它链接 / 缺少目标列 / 校验未通过 / 失败。预览缓存 30 分钟，过期或已写入后需重新预览。下方「本地报告」表保留（预览 / 执行日志 / 执行结果 JSON + 「查看」格式化展示）。批量改单名、断点续跑（`--resume`）、删除歌单仍在桌面端 / 命令行。
