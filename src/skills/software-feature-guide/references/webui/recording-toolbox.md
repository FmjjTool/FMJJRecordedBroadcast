# WebUI：录播工具箱

- 录播工具箱：自动整理、视频操作、命名投稿、音频提取、字幕转换、继续操作、日历浏览、文件迁移八页已建立 Web 入口。音频提取、字幕转换、视频操作与文件迁移已可操作：扫描工作目录内视频 / 字幕 / 日期文件夹、勾选后后台处理、显示进度与取消、结果列出成功 / 失败 / 输出。音频输出沿用桌面端（视频同目录、按音轨编码）；字幕按配置输出到原目录或统一导出目录，输出与源文件同名时跳过，避免覆盖；视频操作支持格式转换、压缩、合并、切割与截图：转换为无损优先、按桌面默认输出格式、强制同目录、目标格式相同则跳过；压缩按轻度 / 标准 / 高强度重编码（可选分辨率与清除元数据），输出 `<文件名>_compressed_video`；合并按表格当前排序顺序拼接为 mp4 / mkv（无损或兼容转码）；切割按「开始-结束」片段逐段导出 / 拼接成一个文件 / 删除选中片段（无损或精确）；截图可导出单帧（JPG / PNG）或按间隔抽帧到 `<文件名>_frames` 文件夹；轨道页列出音轨 / 字幕轨并可提取全部轨道、删除选中轨道，可追加 / 替换外部音轨（m4a / mp3 / aac / flac / wav / opus / ogg / ac3）与添加外挂字幕（srt / ass / ssa / vtt），外部音轨编码不适合 mp4 时自动改用 mkv；元数据页读取并写入标题 / 备注 / 作者 / 日期（字段名直接显示在输入框，输出 `<文件名>_meta`，保留原旋转）；旋转角度（0 / 90 / 180 / 270）移到转换页独立导出，并保留原标签；切割页可把片段写成章节并封装为新视频（不转码）；切割页还支持自动检测静音 / 黑帧 / 场景切换（静音阈值 dB、黑帧与场景 0.01–1，最短 0.1–10 秒可调），检测只读不生成文件，切点可一键填入片段；片段清单可在页面导出 CSV / EDL / ffmetadata 章节文件（内存生成、按附件下载，不写工作目录）或导入本工具导出的 CSV 回填片段（带表头或无表头的 `序号,开始秒,结束秒` 均可识别，上限 512KB）；勾选 1 个视频时表格下方出现网页播放器，按 Range 按需加载、可拖动进度（MKV / AVI 等浏览器不支持的格式会提示改用桌面端）。全部只生成新文件、**不删除、不改写源视频**，同名自动加序号；压缩与截图输出到源视频同目录，合并、切割、轨道、元数据与章节输出到工作目录根；任务显示进度并可取消。文件迁移复用桌面合并语义：复制 / 剪切日期文件夹到目标目录（可在「全局设置 → 目录设置」里修改迁移目标目录），文件级合并、同名跳过计重复（不覆盖目标）、剪切后清理空目录，迁移前弹窗二次确认；目标目录与工作目录互为父子时拒绝。日历浏览可按日期文件夹浏览：日期列表（文件数 / 大小）+ 点击查看当天文件（上限 500 个）。继续操作可启动桌面端已配置的快捷项：链接在浏览器新标签打开；软件在运行 WebUI 的电脑上启动（启动前二次确认，独立进程运行，不随 WebUI 退出回收）。命名投稿可操作：预览扫描工作目录视频，提取平台、日期、时间、标题并标记是否已标准命名；未标准命名的视频点「命名」弹出表单——选择账户（桌面重命名配置的账户列表）、直播类型（多选）、弹幕版本、平台、标题（留空用提取标题），确认后按桌面模板生成标准文件名（日期_时间_账户_类型_版本_平台_标题）改名，附属文件（弹幕 / 封面 / 时间轴）同步改名，目标已存在或文件被占用时拒绝并提示；表单可选「写入版权标签」——复用桌面 `video_meta` 写标准 copyright（MP4 / MOV / M4V 同时写「备注」，资源管理器可在备注中查看），文本取桌面命名投稿设置的附加信息，写入失败保留已改名视频并提示原因。投稿上传已接入：命名投稿页「B站投稿上传」卡片可勾选多个已标准命名的视频（分 P），填写标题模板 / 简介 / 标签 / 分区 ID / 创作声明 / 合集 / 日期 / 原直播来源与是否自动投稿；分区识别：读取 B站创作中心「当前账号可用分区」，按「父/子（ID）」下拉选择并回填分区 ID，也可手填；预检会把分区 ID 与账号可用分区比对，不在列表内直接拦截并提示重选。封面可填本机图片完整路径（校验存在 / 类型 / 20MB / 可解码，上传时转 JPG）；留空则自动提取首帧，预检会检查 FFmpeg 是否可用。投稿模板与桌面共用 `upload_templates`：进入页面自动载入当前模板，可下拉切换、保存设置（覆盖当前模板）、另存为（覆盖同名）、删除。点「预检」只读检查命名、日期与分 P、标题 / 标签 / 分区、文件状态（空文件 / 30 秒内写入 / 符号链接）、B站登录与合集是否存在，并给出完整元数据预览；预检通过且选择与设置未变时才可「确认投稿」，二次确认后走桌面同一套 UPOS 上传与上传历史（同一视频重复投稿会被拦截）。「投稿历史」卡片列出最近任务与状态（已投稿 / 已上传 / 上传中 / 结果不明 / 失败），已投稿与上传中不可重试；核对 B站投稿管理无重复后可「允许重试」。自动整理可操作：预览按文件名日期分组（日期 / 文件数 / 大小 / 文件预览）并列出无日期视频；勾选日期分组并确认后复用桌面引擎把视频移动到对应日期文件夹（附属文件随视频移动、复制校验后删来源、30 秒内仍有写入的文件跳过以保护录制中文件），无日期视频不参与。「A 端来源」与桌面共用 `config/organize.json`：可添加 / 移除来源文件夹、切换是否含子文件夹；「扫描来源」只读列出可迁移数量、按日期分布与被跳过原因（空文件 / 近期写入 / 已在工作目录），「迁移来源视频」二次确认后按同一引擎迁移（无日期按修改时间归组，同名自动编号，校验后删来源）。
