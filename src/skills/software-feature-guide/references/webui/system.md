# WebUI：系统

- 系统：展示版本、程序 / 配置 / 导出目录、工作目录与 WebUI 端口 / 局域网 / 隧道配置；可修改工作目录、导出目录与迁移目标目录（须为已存在的完整路径、磁盘根目录拒绝、二次确认；桌面端已锁定的目录拒绝修改；迁移目标目录不能与工作目录互为父子目录，保存后「文件迁移」页立即生效）与外观主题（浅色 / 深色 / 跟随系统，写入桌面端配置，桌面端主题定时切换优先）；依赖与组件中，可选本地总结 CPU / GPU 引擎及 GGUF 模型支持下载 / 导入 / 校验 / 卸载，有进度与取消，使用桌面同源服务；抖音签名环境、采集引擎、本地转写程序 / 模型、图识别模型仍只读检测。WebUI 卡片另显示隧道模式、frp 公网地址与 cloudflared / tailscale / frpc 客户端可用性（只读，启停仍在桌面端）。
