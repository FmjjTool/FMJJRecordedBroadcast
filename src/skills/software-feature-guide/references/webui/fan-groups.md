# WebUI：粉丝群

- 粉丝群：「查询粉丝群」卡片支持抖音 / 微博 / B站，粘贴主页链接或 UID 后台查询（`fetch_groups` + 头像下载 + 快照保存 + 人数变化对比），结果表含群名 / 群号 / 人数（含上限）/ 变化（新群、+N、-N）/ 标签 / 链接，查询成功后按桌面逻辑加入定时快照名单。下方 QQ 群卡：头像（本地缓存，缺失首字占位）、群名 / 群号 / 人数 / 变化 / 状态 / 来源与「历史」展开人数记录；「查询 / 订阅」可粘贴群号（需桌面端已登录 QQ 群）或群资料分享链接（免登录），后台读取群资料、保存快照并写入订阅名单；「导出 Excel」按桌面同格式导出当前列表并直接下载（`QQ群人数_时间戳.xlsx`）；「下载头像」补齐已订阅群头像到各群目录（已有文件复用，失败项列明）；「刷新」重新读取列表。改群名与删除订阅仍在桌面端。
