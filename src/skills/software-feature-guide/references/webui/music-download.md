# WebUI：歌曲下载

- 歌曲下载：「搜索并下载」卡片提供「关键词搜索 / 单曲解析」。搜索可选五平台对比 / 网易云 / QQ / 酷狗 / 酷我 / 5sing / 酷狗概念版，按每平台条数（10/20/30）返回平台 / 歌名 / 歌手 / 专辑 / 时长表，可排序、全选 / 反选并下载或导出。单曲解析选择具体平台、输入官方完整歌曲链接或 ID，显示元数据、封面与最多 100 行歌词，自动选中唯一歌曲、不显示行勾选或批量选择，底部仅一处「下载歌曲」，并可导出该结果快照的信息包（此项为 Web 附加能力，桌面单曲暂不导出）；输入或平台变化、切换模式即作废旧详情。分享短链与酷狗 8 位 mixsong 短码不支持。解析可取消（等待当前平台请求返回），封面不可用不阻塞歌曲详情。桌面与 WebUI 均可勾选「下载封面」（默认勾选），控制音频下载是否另存封面；单曲详情预览独立只读。音质选项由后端按所选平台返回，网易云默认「超清母带」、其他平台默认「最高可用」，保留支持的无损 / 320k / 192k / 128k 选项；指定档位不静默降低，「失败或试听自动换源」沿用同一音质要求。文件保存到音乐下载目录，下载结果列出文件名、试听标记、实际媒体音质与换源平台；平台授权及接口限制与桌面共用同一实现。下方统计总首数、总大小与格式分布，表格列出本地音频文件（文件名 / 格式 / 大小 / 时间）。解密仍在桌面端。
  - 搜索结果导出：在同一结果卡片勾选歌曲后点「导出选中」，核对数量并确认，生成 JSON / Excel / Markdown 的 ZIP 包，再点任务中的「下载结果」保存到浏览器下载目录。只导出原搜索结果的勾选子集，保留原关键词、歌曲全字段与原始公开信息，不重新请求平台，不下载音频或封面，不写桌面音乐信息目录。签名链接与敏感字段会清洗，酷狗公开歌曲 hash 保留；Excel 文本按原文字面值写入。搜索快照最多 300 首、24MB，进程内最多保留 3 组，30 分钟后失效；过期或被后续搜索淘汰时需重新搜索。排序不会改变勾选歌曲，表头支持三态排序与右键列宽操作，表格底部提供自适应 / 重置。导出显示进度且可取消，当前文件生成阶段结束后响应取消，不提供半成品下载，原勾选保留可重试；导出期间搜索、勾选与下载暂时禁用，短暂断线恢复后会清除旧失败提示。
