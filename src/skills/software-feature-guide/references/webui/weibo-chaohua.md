# WebUI：微博超话

- 微博超话：「解析与采集」卡——输入超话链接或 100808 开头 ID 解析（后台任务），列出频道表（勾选 / 频道 / flowId / 最大页数 1–500，默认 10），「开始采集」按所选频道抓取并入库（可取消，进度逐条写日志，入库失败只提示不影响结果），「导出 Excel」下载与桌面同格式的数据表（`超话名超话_数据采集_时间戳.xlsx`，内容取最近一次采集）。下方本地累计：超话下拉（`config/weibo_chaohua.db` 的 topics）、摘要行（累计帖子 / 采集次数 / 首次与最近入库 / 最近一次新增与状态）与五张卡片——最近采集批次、超话指标快照（签到 / 分类排名 / 帖子数 / 粉丝数）、每日新增、热门帖子（按点赞，可打开链接）、增长榜（多次采集点赞增幅）。改数据库路径与历史清理仍在桌面端。
