# 封面制作

> **写入边界**：下文封面图回填仅说明既有用户功能，目标固定为《封茗囧菌数据汇总库》`DRnd3bkhkQUR1aEJr` 的「官方动态」`ss_h2uh2s`。Agent 执行仍需当次具体授权、确认与刷新门禁，遵守 [腾讯文档范围](../../tcdoc-sync-scope/SKILL.md)；本轮未执行回填或修改应用代码。

-   随机底图 + 标题/日期/备注三段文字，快速产出静态封面。
-   底图缩放缓存设有内存预算；离开页面释放底图与成品预览，返回时按原有文字、样式和位置重建，导出仍使用所选分辨率。
-   界面三段式：顶部工具条（底图文件夹路径+张数+更换/重扫、底图适配、随机/选择/上传图片）、左侧文字样式卡片 + 模板按钮、右侧预览卡片（顶部显示当前底图名）与导出条（分辨率、JPG 质量、复制/导出 PNG/导出 JPG）；提示文字进 tooltip，不占页面。
-   底图：递归扫描底图文件夹随机抽取；可临时上传替换；适配模式支持裁剪填充或完整包含；无底图时画布内显示虚线空状态与操作引导。
-   文字：三组字段各自一行标题+对齐、一行文本、一行「字体+字号+颜色+B/I」，三组同屏不滚动；同步可勾选字体/颜色/字号三项，只同步被勾选的属性。
-   定位：预览区拖动文字块；重置位置恢复默认纵向分布；整体 Y 轴按画布高度百分比平移（-30%~+30%）。
-   分辨率：按画布比例存储，预览 960x540，导出可切 1080p/2K/4K；超长文字自动换行并缩小。
-   导出 PNG 无损或 JPG（质量 60~100）到 `download/套版封面/`（主按钮为「导出 JPG」）。
-   模板存 `config/cover_templates/`，保存样式/位置比例、底图记忆及底图适配、整体 Y 偏移、导出分辨率和 JPG 质量，不保存文字内容；旧 v1 模板仍可读取，缺少的新参数采用默认值。
-   「批量补封面」使用打开窗口时的当前样式、底图和备注快照：选择本地视频目录，可包含子目录，扫描后双击标题 / 日期修正，勾选并确认生成。日期识别支持紧凑 / 分隔 / 中文日期及跨日范围，文件名没有日期时取扫描目录以内最近的日期目录；没有日期时留空，不用修改时间猜测。非法 / 多个无范围关系的日期须人工修正，同主名多格式视频冲突须先区分主名。
-   批量输出位于视频旁，命名为 `<视频主名>.jpg`；同名图片以及 `_封面` / `_cover` / `.cover` 附属图都视为已有封面并跳过。生成前后复核已有文件，原子创建且不覆盖，取消保留已完成文件；视频本身不修改。不接投稿、自动整理或其它录播核心模块，也不安装定时任务。扫描 / 生成用例位于 Qt-free 的 `toolbox/cover_automation.py`，可供后续流程调用。
-   本地封面渲染完成后会自动读取腾讯文档「官方动态」并按作品标题 + 发布时间日期匹配；唯一匹配的记录在确认后追加到「封面图」字段，保留已有图片并逐条读回核对。多条匹配、未匹配、字段异常或刷新门禁未通过时只保留本地封面并提示原因。目标固定为《封茗囧菌数据汇总库》的 `ss_h2uh2s`，桌面与 WebUI 共用同一回填用例。
-   WebUI 的「封面制作」提供模板选择、工作目录内相对子目录扫描、标题 / 日期修正、勾选和可取消补全；复用桌面保存的模板与相同引擎。自绘排版编辑仍在桌面，Web 不建立另一套模板存储。
-   WebUI 生成完成后自动展示腾讯文档匹配清单，确认后追加「官方动态」封面图并显示读回结果。
-   下拉/滑条/数字框不响应滚轮；字体可直接输入；颜色使用内置主题色板。
