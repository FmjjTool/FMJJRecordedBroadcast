# 公众号文章

-   页面分为「链接导出 / 公众号资料 / 文章归档」。链接导出每行输入一篇 `mp.weixin.qq.com` 图文（每批最多 30 篇）；自动提取公开链接、去重、逐篇限速并支持停止。收录只保存资料与文章元数据，导出时才抓取正文与图片。
-   「公众号资料」可从一篇文章识别账号，显示名称、标识、备注、文章数与最近同步；支持搜索、编辑备注、查看该账号文章、「同步最新」与「继续抓取」。同步最新遇到已有完整元数据时停止；继续抓取按已保存的分页断点向前读取，每次默认最多 10 页，上限 50 页。失败占位不作为增量停止边界，重复识别不覆盖已有备注。
-   「文章归档」按公众号、标题关键词、起止日期（含结束当日）和状态筛选；状态为已归档 / 已导出 / 失败 / 待生成 PDF。每页 200 条，表头升序 → 降序 → 默认按全结果排序后分页，支持列宽自适应 / 重置、跨页勾选、打开原文、导出勾选和失败重试。单批导出最多 200 篇；失败重试最多读取当前公众号范围的前 200 条失败文章，数量更多时分批继续。导出清单为当前筛选范围的 UTF-8 BOM CSV（最多 50000 条），只含公开元数据，不是整库备份。
-   正文支持 HTML（图片内嵌）、PDF（桌面 Qt 渲染，A4）、Word（docx）、图片文本 MD（Markdown + 图片文件夹）。导出位置可选默认（统一导出目录/公众号文章）或固定位置，按公众号名 / 文章名建文件夹。图片抓取不完整会标为失败；停止保留已完成文件，未生成的 PDF 可从失败状态重试。
-   资料与分页断点统一存于本地 `config/wechat_library.db`，schema 1，由共享存储 owner 管理；文章长链按公众号标识 / mid / idx 去重，短链按文章路径去重。库中不保存正文、图片、请求头或登录信息；无自动清理、迁移或整库导入入口。
-   历史列表需要目标公众号对应的短期阅读会话。统一「账号与登录」的「微信公众号」行默认提供「自动检测」：打开非模态窗口，阅读并勾选临时系统设置同意项，再点「开始检测」，随后在电脑版微信中新打开一篇目标公众号文章。最长等待 120 秒；识别新请求后先还原临时设置，再交给既有内存会话接口。手动输入保留为同一窗口内的备用操作，普通分享链接不能代替有效阅读请求地址。会话仅保留内存，最长 10 分钟；清除、关闭账号使用、过期或身份变化后停止继续读取，不自动刷新或写回已有登录数据。业务页不提供登录或信息输入入口。
-   自动检测依赖 Windows 本机 HTTPS 代理、当前用户证书存储及独立进程，属于桌面专属的 L2 操作面板，归入现有统一管理入口，不新增侧栏、管理器或长期账户数据。仅在用户主动开始后临时设置 HTTPS 代理并信任随机的短期检测证书；只解析 `mp.weixin.qq.com` 的文章阅读请求，其余公网 HTTPS 仅作不解密隧道，普通 HTTP 不接管。已有手动代理或 PAC 时停止并提示，不覆盖；检测期间外部修改网络设置时保护用户的新设置。停止、超时、关闭窗口与父进程正常退出均先走还原；还原失败时保持检测进程并重试，不把失败当成成功。
-   还原确认前不安装检测结果，取消或失败保留原有有效会话。检测窗口不可在仍占用临时设置时静默销毁；工作进程失联时明确提示人工检查网络代理与当前用户证书，允许关闭提示窗口，但禁止本进程重新检测。工作进程被强制结束、系统崩溃或断电不保证自动还原；发生这类情况，应检查 Windows 代理设置与本次 `FMJJ Reading Detection` 临时证书，完成手动还原后再启动软件。没有持久化恢复日志。
-   WebUI 同步三个视图、资料编辑、筛选分页、历史同步、HTML / Word / Markdown 导出、重试和 CSV；导出位置由服务端配置决定。PDF 依赖桌面 Qt，属于本机渲染专属。自动检测保留 `renderDesktopOnly` 说明区，不提供远程修改系统设置、阅读信息输入或检测启停接口。桌面主动启动的 WebUI 子进程通过受随机能力保护的回环只读通道使用同一临时会话，浏览器不接收原始信息；独立启动 WebUI 无该桥接，也不提供第二个输入入口。
-   检测独立实现，未运行或复用 WeDown 闭源组件。代理仅观测 HTTP/1.x 的明确长度请求，不解析 HTTP/2 或 chunked 请求体；实际客户端若不使用系统代理或不接受临时证书，检测可能超时。开发验证仅使用虚构数据、本地 TLS 服务与假系统接口，未修改用户的真实代理、证书或已保存登录数据；真实微信客户端兼容性及已打包程序尚未实测。历史适配为未公开的微信列表协议，已用虚构响应验证，真实平台可用性尚未实测；付费、加密、删除、登录失效、验证码与平台限制会明确停止，不绕过访问控制。互动计数、关注状态、自动发现账号等参考软件能力尚未实现。
