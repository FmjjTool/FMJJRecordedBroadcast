# 资料站

-   `mandisa-miniprogram`（微信小程序主程序，`master`）、`webwiki-api`（Wiki API，`main`）与 `webwiki`（Wiki 网页前端，`main`）分别位于资料站目录。小程序与 Wiki 网站是两个独立项目，不是主从投影；可单独更新任一仓库，也可更新全部，单项更新只同步代码，不安装依赖、不重建数据、不启动项目。站点数据从「腾讯文档监控 → 表格同步」的本地 `tables.db` 重建，浏览器访问 `http://127.0.0.1:站点端口/`。
-   「启动所选项目」可选「仅微信小程序」「仅 Wiki 网站」或「全部（小程序 + Wiki 网站）」。仅小程序会在本机微信开发者工具打开工程；仅 Wiki 会同时启动网页与 API；全部会依次执行两项。运行范围只决定打开 / 启动哪些项目，不更新仓库、不上传或发布小程序；仓库更新与一键部署是另一组操作。
-   项目为私有仓库：未登录时「拉取代码」「一键部署」锁定；登录状态由软件统一管理。
-   「一键更新全部并部署 Wiki 网站」按 5 步执行：更新微信小程序主程序、Wiki API、Wiki 网页前端三个仓库 → 安装依赖 → 重建站点数据 → 构建前端 → 启动 Wiki 网站（网页 + API）。如果站点已运行，会先停止旧服务再启动；此部署流程不会打开微信开发者工具或发布小程序。按钮下方进度条显示 `第几步/共几步 + 当前动作`，旁边「取消」停在当前步骤（已完成部分保留，状态写「已取消（完成 N/5 步）」）。
-   任一步失败会自动从头重新部署一次（日志写明中断原因与第几次重新部署）；两次都失败才弹窗，并给出已重试次数与下一步建议。
-   仓库更新按约定 15 逐档换通道（直连 → 环境变量代理 → 系统代理 → 本机 7890/10809/12450 的 HTTP 与 SOCKS5 → `git config http.proxy`），日志逐档记录失败原文；仓库以云端为准，远端历史被重写时先留 `pre-sync-<时间>` 备份分支再对齐云端。
-   每次重建全量读取最新本地数据，不重新请求腾讯文档。
-   已下载的本地图片优先使用（封面直接读本地文件并生成缩略图），缺失才回退图床缓存。
-   只监听 127.0.0.1；端口被占用时在「目录与端口」更换。
-   站点访问监控读取线上站点后台统计，密码加密存 `config/webwiki_analytics.json`，只掩码显示；「采集今日」写 `download/站点监控数据/访问统计.db`，同日覆盖；历史表显示最近 14 条。
-   每日自动采集的 Windows 计划任务为 `FengMingWebwikiAnalytics`，统一在「任务」页安装/修改；失败写 `采集日志.log`。
-   站点默认只保留近 90 天明细；后台密码错 5 次锁 15 分钟。
