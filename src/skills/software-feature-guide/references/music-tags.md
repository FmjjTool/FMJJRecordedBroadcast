# 音乐标签

-   用途：读取/编辑/保存 FLAC、MP3、M4A、OGG、OPUS、WAV、APE、WV、WMA、AIFF、DSF 的标签与内嵌封面；右侧文件列表 + 左侧表单，多选可批量套用同一份修改。
-   网络匹配：工具栏「网络匹配」四平台搜候选手动挑；「自动匹配」按相似度批量填标签、封面、歌词。
-   封面：封面搜索、更换封面、图片管理（多图）、导出/移除封面。
-   歌词获取：表单「歌词」框右侧「获取」先读同目录同名 .lrc/.txt；没有才按当前标题/艺术家/专辑从网易云、QQ、酷狗、酷我联网匹配（有翻译时按时间轴合并）。取到后自动存同名 .lrc 并写入音频文件，状态栏/提示会注明来源与 .lrc 数量。
-   歌词区布局固定：右侧竖排「获取」「展开/编辑」，顶端对齐，不随内容滚动；窗口放大时歌词框同步变宽变高、按钮跟随贴右（左表单与右侧列表按 2:4 分配宽度）。
-   「展开/编辑」窗口可读取本地 .lrc 或导入 .lrc 后写回表单；歌词搜索支持时间偏移、去时间标签/空行/头部标签；手动挑在线来源仍用工具栏「歌词搜索」，搜不到会显示失败来源。
