# 歌单制作

> **当前有效范围优先**：Agent 对腾讯文档的写入仅限《封茗囧菌数据汇总库》（`doc_key=DRnd3bkhkQUR1aEJr`）的「官方动态」`ss_h2uh2s` 与「直播记录」`ss_1xgstm`。白名单只是上限，执行仍需本次任务授权与门禁。下文五表上传、线下活动宣传图追加、活动歌单回填等白名单外按钮和旧授权仅保留为既有实现说明，**不构成现行许可，Agent 不得触发**；详见 [腾讯文档范围](../../tcdoc-sync-scope/SKILL.md)。本轮仅整理文档，未修改应用实现。

-   页面：音乐工具 →「歌单制作」（`src/gui_qt/pages/music_playlist.py`）；桌面与 WebUI 来源固定为线下活动曲目。命令行 `python main.py --music-playlist ...` 保留原有独立来源，无窗口、不加载界面。
-   活动：默认选择活动日期最新的一场（含未来活动；同日按快照行号倒序），可在框内搜索、清空或改选；清空只取消选择，不删除活动记录。曲目取「标准化曲目」（缺失时解析「演唱曲目」），仍复用「完整歌曲」的官方平台链接。歌单名称默认「封茗囧菌数据汇总库-」+ 活动名，包含前缀的完整名称均可修改或删除；提交只校验非空与总长不超过 60 字，不自动补回前缀。自动生成的默认名最多 60 字；直接重选同一活动保留手改名称，改选不同活动重置默认名；主动清空后重新选中则重新生成默认名。
-   **取歌走官方**：快照里的平台链接就是该平台官方歌曲 ID，匹配时直接使用，不再搜索；只有该平台链接缺失或无法解析时才调用平台官方搜索接口（网易云 `api/search/get`、QQ `client_search_cp`、酷狗/酷我官方搜索）。歌名与歌手都参与打分，同名翻唱只算「待确认」，默认不写入。
-   目标：网易云 / QQ音乐 / 酷狗 / 酷我 均可勾选；酷狗云歌单需要 App 令牌，可在「账号与登录 → 登录状态 → 酷狗 → App扫码」扫一次（令牌存 `config/kugou_app_session.json`，不写网页登录态；写入遇 20017 会自动刷新一次）。**未登录酷狗 App 时**，写入确认框会先提示，写入结果也会明确显示「酷狗云歌单需要登录酷狗 App：请到账号与登录 → 酷狗 → App扫码」，不影响其他平台；酷我同样支持「App扫码」（存 `config/kuwo_app_session.json`）：扫码后建单走 `pl3_addlist`（body 含 title/intro/ispub）、加歌走 `pl3_add`（body `{"data":[歌曲ID],"pid":…,"pos":0}`），与 PC 客户端同款；网页建单已下线，仅保留报错提示；未扫码时提示去登录；5sing 已支持创建与加歌：走网页「歌单」JSONP 接口（`service.5sing.kugou.com/songlist/`），程序自动上传封面、填「流行」标签，曲目按歌名+歌手回查 5sing 自己的「类型$ID」（yc/fc/bz）后按批加入，歌单 ID 从「歌单管理」页回查。
-   重复执行：QQ 音乐同名歌单已存在时直接复用该歌单继续加歌（创建接口 `code=21` 返回 `dirid`），不会因为上次中断而无法重跑；加歌遇到非 JSON 响应（风控页/空响应）会换新签名重试一次，仍失败才报错，错误提示带 HTTP 状态、Content-Type 与响应摘要。
-   预览：逐平台搜索并生成计划，结果表按「已匹配 / 待确认 / 未找到 / 重复」标注，支持表头排序；默认只预览，不创建任何歌单。 修改歌单名、清空活动或改选活动会清除旧预览与逐首勾选，需重新预览才能写入；直接重选同一活动且名称未变时保留预览。
-   逐首勾选（2026-11-26）：结果表第一列「写入」是勾选框，勾选＝写这首歌、取消＝这次跳过；「已匹配」默认勾上、「待确认」默认不勾（未找到 / 重复的行没有勾选框，显示「—」）。桌面「匹配结果」标题旁提供「全选 / 选匹配 / 清除」，结果摘要合并显示「已勾选 N / M 首」；「打开报告目录」位于来源区标题旁，路径不在结果区重复显示。平台细节放在「目标平台」悬停提示中。顶部「同时加入待确认歌曲」勾上等于把待确认行整批勾上（仍可逐首取消）。写入只按勾选执行（`MatchItem.selected`，`PlatformPlan.selected()` 统一判断），勾选为空的平台整条跳过，确认框按平台列出实际勾选数量。WebUI 同一套语义，提供相同的三项按钮文案并精简选中计数，写入请求带 `selection={平台: [序号…]}`。
-   写入：预览后点「写入平台」二次确认，按平台创建同名歌单并分批加歌，进度与失败原因写入运行日志；每个平台写 `journal_<平台>.json`，中断后可用命令行 `--resume` 续跑。
-   线下活动回填：来源选「线下活动曲目」时，平台创建成功后自动把歌单链接写回腾讯文档「线下活动」的 `活动歌单_网易云` / `活动歌单_酷狗` / `活动歌单_QQ` 三列（只更新该活动行、只写这三列；已有其它链接不覆盖；酷狗链接先做只读网页探测，未通过不写）。回执区分已写入 / 已是该链接 / 已有其它链接 / 缺少目标列 / 链接未通过校验 / 失败，并写进 `result_*.json` 的 `writeback`。
    - 曲目来源：优先用「完整歌曲」表里该平台的歌曲链接（酷狗存的是 `m.kugou.com/mixsong/<短码>.html`，程序会取一次页面解析出 hash / mixsongid，不再退回搜索，避免匹配到翻唱）。
    - 链接口径：网易云用 `playlist?id=`；QQ 建单返回的是 `dirId`，会自动调 `GetPlaylistByUin` 换成公开页用的 `tid`（`y.qq.com/n/ryqq_v2/playlist/{tid}`），再用 `fcg_ucc_getcdinfo_byids_cp` 核对歌单名是否与本次一致，不一致就不写（`dirId 201` 是「我喜欢」，不能当自建歌单）；酷狗用 `global_collection_id` 拼 `yy/special/single/collection_3_<uid>_<listid>_0.html`（实测自建云歌单无需 specialid 也能打开，页面标题即歌单名），拼出的歌单名与本次不一致、或歌单已下架时返回空链接，回执「平台无网页链接」。
    - 已有链接若被探测为「已失效」（404 / 显示不存在 / 跳非歌单页），自动替换为本次新链接；网络异常不算失效，保持不覆盖。
-   顺序：按来源列表顺序写入；网易云批量加歌会倒置，自动调用排序接口；QQ 新歌插到最前，逐首反向添加。平台无原曲的歌曲跳过，不拿翻唱硬顶。
-   酷狗定位音频：云歌单按 `album_audio_id`（mixsongid）+ hash 定位，**不能**用单曲 `audio_id`——实测《声声慢》用 audio_id 会被换成同名无关的有声书；`KugouPlaylistWriter.add_songs` 已固定优先 `album_audio_id`。
-   报告：预览与执行报告写到统一导出目录的 `音乐信息/歌曲合集`，页面可直接打开该目录。
-   登录：目标平台需已在统一登录入口完成登录；页面只读使用当前登录态，不保存、刷新、迁移或展示登录内容。写入节奏默认搜索间隔 0.35 秒、加歌批次间隔 0.8 秒，可用命令行参数调整。
-   网易云分权账号：建单读「网易云（歌单创建）」`netease_playlist` 的登录态（`netease` 主账号只用于会员下载/采集）；未单独登录歌单账号时回落主账号，页面说明与写入日志会注明当前用的是哪个账号；WebUI 与命令行同一条 `playlist_service.get_login_jar`，行为一致。
