# 项目约定总入口

所有 Agent、子 Agent 与自动任务操作前完整阅读本入口、[真实 Cookie 保护](../cookie-data-protection/SKILL.md)，更新前再读 [八个核心模块保护](../recording-toolbox-core/SKILL.md)。项目规则冲突时以总约定为准，真实 Cookie 保护在项目内最高优先；上层指令与用户本次具体范围仍须遵守。技能文档约束 Agent，不代表已安装运行时拦截。

## 按任务读取

- 变更仓库、备份、Git / 网络 / 提交或报告：[Git、Markdown 与日报执行细则](references/git-workflow.md)。本地提交无需读发布技能。
- 对应产品规则细节：[产品与数据边界](references/product-boundaries.md)，按下表编号读相关章节，不因一次普通编辑通读所有领域。
- 多 Agent、共享文件、并行进程、他人 WIP、长任务：[并行协作](references/coordination.md)。一个文件同时一个写入方；共享文件串行更新。
- 用户明确调用 /shaman 或要求该风格：[可选匠心风格](references/craftsmanship.md)，默认不加载，不改变授权、工具或模型参数。

## 17 条现行约定

保留原编号；细则只在上述 references 维护。新增规则连续追加，明确授权的规则更新可以修订 / 合并文字，同时更新 AGENTS.md 与快捷路由，不能用历史附录扩大权限。

1. **版本领先**：更新前 status → 本任务稳定 WIP 本地备份 → 核对 origin → 成功 fetch → 祖先关系与左右独有提交数比较。远端领先只快进，本地领先保留，分叉先展示双方差异再询问；同步失败停止，不强推。非 main 先核对目标分支映射；独立树沿用已确认基线，不误判 detached HEAD。
2. **备份与本地提交**：修改前检查，完成后本地提交并报告实际哈希。只处理明确路径与本任务内容，不擅自暂存 / 提交正在变化的他人 WIP；可使用独立干净 worktree 安全隔离后合回。提交不等于推送。
3. **Markdown-only**：项目 skill 放 src/skills/<name>/，仅 SKILL.md 与可选 .md 子文档。默认不附脚本、二进制、JSON/YAML/TOML；用户明确要求的当次例外不沉淀为默认。改动技能时清理其非 md 遗留，但不碰用户数据。
4. **唯一日报**：按北京时间完成日期维护 Progress/YYYY-MM-DD_当日总结.md，先读现有报告、合并保留其它任务，再连同本任务本地提交；记录需求、方案、文件、实际验证、未完成项与提交信息，不为自身哈希反复提交。
5. **统一账户管理**：应用内账户只由总管理器与管理层接口提供；业务不自建凭据、登录窗或存储，不假装迁移已完成。宿主 Git / gh 可只读使用既有原生认证，不复制或改应用凭据；真实 Cookie 永不写入。
6. **核心八模块**：自动整理、视频操作、命名投稿、音频提取、字幕转换、继续操作、日历浏览、文件迁移默认禁改；具体授权须覆盖本次模块和范围，共享代码间接影响同样受限。可只读分析、维护保护文档，不擅自修复核心。
7. **真实 Cookie 绝对保护**：原值、归属、时间、加密表示、存储文件和关联快照均不可写 / 删 / 迁移 / 刷新 / 复制到测试环境；整文件只改开关也不行。无测试、修复、临时授权或恢复例外；意外变化停止，不自行回滚。
8. **总结边界**：实际“总结文章”须有可读取附件 / 明确文件路径，按 [直播总结](../fengming-livestream-summary/SKILL.md) 完整纠错、分类、模板执行；规则维护和工作总结不套文件门槛。所有总结默认不 push / 打包 / 改版 / tag / Release。
9. **业务页不管理登录**：应用只有统一 Cookie 管理入口；业务页无 Cookie 字样、凭据路径、登录控件或“去登录 / 打开管理”引导，未登录只提示“需要登录”等状态。已有违规只在获准修改对应页面时处理，不批量顺手改。
10. **定时任务**：Windows 计划只在任务页配置，经 task_center 统一注册 / 分发；功能页不内嵌计划设置。会话内计时器可保留但需明确仅软件运行时生效，不改已有任务名与配置键。
11. **依赖安装**：检测、下载 / 安装、受控本地组件卸载统一在全局设置；可选依赖不阻塞。打包态无 pip 按钮，系统 / 自定义 / FULL 内置组件不提供卸载，受控卸载二次确认。
12. **入口分级**：管理器须跨页、单一事实来源、独立生命周期；中心只聚合，页内用设置 / 列表 / 面板。新增前判 L0/L1/L2，登记功能说明与日报；不能重建第二套认证、任务、备份或依赖入口。
13. **数据与 skill 同步**：获准只读使用真实腾讯数据后，实际字段 / 枚举 / 口径与代码、skill 一致；更新说明快照来源和时间，不扩大 [两表白名单](../tcdoc-sync-scope/SKILL.md)。
14. **统一表格行为**：可比列三态排序，table_sort 统一键、空值最后、选择随行；服务端分页整库排序再分页。table_columns 提供表头右键及卡片操作行自适应 / 重置，默认无横滚，不自写第二套。
15. **GitHub 网络**：先直连且临时清代理，失败才按候选代理，再告知后尝试其它方式；逐档记录真实错误。origin 始终为约定 HTTPS 地址，SSH 回退用单次 URL，不持久修改 remote / 代理，不强推。
16. **隔离测试与实例**：默认源码副本 + 独立 config/download/logs/端口 + 虚构数据，所有烟测过程放 _smoking/；真实目录默认只读。接入真实实例 / 指定非凭据数据须本次列明范围、快照哈希和整文件还原并获同意。用户实例默认禁关；本次授权且提示风险才可操作。Agent 自建确认隔离的进程可正常收尾。真实 Cookie 无例外。详情见 [质量门禁](../testing-quality-gates/SKILL.md)。
17. **备份与恢复**：配置 / 资产备份、恢复、整库导入导出只在全局设置，复用既有引擎；网盘增量上传仍在网络库。计划仍在任务页，内部安全副本 / 迁移保护 / 日志轮转保留，不授权真实数据操作。

## 合并后的路由

13 个主入口与 12 个旧名兼容入口的映射见 [快捷指令](../quick-commands/SKILL.md) 与根 AGENTS.md。兼容入口只转交，不重复维护规则。实际任务必须读对应主入口及被选分支；快捷摘要、技能发现、程序按钮都不能替代权限核对。

代码验证与清理统一到 testing-quality-gates；架构 / 数据 / 平台 / WebUI 同步统一到 layering-contract；视觉 / 交互 / 程序出图统一到 ui-visual-spec。保留独立凭据、安全、业务领域、输出模板与真实数据范围约束。仅明确要求发布才读 summarize-update。
