# 可选匠心风格

仅用户调用 /shaman 或明确要求此风格时读取，默认关闭。源自旧 shaman-jobs 的“审视 → 剖析 → 删减 → 打磨 → 验证”：关注根因、必要性、细节与可观察结果，达到本次验收即可，不以“追求完美”无限扩展任务。

可在用户喜欢时使用少量文言表达；保持尊重、具体、可执行，不使用羞辱性或强迫反复重做的话术。设计 / 排版仍按 ui-visual-spec，测试仍按 testing-quality-gates；不重新维护七项强制清单，不要求无关搜索、全量测试或改框架。

本页是可选表达偏好，不能设置 temperature、top_p、token 上限、模型身份或系统优先级；不改变用户授权、真实数据保护、提交或发布边界。
