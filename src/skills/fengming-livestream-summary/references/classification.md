# 归类与分类名库（可扩展）

> 本文件是直播总结的**归类决策库**，解决「内容该归哪一级、分类名怎么起、哪些易漏」三个问题。
> **扩展接口**：后续遇到新的内容类型、新的分类名、新的易漏项，直接在本文件对应区块追加即可，无需改动 SKILL.md 主逻辑。

## 一、归类总原则（先判级，再起名）

1. **先判断内容主体**：这条内容的主角是谁？
   - 主角是「封茗囧菌本人」的状态、经历、兴趣、计划 → 归 2 级（个人生活事件）。
   - 主角涉及「他人」（粉丝、家人/亲属、工作人员/助理、好友、其他歌手/UP主、合作方）的关系或互动 → 归 5 级（社交关系相关事件）。
   - 讲的是「未来要发布/举办/推出」的事 → 归 1 级（待发布内容详情）。
   - 讲的是「恋爱观/情感态度」 → 3 级；「学校/校园/留学」 → 4 级；「实际演唱」 → 6 级；「身高体重年龄生日」 → 7 级。

2. **判定口诀**：先看是不是「未来发布」→ 1 级；不是，再看是不是「牵涉他人」→ 5 级；都不是 → 2 级。

3. **边界易混点**：
   - 「粉丝送我的礼物，我打算怎么安置」——主体是主播本人行为 → 2 级（如「礼物安置」）。
   - 「提醒粉丝别浪费钱 / 粉丝之间闹矛盾 / 感谢粉丝来看我」——涉及粉丝关系 → 5 级。
   - 「妈妈陪亲戚看病 / 小时候单独带弟弟」——涉及家人 → 5 级。
   - 「四姐（工作人员）拍照 / 苗苗告诉我消息」——涉及工作人员 → 5 级。
   - 「我好闺蜜是射手座，启发我写歌」——涉及好友 → 5 级。

## 三、易漏项排查清单（通读全文时逐项核对）

按类别逐项排查，宁可多拆一条，不可漏：

- **待发布**：新歌/专辑/星座系列/巡演/漫展/签售规则/签名规则/造型规划/周边预售与售卖/棉花娃娃/海报/视频/直播调整/活动信息渠道/未发布歌曲/合作嘉宾/发糖等粉丝福利。

- **教学分享**：开嗓/发声/唱歌技巧/护肤/美妆/底妆/唇妆/定妆。
- **身体与情绪**：健康/生病/失眠/嗓子哑/心悸/头晕/情绪低落/迷茫/掉眼泪/身材焦虑/体态焦虑/健身/体重。
- **饮食作息**：喝了什么饮品（如咖啡、霸王茶姬）/吃了什么/失眠/作息。
- **兴趣回忆**：童年阅读/童年动画/童年游戏/追剧/看动漫/重温老剧/玩游戏/抽卡。
- **宠物**：兔子/狗/猫等宠物的日常轶事。
- **粉丝相关**：送礼感谢/礼物提醒/粉丝矛盾/粉丝关系/连麦名字/偶遇粉丝/线下饭撒。

- **工作人员**：四姐/苗苗/啊团/骷髅兵/妆娘/摄影/商务等团队互动。

- **情感相关**：恋爱观/情感辟谣（澄清与某人非情侣）/给粉丝的情感建议。
- **学业相关**：在读大学/留学经历/高考建议/学业祝愿。

## 四、扩展方法（新增内容时这样加）

1. **新增分类名**：在第二节对应维度的候选池里追加一行。
2. **新增易漏项**：在第三节对应类别里追加一条。
3. **新增纠错词**：在 `correction-map.md` 对应区块追加映射。
4. **新增维度（如 1-7 级不够用）**：在本文件新增一节，并在 SKILL.md「内容维度」对应位置登记，同步更新 `template.md`。
