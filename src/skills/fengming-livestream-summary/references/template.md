# 输出模板

最终输出为**纯文本**（禁止 markdown）。行序如下：

```
封茗囧菌 YYYYMMDD 直播总结
【腾讯文档】封茗囧菌数据汇总库
@share-html:https://docs.qq.com/sheet/DRnd3bkhkQUR1aEJr

1 级：待发布内容详情
[实际分类名称]：核心详情，时间：XX，地点：XX，合作方：XX（五要素逐字段列出，未知填「暂未公开」）
[实际分类名称]：核心详情，时间：XX，地点：XX，合作方：XX

2 级：直播中提及的「个人生活事件」
[实际分类名称]：核心信息
[实际分类名称]：核心信息

3 级：直播中提及的「恋爱相关事件」
[实际分类名称]：关键内容

4 级：直播中提及的「学校相关事件」
[实际分类名称]：关键内容

5 级：直播中提及的「社交关系相关事件」
[实际分类名称]：关键内容（含粉丝关系/矛盾/礼物、家庭/亲属、工作人员互动、好友联动等）

6 级：直播中演唱的歌曲
《歌曲名称》（片段）
《歌曲名称》

7 级：直播中提及的个人基础数据
[身高]：明确数值，无则「未公开」
[体重]：明确数值，无则「未公开」
[年龄]：明确数值，无则「未公开」
[生日]：明确数值，无则「未公开」

【腾讯文档】封茗囧菌数据汇总库
@share-html:https://docs.qq.com/sheet/DRnd3bkhkQUR1aEJr
```

## 说明

- `YYYYMMDD` 替换为直播日期；未知时标题改为「封茗囧菌暂未公开（直播日期）直播总结」。
- 各维度无有效内容时，保留维度标题并在标题后标注「未提及」。
- `[实际分类名称]` 替换为贴合该条内容核心属性的简洁分类名，禁止保留占位符。
- 1 级每条必须逐字段列出「时间、地点、合作方」等要素，未知字段单独写「暂未公开」，禁止省略字段、禁止整条糊成「暂未公开」。
- 6 级无演唱内容时填「未演唱歌曲」；片段演唱标注「（片段）」。
- 7 级四项用方括号标注：`[身高]`、`[体重]`、`[年龄]`、`[生日]`。
- 首行标题 + 第 2/3 行固定标注 + 末两行固定标注必须齐全且与第 2/3 行一致。
