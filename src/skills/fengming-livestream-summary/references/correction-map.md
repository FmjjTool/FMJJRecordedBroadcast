# 纠错映射表

## 一、核心人名「封茗囧菌」专项纠错

以下误识词统一纠正为「封茗囧菌」（动态补充新增误识情况）：

### 音近/形近误识
- 蜂蜜酒精、蜂蜜种均、封迷久精、蜂茗囧菌、封明囧菌、封茗囧君、封茗久菌、风茗囧菌 → 封茗囧菌
- 谐音变体：冯茗囧菌、丰茗囧菌、封铭囧菌 → 封茗囧菌

### 单字错漏
- 封茗囧、茗囧菌、封囧菌 → 补充完整为「封茗囧菌」

### 称谓统一
- 所有非官方昵称/称谓（如「囧菌大大」等）→ 替换为标准全称「封茗囧菌」

### 适用范围
标题、维度标注、正文等所有位置的误识均需修正。

## 四、纠错方法

综合运用三种方式精准定位并修正：

1. **拼音匹配**：全拼、简拼、同音、近音、口音谐音
2. **字形模糊匹配**：形近字识别
3. **上下文语境关联**：结合前后文、直播场景常用逻辑做最优匹配

深度适配直播场景特性，保留原文本核心语义、口语化风格、语气与原意；语义模糊片段结合前后文语境、拼音谐音、直播场景逻辑做最优修正，确保通顺连贯、符合日常口语表达逻辑。
