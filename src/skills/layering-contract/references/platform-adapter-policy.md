# 平台适配与外部接口策略（Platform Adapter Policy）

本文件是 [架构总入口](../SKILL.md) 的平台规范正文；新增或修改平台接口、登录适配、下载及回退策略时完整阅读。旧 `platform-adapter-policy` skill 仅转交本文件。

先阅读 [convention-skill](../../convention-skill/SKILL.md) 与 [layering-contract](../SKILL.md)。涉及登录/凭据时按 [cookie-data-protection](../../cookie-data-protection/SKILL.md) 与 [cookie-manager](../../cookie-manager/SKILL.md)；涉及网络/文件/依赖安全时读 [security-baseline](../../security-baseline/SKILL.md)；涉及测试时读 [testing-quality-gates](../../testing-quality-gates/SKILL.md)。

本 skill 只约束 **L4 平台适配层**：协议、签名、解析、分页、回退、错误映射与平台能力说明。它不授权在页面里直接发平台请求，不授权绕过登录/付费/风控，也不改变腾讯文档写入白名单。

## Adapter 契约

每个平台适配器必须提供稳定的输入/输出契约：

| 方向 | 必须 | 禁止 |
| --- | --- | --- |
| 输入 | 规范化参数：URL/ID、分页游标、数量上限、日期范围、筛选条件、取消信号、进度回调 | 页面对象、控件、主题、全局 UI 状态 |
| 凭据 | 通过统一管理层获取；按平台原生方式注入；请求结束即丢弃 | 直接读凭据文件、页面保存 Cookie、第二套登录态 |
| 输出 | 领域 DTO/字典、分页信息、来源、抓取时间、限流提示 | 直接写数据库、直接改页面数据、直接弹窗 |
| 错误 | 类型化错误：AuthRequired / RateLimited / NotFound / ParseChanged / NetworkError / Blocked / Unsupported | 裸 `Exception`、字符串匹配、静默返回空列表 |
| 取消 | 支持停止信号，已抓部分保留，未完成状态明确 | 无法取消的无限翻页/浏览器滚动 |

Adapter 不负责“该用哪个账号、该不该重试、该不该换平台”的业务决策；这些由 L3 用例决定。

## 能力矩阵

新平台接入或已有平台变更时，必须维护一张能力表（README 或适配器文档均可），至少包含：

| 字段 | 说明 |
| --- | --- |
| 平台 | B站 / 抖音 / 微博 / 快手 / 小红书 / 腾讯文档 / 音乐平台 / 票务 / 购物 / 网盘 |
| 单作品 | 是否支持；HTTP / 浏览器 / 混合 |
| 用户时间线 | 是否支持；分页方式；数量上限 |
| 账号追踪 | 是否支持；字段完整度 |
| 评论/搜索 | 是否支持；需要的登录态 |
| 登录方式 | 游客 / Cookie / 扫码 / 浏览器快照 / Token |
| 回退顺序 | 游客 HTTP → 用户 Cookie HTTP → Playwright |
| 限流/限制 | 页大小、频率、已知风控、字段缺失 |
| 已知限制 | 仅首批、需设备 Cookie、需登录、接口已关闭等 |

页面不得各自复制一份能力表；页面只展示适配器返回的能力/错误。

## HTTP 与浏览器回退

1. 回退必须**显式、有界、可观测**：每一级记录尝试与结果，不无限重试。
2. 默认顺序：匿名 HTTP → 已启用 Cookie 的 HTTP → 浏览器/Playwright 兜底。平台有特殊顺序时在适配器内写明。
3. 用户关闭 Cookie 总开关后，不得偷偷使用缓存/旧文件/浏览器 profile 恢复登录；按游客流程或返回 `AuthRequired`。
4. 游客票据只用于当次请求；不持久化为用户登录态，不写入统一凭据存储。
5. 回退到浏览器时必须设置超时、页面上限、取消信号；浏览器失败返回 `Blocked`/`NetworkError`，不返回空数据冒充成功。
6. 平台接口已关闭/需要付费/需要 DRM 时，返回 `Unsupported` 并说明；不得绕过付费或版权限制。

## 网络策略

1. 连接/读取超时、最大重定向、最大响应体必须设置；大文件下载分块、限速、可取消。
2. 重试只针对幂等请求和临时错误；使用指数退避 + 上限；`AuthRequired`/`Blocked`/`ParseChanged` 不盲目重试。
3. 翻页设置最大页数/最大条数；数量 0 表示“无上限”时必须有停滞检测和取消信号，不能真的无限翻。
4. 并发按平台限制；同一平台账号间共享冷却/限流状态，避免请求风暴。
5. 响应必须校验状态码、Content-Type、JSON 结构、关键字段类型；解析失败归类 `ParseChanged`，不要当空数据。
6. TLS 校验默认开启；不向第三方/CDN 转发平台 Cookie/Authorization。

## 签名与反爬

1. 平台签名（WBI、a_bogus、mcloud-sign 等）属于 Adapter 细节；签名输入/输出不进入日志、报告或 UI。
2. UA/Referer/设备指纹按平台要求设置；不伪造他人身份，不共享/转卖账户凭据。
3. 游客票据、设备 Cookie、临时 Token 只在内存/当次请求使用；不写入真实凭据文件。
4. 遵守平台频率与访问控制；不绕过付费、DRM、验证码或风控，不做账号池/代理池规避。
5. 发现平台结构变化：先停用受影响字段/功能并明确提示，不静默返回错误数据。

## 错误分类

| 类型 | 含义 | L3 处理 | UI 展示 |
| --- | --- | --- | --- |
| `AuthRequired` | 需要登录/登录失效 | 走游客流程或提示需要登录 | 不含凭据名词的“需要登录” |
| `RateLimited` | 触发限流/冷却 | 等待/降低频率/停止 | “请求过于频繁，请稍后再试” |
| `NotFound` | 内容不存在/已删除 | 跳过该条 | “内容不存在” |
| `ParseChanged` | 页面/接口结构变化 | 停止该适配器，记录诊断 | “接口可能已变化” |
| `NetworkError` | 超时/连接失败 | 有界重试/切换回退 | “网络异常” |
| `Blocked` | 风控/验证码/拒绝 | 停止，不绕过 | “平台暂时拒绝访问” |
| `Unsupported` | 平台不支持/已关闭/需付费 | 换源或说明限制 | 明确说明，不诱导付费 |

错误对象携带平台、阶段、HTTP 状态（如有）、重试建议；不携带 Cookie/Token/完整响应体。

## 契约测试与 fixture

1. 每个 Adapter 至少覆盖：成功解析、空结果、分页、关键字段缺失、错误响应、限流、结构变化、回退路径。
2. 测试使用最小 fixture 或 MockTransport，不访问真实平台；fixture 去除个人信息/凭据/签名。
3. 断言输出 DTO 的字段、类型、排序、分页信息与错误类型，不断言内部私有方法。
4. 真实账号实测只在用户明确要求时手工执行；结果记录在报告中，不写成自动化测试依赖。
5. 平台接口变更时先更新 fixture 和契约测试，再改实现。

## 新平台接入清单

- [ ] 明确平台、可抓范围、登录方式、限制与合规边界。
- [ ] 在 L4 新增 Adapter，不把请求写进页面。
- [ ] 定义输入/输出 DTO、分页、错误类型、取消信号。
- [ ] 实现游客 HTTP → Cookie HTTP → 浏览器回退（按平台实际情况）。
- [ ] 设置超时、重试、限流、最大页数、响应大小限制。
- [ ] 凭据只走统一管理层；不新增第二套登录/凭据存储。
- [ ] 补契约测试与最小 fixture；不访问真实网络。
- [ ] 更新能力矩阵/README；记录已知限制。
- [ ] 页面只调用 L3 用例，不直接 import Adapter。
- [ ] 更新当日报告并本地提交。

## 变更与废弃

1. 平台字段/接口变化：Adapter + fixture + 能力矩阵 + 报告一起更新。
2. 旧字段/旧接口保留兼容层时，标明废弃时间与替代字段；不要让页面直接依赖旧字段。
3. 删除适配器前确认没有页面/任务/导出引用；保留必要的历史解析兼容。
4. 每次平台故障都记录：平台、时间、错误类型、影响功能、临时处理；同类故障重复出现时再沉淀为规则。

## 与其他 skill 的关系

- `layering-contract`：Adapter 属于 L4；页面不直连协议。
- `security-baseline`：网络、TLS、SSRF、日志脱敏、依赖与子进程。
- `testing-quality-gates`：契约测试、fixture、失败/回退用例。
- `cookie-manager` / `cookie-data-protection`：凭据获取与保护；本 skill 不授权真实凭据操作。
- `tcdoc-sync-scope`：腾讯文档写入白名单；Adapter 只读/写回都不得越界。
