# 抖音弹幕录制工具 - 部署说明

## 1. 环境准备
在使用本工具前，请确保您的电脑已安装 Node.js。
- **Node.js 下载地址**：https://nodejs.org/
- **建议版本**：v18.0.0 或更高版本

## 2. 安装步骤
1. 打开文件夹，在地址栏输入 `cmd` 并回车。
2. 在弹出的黑色窗口中输入以下命令进行安装：
   ```bash
   npm install
   ```
3. 等待安装完成（如果网络较慢，建议使用淘宝镜像安装）：
   ```bash
   npm install --registry=https://registry.npmmirror.com
   ```

## 3. 运行工具
安装完成后，您可以直接双击运行根目录下的：
- **`start.bat`** (推荐：会自动启动后端并打开浏览器)

## 4. 常见问题
- 如果运行报错提示“找不到模块”，请删除 `node_modules` 文件夹后重新执行 `npm install`。
- 确保您的网络状态良好，以便程序能实时连接到抖音直播间。
