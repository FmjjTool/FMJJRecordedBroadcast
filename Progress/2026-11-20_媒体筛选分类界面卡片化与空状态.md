# 2026-11-20 媒体筛选分类页界面卡片化 + 空状态补全

## 问题

用户截图：媒体筛选分类页顶部两行是裸控件堆叠，三栏没有卡片容器，文件列表 / 预览 / 分类文件夹 / 文件信息在无内容时全是空白白块，视觉上和「套版封面」页差距明显。诉求：参考套版封面的卡片式界面优化。

## 根因

- `image_sorter.py` 的 `_init_ui` 直接往页面根布局塞 `QHBoxLayout` 与各面板，页面外边距只有 4px，没有 `variant="toolbar" / "card"` 语义容器，按钮全部默认样式、无图标。
- 各面板自带一套硬编码浅色标题与白底列表（`#ffffff` / `#2f3440` 等），与主题体系脱节，深色下靠历史 remap 勉强可用。
- 四个区域都没有空状态：左栏空列表、预览黑底、分类文件夹空列表、右侧信息区都只是纯空白。
- 副标题重复：右侧 `文件信息` 页签下又有一层「媒体信息」标题；文件夹面板在窄栏里 6 个按钮挤成一行会被裁切。

## 改动

| 文件 | 改动 |
| --- | --- |
| `src/gui_qt/pages/image_sorter.py` | 页面外边距 16、间距 12；两条 `variant="toolbar"` 工具栏（源文件夹 / 分类工作流），按钮改用 `variant` + `line_icon` 线形图标并补 tooltip；新增「处理状态」`variant="subtle"` 状态条；三栏改用 `variant="card"` 卡片（标题 `role="sectionTitle"` + 右侧 caption：视图模式 / 当前文件名）；页内设置区改 `variant="subtle"`；`设置` 按钮改为可勾选并同步展开状态；分栏手柄 10px；新增 `on_theme_changed()` 重画图标 |
| `src/gui_qt/pages/image_sorter_widgets.py` | 文件列表去掉自带标题与白底边框（交给卡片），新增「还没有可筛选的文件」空状态并在加载/空/有内容三态间切换；预览区新增居中空状态提示，未选中时隐藏 100% 与 0/0 角标；文件信息面板改 `variant="card"`，删掉重复的「媒体信息」标题、三个操作为 ghost 按钮、标签页面板去边框透明化、新增空状态；重命名页的标题/提示/主按钮改用 `role` / `variant`；修掉信息行 `deleteLater` 残留（先 `setParent(None)`） |
| `src/gui_qt/pages/image_sorter_folder_panel.py` | 面板改为卡片（标题 `role="sectionTitle"` + 排序下拉）；面包屑只在进入子目录后显示；文件夹列表去白底边框；新增两种空状态（未设置工作目录 / 目录内没有文件夹）；操作按钮拆两行（创建/重命名/删除/刷新 + 复检此夹/返回源目录），加 `variant` 与线形图标；主题切换时重画卡片图标与按钮图标 |

刻意未动：`theme.py` / 全局 QSS / 配色，未新增任何十六进制颜色（沿用 `palette(...)`、`variant`、`role` 与既有线形图标）。
