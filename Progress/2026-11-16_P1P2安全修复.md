# P1 / P2 安全与数据正确性修复

日期：2026-11-16

## 问题与方案

1. **P1：剪辑合并删除源视频或已有输出。** 切割前校验输出与源文件的真实路径及文件身份；已有输出使用递增文件名。合并在输出目录内的临时目录完成，确认产物有效且未取消后才重命名落盘，失败不删除原文件。
2. **P1：配置导入覆盖源码。** 模块文件严格限制为已有的四项账号配置；增加相对路径及解析后目录范围校验，并在全包预检通过后才开始写入。
3. **P1：腾讯文档回写越界。** 界面仅允许指定汇总库的官方动态（`ss_h2uh2s`）与直播记录（`ss_1xgstm`）。底层用官方转换接口确认的文档身份校验写入目标，同时拒绝表结构修改和缺少行定位的更新、删除。读取其他表不受写入限制影响。
4. **P1：直播状态接口失败导致漏录。** 区分未知直播状态与确认关播；查询失败保留原状态和录制任务。开播状态与当前是否取得可用流地址分别处理，取流失败不会触发关播。
5. **P2：分段下载错误地报告成功。** 校验 HTTP 206、Content-Range、响应编码、分段边界和最终文件长度；分段响应异常后清理临时文件并回退单流重下，取消时不回退。
6. **P2：部分表格采集缓存成功版本。** 未采集完整时清除文档版本缓存，保证相同远端版本仍会补采；仅完整采集且 Excel 导出成功时缓存新版本。
