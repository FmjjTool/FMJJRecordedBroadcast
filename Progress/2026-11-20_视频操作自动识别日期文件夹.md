# 2026-11-20 视频操作页自动识别日期文件夹

## 需求

- 用户：「视频操作识别逻辑，不要手动扫描，需要和交互式重命名一样，支持自动点入后获取」。
- 现状：`EditorPage` 进入页面只恢复上一次的预览，左侧队列必须点「扫描工作目录」才会按递归方式收集整个工作目录的视频。
- 交互式重命名（`RenamePage`）的口径：进入页面自动扫描全部日期文件夹、自动点入第一个文件夹并载入其中视频，不需要任何手动扫描。

## 处理方案（用户确认的两点）

1. 自动获取范围：自动进入**最新日期文件夹**（工作目录下 `YYYYMMDD`，按名称升序取最后一个），只载入该文件夹内的视频；无日期文件夹时回退递归扫描工作目录（仅队列为空时）。
2. 与现有队列共存：「和交互的逻辑一样，加载所有日期文件夹」——左侧新增「日期文件夹」下拉，列出工作目录下全部日期文件夹；进入页面自动点入最新一个，点选其它文件夹即载入该文件夹的视频。

实现要点：

- 识别统一走 `toolbox.date_folders.scan_date_folders()`（与交互重命名同一份日期文件夹识别、同一份跳过目录配置），不另写一套正则。
- `_sync_folders()`：重建下拉 → 有日期文件夹时选中「当前自动文件夹」或最新一个 → `_load_folder()`；队列是手动添加/「扫描工作目录」得到的（`_auto_folder is None`）时只让下拉跟随显示，不覆盖队列。
- `_load_folder()`：`find_videos_in(folder)` 取该文件夹视频，队列替换为该文件夹内容并载入第一个预览；文件集合没变时直接返回，保留当前播放进度与已标记切割片段。
- `add_dropped_files()`（手动添加文件/文件夹、转换页扫描都会走这里）把队列标记为手动，自动识别不再覆盖。
- `on_show()` 每次进入页面都同步一次（新录的日期文件夹会出现在下拉里），`on_dir_changed()` 在工作目录切换时重扫并载入；原本只刷新转换提示的 `on_dir_changed` 与新方法重名会互相覆盖，已合并为一个生命周期方法并上移到 `on_show` 旁边。
- 原有「扫描工作目录 / 添加文件 / 添加文件夹 / 按名排序 / 移动 / 删除 / 清空」按钮全部保留；「扫描工作目录」保留为无日期文件夹时的兜底。

## 验证结果

- `python -m compileall -q src` 通过。
- 离屏功能烟测（临时工作目录：`20261118` 两个视频、`20261119` 一个视频、根目录一个视频）：
  - 首次 `on_show()`：下拉 `["20261118", "20261119"]`，自动点入 `20261119`，队列 `["b1.mp4"]`。
  - 下拉切到 `20261118`：队列变为 `["a1.mp4", "a2.mp4"]`。
  - 选中第 2 个文件并标记片段后再次 `on_show()`：文件集合未变，片段 `[(0, 1000)]` 与当前行保留。
  - 手动加入根目录视频后再次 `on_show()`：队列保持 3 项不被覆盖。
  - 自动来源的队列在工作目录切换后按新目录重建；手动队列在目录切换时保留。
  - 工作目录无日期文件夹：回退递归扫描，下拉置灰禁用。
- 全量离屏测试 **678 项全部通过**（`QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests`）。
