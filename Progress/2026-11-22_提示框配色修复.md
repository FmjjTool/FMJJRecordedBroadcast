# 提示框（ToolTip）深色下整块发黑

## 现象

深色主题下，鼠标悬停按钮时提示框是一块纯黑矩形、看不到任何文字；浅色系统上则退回 Windows 原生浅黄底（`#ffffe1`）配浅色文字，同样几乎读不出来。

## 根因

`src/gui_qt/theme.py` 的 `NEUTRAL_QSS` 里 `QToolTip` 规则用了错误的调色板角色名：

```css
/* 错 */ background: palette(tool-tip-base); color: palette(tool-tip-text);
/* 对 */ background: palette(tooltip-base); color: palette(tooltip-text);
```

Qt 样式表的 `palette(...)` 只认 `QPalette` 角色表里的名字（`tooltip-base` / `tooltip-text`，中间没有第二个连字符）。名字写错时 Qt **静默丢弃整条声明**、不报任何日志，于是提示框没有自定义底色和文字色，退回系统原生绘制 —— 深色 Windows 下交给系统画黑底，浅色下是经典浅黄底，两种都跟主题对不上。

自检确认：用 `QPalette` 角色名逐个比对 Qt6Gui.dll 里的角色字符串，只有 `tooltip-base` / `tooltip-text` 存在；`tool-tip-base` / `tool-tip-text` 完全不存在。全仓 `palette(...)` 扫描也只剩这一处写错。

## 修复

- `src/gui_qt/theme.py:68`：`tool-tip-base` → `tooltip-base`、`tool-tip-text` → `tooltip-text`。只改这一行的两个角色名，其它配色、QSS 结构未动（符合「全局配色不得改动」约定，这里修的是失效的引用而不是改颜色）。

## 验证

真实 `windows` 平台抓 `QTipLabel` 控件像素（`Progress/ui/2026-11-22/tooltip_compare.png`）：

| 主题 | 修复前 | 修复后 |
| --- | --- | --- |
| 深色 | `#ffffe1` 底 + `#dce5f3` 字（原生黄底浅字，实机上为整块黑） | `#243044` 底 + `#dce5f3` 字，边框 `#303e52` |
| 浅色 | `#ffffe1` 底 + `#dce5f3` 字 | `#ffffff` 底 + `#263449` 字，边框 `#dce3ed` |

- 新增 `tests/test_theme_tooltip.py` 2 项：① `NEUTRAL_QSS` 里所有 `palette(...)` 角色名必须在 Qt 角色表内；② `QToolTip` 必须同时定义 `tooltip-base` 与 `tooltip-text`（防止再写错名字静默失效）。
- 主题/UI 相关用例 49 项通过（`test_theme_tooltip`、`test_emoji_strip`、`test_backup_panel`、`test_home_drawer_fit`、`test_cover_maker_page`、`test_certificate_maker_page`）。
- 全量 758 项：4 项既有失败（`test_page_preload` ×3、`test_page_index` ×1，与本次改动无关）；`test_live_workflow.UploadPipelineTests.test_upos_chunks_csrf_and_duplicate_submission` 在全量里失败、单独跑 19 项全通过，属既有顺序相关抖动。

## 生效方式

需完全退出程序（含托盘）后重新启动，旧进程仍是旧代码。
