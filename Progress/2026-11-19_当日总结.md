### 处理方案

- 新增 `src/toolbox/timecode.py`：
  - `parse_start_time()` 从文件名解析录制起点（`主播_20261116-183009.ts` / `日期_时-分-秒` / `日期_时分秒`），非法日期返回 `None`；

- 文档：`software-feature-guide` 直播录制章节补「工具 → 写时间码」。

## P1：录制时间轴锚点（墙钟 ↔ 视频时间）

### 需求

- 在 P2（写容器时间码）之后补 P1：录制时记录首帧墙钟与视频 PTS 的对应关系，供弹幕对齐与写时间码使用，精度目标 <0.5 秒。

### 处理方案

- 新增 `src/toolbox/timeline.py`：
  - `TimelineRecorder` 每场录制写 `<视频主干>_时间轴.json`，结构 `{version, platform, room, base, created, files:[{file, anchors:[{pts_ms, wall_ms}]}]}`，每加一条锚点立即原子落盘（崩溃不丢，写失败不影响录制）；
  - `video_ms_for_wall()` / `wall_ms_for_video()` 分段线性换算：两条锚点之间按 PTS 增量截断，断流停顿段不外推（画面停在原处）；
  - `start_datetime()` 取首帧锚点，供「写时间码」当起始时间。
- 采集端接线（`live_record.py`）：
  - `FfmpegRecorder` 新增 `on_media_start(wall_ms, file, pts_ms)`：TS 管道模式在写入第一段字节时回调（精确到秒内）；直写 FLV / 分段模式用 1 秒轮询输出文件，出现即记锚点（误差 ≤1 秒）；分段文件各自 pts 从 0 起算；
  - `StreamDownloader` 在每段文件真正写入首批字节时回调；
  - `RecordManager.start_record` 建时间轴并注入回调，断流续录时以 `-output_ts_offset` 为 pts 追加新锚点。
- 「写时间码」联动：起始时间优先取时间轴首帧锚点，没有时间轴才退回文件名时间；对话框选中文件时打印「已读到录制时间轴（首帧锚点）」。

### 验证结果

- `python -m compileall -q src tests` 通过。
- 新增 `tests/test_timeline.py` 9 项：文件名/读写/空文件/坏 JSON、暂停段映射（不外推）、正反换算、未知文件、`FfmpegRecorder` 首帧回调（真实 ffmpeg 管道，回调墙钟与当前时间差 <60 秒、pts=0、文件非空）全部通过。
- 全量离屏测试：**515 项全部通过**。
- 联调：给 3 秒 ts 写一条首帧锚点后，`TL.video_ms_for_wall(锚点+5s)=5000`；`write_timecode()` 自动改用时间轴时间（日志显示「起始时间取自录制时间轴（首帧）」），读回 tmcd 一致。

  - 文字颜色取 `palette(ButtonText)`，浅色 / 深色主题都跟随。

## 版权写入：Windows 不显示 MP4 版权，改用「标准版权 + 备注」双写

### 需求

- 用户实测「交互重命名 → 写入版权属性」后，资源管理器 属性 → 详细信息 → 版权 仍为空。

### 排查结论（本机实测）

- ffmpeg `-metadata copyright=…` 对 MP4 写的是 `cprt` 标签，ffprobe/mutagen 都能读到；追加 `©cpy`（iTunes 键）也写了。
- 用 Windows Property System 读取（`propsys.PKEY_Copyright`）仍是 `None`；同一文件 `PKEY_Title / PKEY_Comment / PKEY_Author / PKEY_Music_Artist / PKEY_Music_AlbumTitle / PKEY_Music_Genre / PKEY_Media_Year` 都能读到。
- 结论：**不是写失败，是 Windows 资源管理器不映射 MP4 的「版权」字段**（标题、备注、作者等正常）。因此无法让「版权」这一行显示内容。

### 处理方案

- 新增 `src/toolbox/video_meta.py`（L3/L5，页面不再自己拼 ffmpeg）：
  - `write_copyright()`：重封装备份到临时目录 → 写 `copyright` → mp4/mov/m4v **同时写 `comment=版权：<文本>`** → 读回校验 → 核对来源未变 → `os.replace` 替换；失败保留原视频。
  - `read_copyright()` / `read_tags()`：用 mutagen 读 `cprt` / `©cpy`。
- `gui_qt/pages/rename.py` 的 `_write_copyright_metadata()` 改为调用该模块；两处「写入版权属性」勾选框加 tooltip 说明「MP4 资源管理器不显示版权，看备注」。
- 成功提示改为「版权已写入；资源管理器不显示 MP4 版权，已同时写入『备注』……」。

## B站投稿：修 2 GB 以上进度溢出，按 biliup 改线路探测与并行分片

## 网盘文件下载：支持分享选中项 + 列头排序

### 需求

### 处理方案

- **分享**：`quark_download` 新增「分享选中」按钮。优先取勾选的文件；没有勾选时取当前选中行（这样文件夹也能分享，文件夹本来没有勾选框）。弹窗填名称、有效期、是否带提取码；确认后后台调用 `QuarkClient.create_share`，结果写入右侧日志、自动复制链接到剪贴板并 toast。非夸克网盘提示「暂不支持」。
