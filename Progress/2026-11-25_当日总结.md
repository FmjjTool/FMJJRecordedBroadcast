## 任务六十五：批量改名「按类型删除」在 Web 端放开

### 先纠正一处口径

桌面「批量改名 → 删除」页签里的「按类型删除」并不是删除文件，而是**从文件名里删掉某类字符**（空格 / 数字 / 小写 / 大写 / 中文 / 特殊字符），同页签还有「按位置删除」「按关键词删除」。页面与引擎都不含任何删文件逻辑。
此前我在进度里把它写成「永久删除文件」，属于我的描述错误；本轮按桌面真实语义接入，Web 端不需要「输入文件名确认」这类删文件级确认（改名本身已有二次确认 + 预览）。

### 处理

- `src/toolbox/webui_rename_batch.py`：`_cfg_from_options` 把 `del_types` 做白名单校验（space / digit / lower / upper / chinese / special），并把 `del_pos` / `del_cnt` / `del_from_right` / `del_kw` / `del_kw_cnt` / `del_dir` / `del_incl` 映射进 `cfg["del"]`（原先是 `{"types": []}` 占位，规则永远不生效）。
- `src/toolbox/webui/services/rename_batch.py`：`_options` 透传上述 8 个字段。
- `src/toolbox/webui/static/app.js`：「按类型删除」从折叠 `<details>` 里提出来，放进「改名规则」卡做常显区块（类型勾选 + 从第 N 位删 M 个可反向 + 关键词定位左右删 N 个可选包含关键词），并补事件绑定——勾选 / 输入后 450ms 自动重算预览，不再需要手动点「扫描预览」。
