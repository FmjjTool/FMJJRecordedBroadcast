# 2026-09-30 下载全入口多线程统一 + 全局下载浮窗（下载中心）

用户要求：**排查所有下载入口的多线程情况，统一改成多线程；进度不要在原页面 UI 上逐行刷新，用浮窗形式集中展示**（类似资产管理的浮窗体验）。背景：批量下载多为串行 + 页面内嵌进度（已获取页/批量导入页的内嵌 DownloadPanel、资产页的模态 QProgressDialog），下载期间页面被进度刷屏、批量串行慢，且资产页模态进度框曾是「下载完成后未响应」的嫌疑场景之一。

排查结论：项目里原本**没有**现成浮窗，最接近的是 download_panel.py 的内嵌 DownloadPanel（IDM 槽位风格）与 toast 的无边框风格——本次以「浮窗容器内嵌 DownloadPanel」组合实现。

## 新增：全局下载浮窗（src/gui_qt/download_float.py）

- `DownloadFloatWindow`：无边框 Tool 窗口（`Qt.Tool | Qt.FramelessWindowHint`），贴主窗口右下角，标题栏（⬇ 下载中心 + 批次数 + 收起 + ✕隐藏）可拖动（拖过不再自动贴角）
- `BatchCard`：一个下载批次一张卡片 = 头部（📦 来源 + 汇总 + 取消[可选] + ✕关闭卡片）+ 内嵌 DownloadPanel
- 关闭卡片/浮窗**只隐藏进度不取消任务**，下载继续后台跑（回调链全程吞异常，窗口销毁后渲染失败不影响下载线程）；卡片自带「取消」按钮走 cancel_cb（资产页接 cancel_ev）
- 全局单例 `get_float()`：主线程调用，自动从 topLevelWidgets 找主窗口挂靠；跨线程进度统一走 `card.handle_event(event, *args)`（内部 post_to_main，事件协议 plan/start/bytes/seg/done/skip 与 DownloadPanel 一致）
- 批次互不干扰：并发多个下载入口时各开一张卡片
