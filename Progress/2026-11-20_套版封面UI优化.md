# 2026-11-20 套版封面制作页 UI 优化

## 需求

用户截图指出「套版封面制作」页面：左栏内容被横向裁切（路径文字溢出、"重新扫描"按钮被滚动条压住）、三组字段各占 5 行导致必须滚动、顶部工具栏分成两处、预览区一片空黑，要求优化 UI。

## 选型与边界

- 只改这一个页面（`src/gui_qt/pages/cover_maker.py`），不动 `theme.py`、全局 QSS、配色与渲染引擎。
- 按 `ui-visual-spec` 落地：页面顶端不再放页面标题；颜色只用 `palette(...)` / `theme(...)` 角色；按钮用 `variant` 语义属性；结构性图标统一 `line_icon`；字号收敛到 10/11/12/13/14 阶梯；间距用 4/6/8/12。
- 字段面板采用用户确认的「紧凑卡片 3 行」方案（另两个候选「折叠面板」「顶部标签页」未采用）。
- 不新建页面、不新增管理入口，页面注册名 `cover_maker` 与配置节 `cover_maker` 不变。

## 改动清单

| 文件 | 改动 |
| --- | --- |
| `src/gui_qt/pages/cover_maker.py` | 重构页面骨架与字段面板：见下 |
| `tests/test_cover_maker_page.py`（新增） | 14 项离屏冒烟：紧凑布局、底图区并入顶栏、同步样式、Y 轴百分比、拖动、重置、导出分辨率、复制、配置往返、主题切换 |
| `src/skills/software-feature-guide/SKILL.md` | 「套版封面制作」章节按新界面改写字样 |

界面改动：

1. **顶部工具条合并为一条**（`QFrame variant="toolbar"`）：「底图文件夹路径（中间省略，tooltip 全路径）+ 张数 + 更换文件夹 / 重新扫描」放在左侧（原左栏「底图」卡片整块搬过来），右侧「底图适配 + 随机底图 / 选择底图 / 上传图片」，按钮带线形图标；删掉页面内的「套版封面制作」标题。
2. **左栏只剩一张文字样式卡**：标题+「同步 字体/颜色/字号」、三组字段、底部「整体 Y 轴 + 重置位置」；模板按钮单独一行。底图卡片删除（内容已并入顶栏）。
3. **字段面板从 5 行压到 3 行**：字段名+对齐 / 文本输入 / 字体+字号+颜色+B+I 同一行；字号滑条换成数字框（两位数字完整可见，宽 72）；底图路径用中间省略（`ElidedLabel`，完整路径进 tooltip）；左栏关闭横向滚动条，路径与按钮不再被裁剪。
4. **右栏**：预览放进卡片（圆角裁切 + 边框），卡片顶部一行显示「当前底图：xxx」（中间省略，完整路径进 tooltip），画布外留白用 `alternate-base` 不再是大白块；无底图时画布内画虚线空状态（无文字时给「暂无底图 + 操作引导」，有文字时只在顶部提示「当前无底图」，不压文字）；底部导出条统一放「分辨率 + JPG 质量 + 复制 / 导出 PNG / 导出 JPG（主按钮）」。
5. **文案与提示**：占位符缩短为「封面标题 / 日期，如 2026-09-05 / 备注（可换行，留空不显示）」；原左栏两行长说明与底部长状态栏移入 tooltip。
6. **Y 轴改用百分比**（-30%~+30%，步进 0.5%），配置里仍按画布比例存 `y_shift`，旧配置读写不变。
7. 顺手修掉一个既有隐患：预览节流定时器改为在构建控件前创建，避免恢复非零 Y 值时 `valueChanged` 早于 `_debounce` 初始化而报 `AttributeError`。
