## 新增 skill：标准版 / FULL 内置版双形态发布

### 需求

用户要求写一个 skill，为后续增加「FULL 版 / 普通版」做准备：普通版就是当前形态，FULL 版内置一切（FFmpeg 等外部工具与组件），做到安装后开箱即用。

### 方案

新增 `src/skills/release-editions/SKILL.md`，把双形态发布固化为可执行规则，而不是只写一句「以后做 FULL 版」：

- **两版本边界**：共用一份代码、一个 `APP_VERSION`、一个 Inno AppId、一个 GitHub Release；FULL 只作为同版本额外资产（`FengMingToolbox_Full_Setup_<ver>.exe`），`SHA256SUMS.txt` 含两行。
- **FULL 内置清单**：ffmpeg/ffprobe（`<app>\bin`）、Playwright headless shell（`<app>\browsers`）、whisper-faster 程序与 base 模型（`<app>\models`）、CLIP 模型（`<app>\models\clip`）、node（`<app>\bin\node`）；7-Zip 已随包。
- **查找顺序契约**：ffmpeg 沿用现有 `_bundled_binary`；node 需新增「包内回退」（现在只查 PATH）；Playwright 需在 frozen 态优先包内 `browsers/`，且 `PLAYWRIGHT_BROWSERS_PATH` 必须在 `sync_playwright()` 前设置；CLIP 需新增包内 `models/clip` 回退（现在只认 `config/models`）。
- **更新契约**：`updater` 按 edition 严格筛选资产，标准版只匹配 `FengMingToolbox_Setup_`，FULL 版只匹配 `FengMingToolbox_Full_Setup_`，禁止串包。
- **不做的部分**：FULL 默认只内置 `base` 转写模型与 headless shell，不内置完整 Chromium（436.4 MB）、不复制本机 `models/`（含 small 463.7 MB 与缓存）。
- **落地分级**：P0 代码契约（edition 标记、内置回退、面板「已内置」）→ P1 构建与发布（`--edition full`、双产物、两行 SHA、FULL 烟测）→ P2 体验（安装时选版本、跨版本切换提示、体积优化、第三方声明）。
