# 页面切换误弹 python 空白窗口修复

## 问题

切换部分页面时，主窗口上方偶尔闪现一个标题为 `python` 的空白小窗口。用户截图出现在从自动整理切向视频转换时。

## 根因与修复

共享 `ToolPageHeader` 创建说明 `QLabel` 时没有指定父组件，又在加入布局前执行 `setVisible(True)`。Qt 将此时无父组件的标签视为独立窗口并显示；随后布局接管标签，窗口又被收回，因此表现为短暂闪窗，静态截图或最终 `topLevelWidgets()` 检查容易遗漏。

Windows 原生事件记录已复现改前行为：标题组件构造期间出现无父组件 `QLabel` 的顶层 `Show` 事件，尺寸约 273×36（内容区，未计标题栏）。

修复只修改 `src/gui_qt/toolbox_common.py`：

- 标题和说明标签创建时即指定标题组件为父组件。
- 说明标签先加入布局，再根据内容设置可见性。
- 非空说明继续显示，空说明继续隐藏；标题样式、换行、间距及各页功能保持。

此共享组件由视频转换、已获取和账号管理设置使用，三处一并修复。
