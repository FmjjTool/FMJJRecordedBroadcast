# 2026-11-20 顶部面包屑基线对齐 + 页面注册表单一事实来源（P0+P1）

## 问题

用户截图「信息工具 / 视频评论区」：分组名与页面名不在同一条基线上；并追问页面名是不是硬编码、有没有统一索引。

## 根因

- 顶栏是两个独立 `QLabel`（11px 分组名、14px 粗体页面名），各自垂直居中；字号不同时中心对齐、基线差约 2px，看起来就是小字偏高。
- 名称分散在 `NAV_GROUPS`、`_EXTRA_TOOLS`、`containers.InfoToolsPage` 页签标题、`home.py` 卡片表、`NAV_SEARCH_ALIASES`、`PAGE_ALIASES` 六处，改一处容易漏。

## 改动

| 文件 | 改动 |
| --- | --- |
| `src/gui_qt/page_index.py`（新增） | 页面注册表（唯一注册处）：`PageMeta`（标题、分组、页面类 module/cls、搜索别名、首页卡片短名/说明、底部按钮短名、预载开关、所属容器、容器页签分组）+ `PAGE_INDEX`（42 个 key）+ 派生 `PAGE_CLASSES` + `NAV_LAYOUT` + `HOME_COMMON/HOME_INFO` + `ALIASES`；提供 `page_meta / nav_groups / nav_keys / search_aliases / container_tabs / preload_keys` |

| `tests/test_page_index.py`（新增） | 10 条一致性断言：页面类 ↔ 索引、侧栏 ↔ 索引、别名目标、容器页签、首页卡片、搜索旧名、预载排除、底部按钮 |

## 分级落地

- **P0**：索引骨架 + 只读接入（侧栏 / 面包屑 / 搜索面板），文案逐字照抄。
- **P1**：删掉四处字面量，容器页签、首页卡片、预载队列、底部按钮统一从索引取。
- **P2（按用户要求调整）**：不做 JSON/YAML 外置，改为把**页面类路径也并入 `page_index.py`**——`PageMeta` 增加 `module` / `cls`，`PAGE_CLASSES` 由 `PAGE_INDEX` 派生，`main_window` 不再维护类注册表；以后新增页面只改 `page_index.py`（元信息 + `NAV_LAYOUT` / 首页列表）。
- **刻意未做「统一叫法」**：首页卡片「音乐下载」与侧栏「下载」、搜索旧名（如「信息获取」）都按原样保留；前者用 `card_title` 表达，后者进 `aliases`，需要你确认统一方向后再改文案。

## 面包屑层级（追加）

按用户要求改为三级：`分组（一级）/ 页面名（二级）/ 容器内页签（三级）`，例如「内容采集 / 采集工具 / 视频评论区」；普通页面两级（「资产管理 / 资产库」）。三级都从 `page_index` 读取，整条面包屑是一段富文本，共享基线；`tab_group` 字段随之删除。
