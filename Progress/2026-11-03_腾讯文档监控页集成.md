# 腾讯文档监控集成进工具箱（2026-11-03）

## 需求
把独立工具 `D:\PythonApps\腾讯文档数据保存`（腾讯文档浏览量 / 文档成员数每日记录）
做进工具箱，UI 保持统一；后续要能自定义文档。

## 改动
- 新增引擎包 `src/toolbox/tcdoc/`
  - `config.py`：文档清单（`tcdocs` 配置键，支持任意数量自定义文档）、
    链接解析（sheet / smartsheet / aio / doc / slide / form 等不锁死类型白名单）、
    导出路径（`download/腾讯文档数据/`）、登录态路径（`config/tcdoc_state.json`）
  - `storage.py`：SQLite 两表（daily 每次采集一行 / snapshots 采集明细），
    增量相对上一次采集，`refresh_deltas` 按采集时间重算，`import_legacy` 按
    (doc_key, ts) 幂等合并旧库
  - `collector.py`：Playwright 采集（接口优先 → 界面兜底，aio 无浏览量），
    浏览器统一走 `toolbox.browser.launch`（不再自维护渠道）
  - `report.py`：每文档一份 Excel（每日记录 / 采集明细），新增「已查看人数」列
  - `job.py`：采集编排 + 日志 + 报表重建（GUI 与定时任务同一链路）
  - `task.py` / `run_job.py`：Windows 计划任务（FengMingTCDocMonitor）
- 新增页面 `src/gui_qt/pages/tcdoc.py`（信息获取组「📄 腾讯文档监控」）
  - 标题 + ❓功能介绍浮层 + 白卡片 + 三 Tab（历史记录 / 采集明细 / 文档管理）
  - 底部设置行：定时采集时间、安装/删除计划任务、采集时隐藏浏览器窗口
  - 文档管理 Tab：添加 / 编辑 / 删除（可选连历史一起删）/ 生成诊断包 / 重建全部报表
- `config_manager.py`：登记 `tcdocs`(默认 None=用预置 4 个文档)、`tcdoc_collect_time`、
  `tcdoc_headless`、`tcdoc_legacy_migrated`；导出分类新增 `tcdoc` → 腾讯文档数据
- `main.py`：`--tcdoc-collect` 参数（打包后计划任务用，不加载 Qt）
- README：页面清单 35→36、目录结构补 `tcdoc/`

## 旧数据搬迁
- 旧库 15 条每日记录 / 26 条采集明细全量并入新库（与旧 Excel 的 4/5/3/3 行完全对齐）
- 旧登录态复制为 `config/tcdoc_state.json`，无需重新扫码
- 4 份报表按新格式重建到 `download/腾讯文档数据/报表/`（多出「已查看人数」列）
- 当前新库：19 条每日记录（15 旧 + 4 新）、30 条明细

## 踩坑
- 迁移标记曾被提前置位而旧数据没导进来 → 导入改为幂等合并 + 按 `ts` 排序，
  并把「迁标记 + 导入」顺序理清（导入成功后才置位）
- 全新安装 vs 用户删空清单：默认值用 `None` 区分，删空写 `[]` 不再复活预置文档
- `report.build_report` 只接受 Path，冒烟传 str 直接崩 → 入口统一 `Path(...)`
- 环境策略禁用 `schtasks.exe`：`task._run` 改为捕获 OSError 返回失败结构，
  不再让界面抛异常
