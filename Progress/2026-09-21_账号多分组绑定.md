# 账号多分组绑定（2026-09-21）

## 需求
账号获取页和账号追踪页，一个账号需要能绑定多个分组。

## 现状分析
- **账号获取**主界面：添加账号的组号是手输文本框，`accounts_manager.py` 数据层已支持多组（`group_ids` 列表、逗号分隔解析、`get_accounts_by_group` 用 `in` 匹配）——无需改
- **账号获取**设置页：添加账号和已配置账号列表都是单选下拉（`set_group_sel` / `gsel` QComboBox）——只能绑一组
- **账号追踪**：数据层 `tracker/accounts.py` 只有单一 `group_id` 字符串，UI 两处也是单选下拉

## 修改内容

### 1. 新共用控件 `gui_qt/row_widgets.py` → `GroupMultiSelect`
QPushButton + 弹出勾选菜单（每个分组一个 checkable QAction + 底部「无分组（清除全部）」）：
- `set_groups({组号: 组名})` 刷新可选组（保留已选交集，组被删后自动清掉）
- `set_selected(["11","22"])` / `selected()` → 列表
- 按钮文本：`无分组` / `组11+22`，tooltip 显示组名全称
- 勾选变化发 `changed` 信号（启用「保存全部修改」）
- 注意不能用 `QPushButton.setMenu()`（Qt 点击自动弹菜单与手动弹冲突），改为 clicked 手动构建+exec

### 2. 账号追踪数据层 `tracker/accounts.py`
- `group_id`（字符串）→ `group_ids`（列表），`_norm_account` 兼容旧数据（单一组号 / 逗号分隔串均自动转列表），读取后 `group_id` 键移除，保存即迁移为新格式
- `delete_group`：从各账号组号列表中移除该组（不再清空整个绑定）
- `get_accounts_by_group`：`gid in group_ids`（任一命中），按组导出 PNG 自动支持多组

### 3. 账号追踪 UI `gui_qt/pages/tracker.py`
- 设置页「添加追踪账号」：组号单选下拉 → 分组多选按钮
- 「已配置账号」每行：组号单选下拉 → 分组多选按钮；`_save_all_account_groups` 保存 `group_ids` 列表

### 4. 账号获取设置页 `gui_qt/pages/info_accounts.py`
- 「添加账号」：组号单选下拉 → 分组多选按钮（`_add_set` 取 `selected()` 逗号串传 `add_account`，`_parse_group_ids` 已支持）
- 「已配置账号」每行：组号单选下拉 → 分组多选按钮（`set_selected(a.group_ids)` 显示全部绑定组）；`_save_all_account_rows` 传逗号串
- 主界面手输组号（逗号分隔）和「按组采集」单选下拉保持不变

## 验证
- `_norm_account`：旧字符串/逗号串/新列表/空 → 全部正确转列表
- `get_accounts_by_group`：账号绑 [11,22] 时组11、组22 查询均命中
- `GroupMultiSelect`（offscreen）：多选/显示/组删除后交集保留，全部通过
- `accounts_manager` 全链路：多组添加→txt 序列化→读回→更新→删组解绑，通过
- 4 个文件 `py_compile` 语法通过
