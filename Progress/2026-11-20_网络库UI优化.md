# 2026-11-20 网络库页 UI 优化（备份到网盘 + 文件下载）

## 需求

用户截了「网络库 → 备份到网盘」：页签下再套一层框、工具条占两行（一排按钮 + 一整行空进度条）、左右卡片里两段重复说明、备份条目被拆成四行且路径被强行换行。随后追加「文件下载也改一下」——该页原来工具条四行、动作按钮和保存路径混在一排、全选挤在工具条里。

### 备份到网盘

1. **去掉三层边框**：`QTabWidget#netdiskTabs::pane` 改成无边框、透明底；子页外边距改为 `0,12,0,0`，卡片与页签左边缘对齐。
2. **工具条单行**：`立即备份 / 停止 / 新增备份目录` + 240px 进度条 + 右侧状态文字（超长上传信息中间省略、悬停看全文），总高 56px。
3. **映射卡片三行**：后端标签 + 云端目录（加粗省略）/ `本地 D:\…` / `29 个文件 · 6.8 GB · 上次 … · 上传 6 · 跳过 0`；出现「失败」整行危险色；右侧图标顶对齐；条目高约 110 → 76px。
4. **说明去重**：删掉日志卡片上方独立的一行「定时备份已统一到『任务』页面……」，并进「备份目录」卡片描述；日志卡片描述只留 `config/quark_backup_task.log`。
5. **修残影**：`_render_list` 先 `setParent(None)` 再 `deleteLater()`，避免旧卡片与空状态叠在一起。

### 文件下载

1. **工具条四行 → 三行**：
   - 第 1 行：网盘下拉 + 上一级 + 面包屑（中间省略、tooltip 全文）+ 刷新；
   - 第 2 行：保存到 + 输入框 + 选择 + 「下载后自动解压」；
   - 第 3 行：下载选中（主按钮）/ 下载本文件夹 / 分享选中 / 停止 + 进度条 + 状态文字。
   工具条高度 148 → 139px，且每个控件的语义分组更清楚。
2. **「全选」移入「云端文件」卡片标题行**（与「N 项」并列），不再占工具条位置。
3. **文件夹行加文件夹线形图标**（`link` 色），文件行不显示图标；`on_theme_changed` 重画图标。
4. **长文本处理**：面包屑与状态文字改用 `ElidedLabel`（状态固定 240px、布局预留空间），长文件名不再把工具条撑破。
5. 去掉 `下载进度` 卡片外层多余的 QWidget 包装。

## 未验证 / 注意

- 没有真跑上传/下载（不碰真实网盘与本地大目录），进度/日志仍走原引擎，只改展示层。
- 页签面板改成无边框后，未在用户实机上核对过表格边线观感；要恢复页签框，改 `netdisk.py` 里 pane 样式那一行即可。
- `ElidedLabel` 的默认水平策略是 `Ignored`（配合 stretch 使用）；需要固定宽度时必须显式改回 `Preferred`，否则状态文字会溢出容器（本次踩到并已修正，下载页有注释）。
