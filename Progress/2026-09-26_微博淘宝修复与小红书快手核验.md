# 微博深翻页续抓、淘宝登录真实验证、小红书/快手能力核验与下载闭环（2026-09-26）

## 任务一：账号获取输入 0 提前停 + 淘宝登录状态无法验证

### 问题
1. 账号获取（微博）输入 0（无上限）时只抓约 11 条就停止
2. 淘宝 Cookie 登录状态从不联网校验，掉了也显示"已登录"，用户误以为淘宝有效/失效均无法确认

### 根因
1. **微博访客通行证只能翻 1 页**（实测 11 条后接口返回 ok!=1 断页）；原 `fetch_user_posts` 逻辑"访客有结果直接返回"，登录 Cookie 根本没用上
2. `whoami._taobao` 旧实现只读 Cookie 的 `unb` 字段拼"淘宝ID xxx"，无任何远程校验

### 方案与改动
| 文件 | 改动 |
|------|------|
| `src/platforms/weibo.py` | `fetch_user_posts`：访客拿不满 count 时接入登录 Cookie 从头续翻，按 mid 去重合并（游客拿满则不动 Cookie，游客优先不变）；`_try_api_fetch` 翻页加 0.5s 间隔降风控 |
| `src/tracker/whoami.py` | `_taobao` 改远程真实验证：复用商品采集同款 mtop `wandering.get`——ret 含 SUCCESS=有效 / SESSION_EXPIRED=失效 / RGV587=风控假响应（ok=None）；新增 `_tb_nick` 从 tracknick/dnk/_nk_ 解码昵称 |
| `src/shopping.py` | 新增 `get_verify_seller_id`/`_save_verify_seller_id`（采集成功时持久化卖家 userId 供验证用，内置 3697006383 兜底） |
| `src/toolbox/config_manager.py` | 注册 `taobao_verify_seller_id` 配置键 |

### 验证（真实网络实测）
- 微博 count=9999：访客 11 条 → Cookie 续抓合并 41 条，无重复，降序正常（仅置顶帖在首位，平台原生行为）
- 淘宝：用户 Cookie 调 wandering.get 返回 SUCCESS——**9-25 商品采集失败实为 RGV587 风控而非 Cookie 失效**，淘宝网页层(i.taobao.com)确实过期但 mtop 层有效，商品采集只依赖 mtop 层
- 回归：抖音 whoami 正常（昵称正确返回）

## 任务二：小红书/快手资料获取与下载核验 + 补链

### 问题
确认小红书、快手两个平台的视频资料获取和下载是否已实现；测试中发现缺口

### 结论
- 两平台解析器/账号获取/批量导入/GUI/whoami/账号名查询均已实现
- **快手单视频游客态完全可用**（3 条真实链接实测：字段齐全，直链含 .mp4，`download_media` 真实下载成功 0 失败）
- **小红书单条解析需新鲜 xsec_token**：官方已收紧，搜索引擎缓存的旧 token 全部失效（note=null），需 App 分享链接；小红书/快手主页作品（账号获取）均需对应平台 Cookie（用户当前未保存）
- **发现缺口**：小红书账号获取卡片条目 `video_url` 是笔记页链接，`media_downloader._is_direct_media_url` 不认 → 下载时视频被静默跳过（抖音/微博均有下载前刷新，小红书没有）

### 方案与改动
| 文件 | 改动 |
|------|------|
| `src/platforms/xiaohongshu.py` | `parse()` 加游客 → Cookie 两级兜底（游客无数据/xsec 校验过严时提高成功率） |
| `src/gui_qt/download_ops.py` | 新增 `refresh_xhs_urls`：下载前逐条 parse 回填真实视频流/图片/kind（已是直链跳过，间隔 0.5s）；接入混合下载路径 |
| `src/gui_qt/pages/info_results.py` | `_download_media` 接入 `refresh_xhs_urls` |
| `src/gui_qt/pages/info_parse.py` | 同上 |
| `src/gui_qt/pages/info_batch.py` | 同上 |

### 验证
- 快手 3 条真实视频 parse + 直链 HEAD（HTTP 206 video/mp4）+ `download_media` 端到端下载成功（视频 2.1MB + 封面，0 失败）
- `refresh_xhs_urls`：直链条目不动、页面链接条目解析失败不中断、非小红书条目忽略，全部通过
- 5 个文件 `py_compile` 通过；离屏冒烟测试通过（imports + config key + `_tb_nick` + 4 页面实例化）
