# 2026-11-20 抖音指数移入「账户追踪」

## 需求

- 用户要求把「抖音指数」从「内容采集 → 信息工具」移动到侧栏「账户追踪」组。
- 现状：抖音指数是 `InfoToolsPage`（信息工具页签容器：视频评论区 / 抖音指数 / B站资源 / 公众号解析）里的第 2 个页签，入口藏在容器内。

## 处理方案

- 导航归属：`NAV_GROUPS` 的「账户追踪」组在「网媒账号追踪」后新增 `("douyin_index", "抖音指数")`；「内容采集」组不动（`info_tools` 仍保留，只是少一个页签）。
- 形态：抖音指数按账户追踪组其他页面的惯例做成**独立侧栏入口**，不再作为信息工具页签（账户追踪组内音乐追踪、网媒追踪、腾讯文档监控、微博超话、粉丝群查询均为独立页面）。
- 路由：从 `_EXTRA_TOOLS`（会被重定向到 `info_tools` 的隐藏子页表）中移除 `douyin_index`。`PAGE_CLASSES` 原本就登记了 `douyin_index → DouyinIndexPage`，移除后 `show_page("douyin_index")` 直接打开独立页；面包屑因此显示「账户追踪」。
- 页签容器：`InfoToolsPage.TAB_KEYS` 与构造函数去掉抖音指数，剩「视频评论区 / B站资源 / 公众号解析」三个页签，`open_tab` 与 `_update_page_context` 的索引映射自动跟随。
- 首页快捷卡片：`home.py` 的 `INFO_TOOLS` 保留抖音指数卡片，点击经 `app.show_page("douyin_index")` 打开独立页（首页卡片是快捷入口，不按侧栏分组）。
- 图标：`navigation.py` 中 `douyin_index` 从「search」图标改为与追踪页一致的「chart」图标。
- 文档：README 当前功能介绍（信息工具页签列表、账户追踪表）与 `software-feature-guide` 的「抖音指数」章节同步入口位置。

## 判定依据（约定 12）

- 不是新增管理入口，只是把既有页面在侧栏换组；没有新数据实体、没有第二套事实来源，因此不新增「中心/管理器」，只更新 `software-feature-guide` 与 README，未改任何导航层级规范。
