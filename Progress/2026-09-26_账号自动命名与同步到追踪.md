# 账号自动命名 + 账号获取同步到追踪（2026-09-26）

## 任务一：账号录入名称留空时自动获取「昵称+平台」

### 需求
账号获取等需要录入账号的部分，增加自动识别名称：录入封茗囧菌的抖音但没填名称时，自动采用 `{昵称}{平台}` 形式（如「封茗囧菌抖音」）。

### 方案与改动
| 文件 | 改动 |
|------|------|
| `src/platforms/account_names.py` | 新增统一入口 `fetch_display_name`（视频平台优先识别，音乐平台兜底）与 `_append_platform`（昵称+平台拼接；昵称已以平台结尾则不重复拼） |
| `src/gui_qt/pages/info_accounts.py` | 主界面 `_add` 与设置页 `_add_set`：名称留空 → 后台线程自动获取「昵称+平台」→ 回填入库；占位符提示"留空自动获取" |
| `src/gui_qt/pages/tracker.py` | `_add_account`：名称留空 → 自动获取，失败回退「未命名」（保持原默认） |
| `src/gui_qt/pages/music_tracker.py` | 同上（音乐链接走网易云/QQ/酷狗/酷我/5sing 采集链路取昵称，如「封茗囧菌网易云」） |

覆盖全部 4 个账号录入点：账号获取主界面、账号获取设置页、视频账号追踪、音乐账号追踪。
获取在 `run_bg` 后台线程执行不卡 UI，期间按钮置灰防重复点击；失败不阻断添加（账号获取按无名称、追踪按「未命名」回退并 toast 提示原因）。

### 验证
- 真实网络：抖音主页链接 → 「歆慕抖音」；B站空间链接 → 「笔都吓掉了B站」
- `_append_platform` 防重复拼接 4 组用例全过（含空标签、已带平台结尾）
- 3 个页面离屏实例化通过；4 文件 `py_compile` 通过

## 任务二：账号获取 →「视频账号追踪」一键同步

### 需求
在账号获取页点同步按钮、确认后即可把本页账号同步到视频账号追踪，免得多次录入。

### 方案与改动
| 文件 | 改动 |
|------|------|
| `src/gui_qt/pages/info_accounts.py` | 全选行右侧新增 📤 同步按钮 + `_sync_to_tracker`；帮助浮层补同步说明 |

同步规则：
- 账号名/链接/平台/分组一并带过去
- **去重按 平台+ID**（复用 `tracker.accounts.parse_url`；识别不出 ID 的链接按完整 URL 去重），已存在跳过；全部已存在提示"无需同步"
- 分组带过去：追踪侧缺的组按同组号+组名自动补建（两侧组号规范一致：重复数字 11/22…）
- QMessageBox 确认框列出「共 N 个：新增 X、跳过 Y」+ 最多 8 条预览，Yes 执行 / No 取消

### 验证（备份真实数据 → 测试 → 已恢复原样）
- 实测：8 个源账号、追踪原有 5 个 → 同步新增 2、跳过 6（`共 8 个账号：新增 2 个，已存在跳过 6 个`）
- 幂等：二次同步全部跳过、数据零变更
- 分组 11:默认分组 两侧一致；字段结构（name/url/platform/group_ids）完整
