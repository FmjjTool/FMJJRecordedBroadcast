# 腾讯文档中间层同步、工具箱整理与 v3.0.0 发布

## 需求

- 腾讯文档监控新增「中间层同步」：比对本地已获取/增量库与腾讯表格，列出未上传条目，一键复制后手动上传。
- 支持单行/多行复制、发布时间精确到时分、图片检测与图片内容复制。
- 调整导航：腾讯文档监控移入「账户追踪」，账户追踪组置于录播工具箱与票务购物之间。
- 整理信息工具与 B 站资源入口，去除与信息获取重合的综合搜索。
- 本资料站复用腾讯文档监控本地库，避免重复联网拉取。
- 音乐标签精简顶部按钮与冗余菜单。
- 修复腾讯文档监控页构造时闪出空白小窗口。

## 方案与改动

### 中间层同步

- 新增 `src/toolbox/tcdoc/bridge.py`：合并「已获取」与 `increment.db`，按链接 → 平台 ID → 平台+日期+标题三级匹配；B 站视频与同分钟动态合并；输出 12 列 TSV（官方动态列标准 + 动态链接）。
- 新增 `src/gui_qt/pages/tcdoc_bridge.py`：页签/弹窗共用面板，支持文档/工作表、时间范围 7/30/90/全部、账号多选、单行/多行/全部复制、图片检测与图片内容复制。
- 腾讯文档监控页新增第一页签「🧩 中间层同步」，子页签顺序：中间层同步 → 表格同步 → 历史记录 → 采集明细 → 修订记录 → 成员名单 → 文档管理 → 映射回写。
- 图片：从封面与多图收集去重，表格新增「图片」检测列；下载到临时目录后以文件列表写入剪贴板，单张同时附带图片数据。
- 发布时间：输出 `YYYY-MM-DD HH:MM`。

### 导航与页面整理

- `main_window.py`：腾讯文档监控移入「👥 账户追踪」，该组移到录播工具箱与票务购物之间。
- `containers.py`：信息工具顺序改为 视频评论区 → 抖音指数 → B站资源 → 公众号解析。
- `bili_resource.py` / `bili_emoji.py` / `bili_garb.py` / `bili_info.py`：B 站资源从 8 个入口合并为 5 个；移除综合搜索；表情包与按 ID、装扮搜索与装扮详情分别合并。

### 本地资料站与音乐标签

- `webwiki/deploy.py`：`sync_docs` 改为直接读取 `download/腾讯文档数据/tables.db`，调用 webwiki-api ETL 重建 `webwiki.db`，不再联网、不再做版本号/强制全量判断。
- `localwiki.py`：按钮改为「重建站点数据」，移除强制全量勾选，更新说明。
- `music_tag.py`：顶部工具按钮缩小（图标 22→16、间距/内边距收紧）；移除帮助菜单、语言菜单、工具菜单里的设置项。

### 闪窗修复

- `tcdoc.py`：定时采集的时间输入框等控件在未归属页面时被 `setVisible(True)`，Qt 将其当作顶层窗口闪出。已让控件创建时指定父页面，并把可见性调用移到 `layout.addLayout(bottom)` 之后。
