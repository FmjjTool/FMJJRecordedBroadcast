# 2026-11-20 命名投稿页 UI 优化

## 问题（来自用户截图）

1. 右栏整体放在 `QScrollArea` 里，内容一长，底部「确认重命名 / 跳过」被裁出可视区，只能滚动才点得到。
2. 「直播类型（多选）」用 `QListWidget` + `[ ] 聊天` 文本模拟复选框，既不好看也看不出选中顺序。
3. 顶部两行（刷新/计数/进度 + 自动投稿/投稿按钮）占高度。
4. 预览截图固定 180px 高，右栏剩余空间全空；新文件名不可选中复制。
5. 三个列表没有交替行色，长列表读起来累。

## 改动（`src/gui_qt/pages/rename.py`）

| 区域 | 变化 |
| --- | --- |
| 顶栏 | 压成一行：刷新 / 文件夹计数 / 自动投稿复选框 / 进度 / 投稿设置 / 投稿已重命名视频 |
| 左栏 | 日期文件夹、文件列表加交替行色，分区标题统一 `_section_label`（加粗） |
| 中栏 | 直播类型改成两列真实 `QCheckBox`；勾选顺序用 ①②③ 标在文字后，仍按顺序参与命名；保留「清除所有选择」 |
| 右栏 | 去掉外层滚动区；视频信息收进圆角卡片（版本/平台/标题同一行，输入框单独一行）；预览区改为 `Expanding` 并按当前尺寸等比缩放，窗口缩放会重新适配；新文件名可选中复制 |
| 底部 | 新增固定操作条（写入版权属性 + 跳过 + 确认重命名），不随右栏内容滚动，任何窗口高度都可见 |
| 日志 | 高度 80 → 64，给主体让位 |

## 参数设置 Tab（追加）

用户截图反馈：三列卡片下方留了一大片空白、中列「调试」被裁半行、底部后缀/阈值/保存与附加信息散成两行。

| 区域 | 变化 |
| --- | --- |
| 主体 | 去掉末尾的 `addStretch`（它把多余高度分走了一半，导致三列只占上半页）；三列改为占满剩余高度 |
| 每列 | 列表滚动区加 `palette(base)` 底 + 1px 边框 + 圆角，空余区域也属于卡片，不再像列表悬空；标题改为 600 字重 13px，右侧加「N 项」计数（移动/删除后实时更新）；「添加」按钮同一行 |
| 底部 | 后缀 / 阈值 / 写入版权属性 / 保存设置合并为第一行，附加信息单独第二行，整体收进一张 `alternate-base` 圆角卡片，与三列明显分开 |
| 细节 | 匹配阈值加 tooltip；附加信息加占位提示；列间距 14px、行距 4px |

验证：1258×800 与 980×640 两档窗口下，设置卡片底边都在页面内（755/595 对 766/606）；三列等高、无半行裁切；计数分别为 4 / 8 / 5 项；`test_rename_publishing` 9 项通过。
