# 2026-11-20 采集任务页卡片化 + 控件与状态收敛

## 问题

用户截图（深色）：采集任务页从上到下是一条条裸控件——输入框、按钮行、账号列表、采集参数、限流、进度、日志全部直接铺在页面底色上，没有区块容器；暂停/取消是「▮▮ / ×」字形按钮；「会话定时」后面跟一个孤零零的「○」；空闲时进度条显示「第 0 / 100 个账号」，与列表里的账号数对不上。

## 根因

- `info_accounts.py` 的 `_build_func` 把所有控件直接 `addLayout` 到页面，边距 10、间距 6，没有 `variant="card" / "toolbar"` 语义容器，也没有标题行。
- 状态点、暂停/取消用文本字形充当图标，和全局 `line_icon` 体系不一致；`timer_dot` 只显示「●/○」，没有文字说明。
- 进度条默认 range 0..100，空闲时没设格式，于是显示「第 0 / 100」。
- 账号列表固定 170px，账号少时卡片里空一大片。

## 改动

| 位置 | 改动 |
| --- | --- |
| 页面骨架 | 外边距 16、间距 12；拆成 5 块：`批量添加 / 解析` 卡片、`账号列表` 卡片、`采集设置` 卡片、`运行` 工具栏（variant="toolbar"）、`运行日志` 卡片（占剩余高度） |
| 批量添加 | 输入框 + 操作行：`开始处理`（primary，play 图标）、暂停/取消（`line_icon` pause/close，取消用 danger）、导入文件（folder 图标 + tooltip）；右上角提示 Ctrl+Enter |
| 账号列表 | 标题右侧显示「N 个账号」；全选/反选/清除从纯图标改为 ghost 文字按钮；列表高度按实际条数收缩（最多 6 行，最少 96px） |
| 采集设置 | 左侧两行参数（范围/分组/条数 · 限流/日期段），右侧一列策略开关（增量模式、获取后自动下载），中间细竖线分组；同一卡片的 6 个下拉/输入/按钮统一 30px 高，两行基线一致 |
| 运行区 | 工具栏：`获取最新`（primary，download 图标）+ 暂停/取消 + 分隔线 + `会话定时` + 状态文字「定时未开启 / 定时中 · 每 N 分钟」；下一行进度条改为空闲显示「空闲」（range 0..1），开始时再由原逻辑写入实际总数 |
| 运行日志 | 卡片标题「运行日志」+ 说明「采集过程、错误与统计」；只读文本框占满卡片并加占位提示 |
| 图标 | 暂停/继续切换改为 `pause` / `play` 线形图标（暂停中按钮转 primary），删掉「▮▮ / ▶ / ○ / ●」字形 |

未改任何业务逻辑：采集线程、暂停/取消门闩、会话定时、增量模式、限流、日期段、批量解析流程全部原样，只换了容器、控件外观与状态文案。
