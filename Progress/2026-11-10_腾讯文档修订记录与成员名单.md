# 腾讯文档「修订记录 / 成员名单」全量采集（2026-11-10）

## 需求

把腾讯文档的修订记录（时间 / 版本 / 编辑人）和文档成员名单（昵称 / 权限等级）
本地化、可导出；要求纯 HTTP 直调，不启动浏览器，并能一次拉取全部记录。

## 接口实测（Chrome 抓包 + Python 直连双验证）

### 修订记录

- `GET /dop-api/get/history?padId=<domain$padId>&page=N&xsrf=TOK&uid_only=0`
- 返回 `authors`（uid → 昵称 / 头像）+ `history.items/page/pages`；每页固定 20 个版本，
  **没有 page_size / limit 参数**，全量需顺序翻完 pages 页。
- 版本 item：`v` 界面版本号、`i` 修订号、`t` 毫秒时间、`a` 作者 uid、`l` 子记录（每次编辑）。
- 实测「封茗囧菌数据汇总库」：4430 个版本 / 14164 条编辑 / 222 页 / 约 64 秒；
  最早 2025-03-10（建文档日），共 44 位编辑人。
- 智能表格走同一接口；v6 `/api/v6/file/record/revision/get_list` 仅普通表格可用。

### 成员名单

- `POST /api/collaboratorsearch/list?xsrf=TOK`
  body `{docId:<local padId>, size:100, keyword:"", pageCookie?:"<游标>"}`
- 返回 `result.total/page_cookie/collaborators[]`；游标原样回传直到为空，每页 100 条。
- 字段：`id`(UID)、`name`、`avatar`、`role_id`、`uid_source`、`corp_name` 等；
  role_id 映射：1=可查看、2=可编辑、3=可填写、5=可上传下载、33=特殊、
  1024=可管理、2048=所有者。
- 实测该文档 1707 条记录（接口会重复返回同一 UID），按 UID 去重后 1624 人：
  所有者 1、可编辑 50、可查看 1572、特殊 1。需要文档管理权限。
